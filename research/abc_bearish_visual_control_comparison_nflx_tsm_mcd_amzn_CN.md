# 空头 ABC 视觉控制对照：NFLX、TSM、MCD、AMZN 与 ADBE

日期：2026-08-23  
状态：`visual-control-comparison / not-quantitative / research-only`

## 1. 目的

这不是胜率表，也不是把五个案例压成评分。它的用途是给视觉助手建立一个可复用的人工判断顺序：先看完整图表上是否像空头 `A → B → C/L1`，再分开检查订单是否真实可重建、结构止损是否合理、第一支撑是否允许交易；这不是准确率或自动识别结论。

五个案例都可以在第一阶段记为 `pattern_like`，但它们在交易层的结果不同。正因为结果不同，才适合放在一起作为视觉控制样本。

## 3. 视觉层得到的结论

### A. `strong-looking A` 只改变优先级，不是交易许可

NFLX、TSM 和 MCD 都有足够的方向性，可以优先检查 L1；但 MCD 仍然因为首支撑过近而不交易。视觉助手应该输出：

```text
strong-looking A → 值得检查 L1
```

而不是：

```text
strong-looking A → 必须卖出
```

### B. B 的“受控”要看压力变化，不只是回撤幅度

- NFLX 的 B 很深，但后段稳定，仍没有回到 A 起点，所以保留为 `deep-but-controlled`；
- TSM 的 B 也不浅，但后段收缩、结构没有被接受性破坏；
- MCD 的 B 很短，视觉上更容易让人想卖，但短 B 仍然不能绕过第一支撑；
- AMZN 的 B 更长、重叠更多，因此优先级低于 NFLX/TSM。

这说明“浅 B 优先、深 B 次之”是筛选顺序，不是硬规则。真正需要看的是反向压力有没有继续扩张、是否已经区间化、以及它在 A 起点下方是否仍保持 lineage。

### C. 无 gap 只改善订单审计，不自动改善 R/R

NFLX、AMZN、MCD 都没有原始开盘跳过；但 NFLX 首支撑空间最好，AMZN 边界，MCD 直接被第一支撑否决。订单是否能按原价穿越，和穿越后有没有空间，是两个独立问题。

TSM 则说明小 gap 会切换合同：原 stop 未成交、旧价 limit 未回测，只有事先允许的 gap-reprice 分支才可以另行研究。不能把“后来下跌”倒推成原始订单已成交。

### D. 第一支撑优先于更远的 MM

五个案例都应先回答：触发后最先会遇到哪一个左侧主要低点？只有第一支撑有基本空间，才继续看更远的 MM、AB=CD 或延伸目标。

MCD 是最清楚的反例：虽然更下面的 `277.36–274.31` 历史簇看起来能给出更大的距离，但价格首先会面对 `278.81`，不能跳过它计算漂亮 R/R。

### E. 父级背景会改变样本的用途

ADBE 的完整日线显示，局部空头 A/B/L1-like 发生在 2025-12 高位停顿之后的“过渡转空”阶段。它的财报过滤、订单顺序和首支撑空间都比边界案例干净，但不能与 NFLX 那种普通开放趋势基准放在同一类里。视觉助手应保留两层描述：

```text
局部形态：strong-looking A → controlled B → L1-like
父级状态：transition-to-open-bear
```

这不是把 ADBE 降成无效图，而是防止在不同市场背景下把同一个形状当成同一个机会。

### F. L1 后的连续下跌不自动是 L2

NFLX、TSM 和 MCD 的后续低点都没有自动增加 L2。必须先出现新的独立反向 B，再出现第二次空头尝试；否则只能写成 `L1 后跟随`。如果反弹越过旧 B 高点，默认还要考虑计数重置，而不是机械把下一次下跌叫 L2。

## 4. 视觉助手的阶段性输出模板

在不要求精确量化的阶段，助手可以按下面的顺序给出人工可读结论：

1. **背景**：开放空头、交易区间、过渡还是高潮；
2. **形态**：是否像方向性 A → 反向 B → L1/L2-like；
3. **位置**：B 是否仍低于 A 起点，左侧有没有主要低点/支撑簇；
4. **订单**：sell-stop、收盘确认、limit-retest 或 gap-reprice 是否是不同合同；
5. **风险**：结构止损在哪里，第一支撑先到哪里；
6. **结论**：`值得深入`、`形态像但观望`，或 `不是这个 pattern`。

这个模板允许价格区间和 A/B 端点先用近似值，但不允许混淆时间顺序、订单合同、首支撑或后见之明。

## 5. 当前研究含义

目前最有价值的空头视觉对照不是“最漂亮的图”，而是下面这组分层：

- NFLX：形态像、无 gap、第一支撑有空间；
- TSM：形态像、原订单失效，但重订后仍有空间；
- AMZN：形态像、订单干净，但普通 A/深 B/首支撑只在边界；
- MCD：形态像、订单干净，但第一支撑太近、市场/板块许可混合。
- ADBE：局部形态与订单空间较好、财报通过，但父级过渡且市场逆势；它是条件样本，不是纯开放趋势基准。

它们共同支持视觉优先的工作方式，但远不足以证明固定胜率。它们已经足以作为当前空头 ABC 工作版的条件对照；后续只在出现新的父级状态、订单分支或第一障碍边界时补图，不再为了寻找“完美正例”主动扩大股票池。仍不建立量化扫描器，也不交给 Codex Trading 或 Execution Agent。
