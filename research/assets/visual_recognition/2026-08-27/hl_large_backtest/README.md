本目录服务于 PA Research 的一轮人工看图合同冻结。每张 PNG 都包含：

- 上方：截至窗口末日的两年 Daily 背景；

## 数据边界

价格快照为公开 Yahoo Chart API 历史 Daily OHLCV，经 agent-reach 的 Jina 公开路由读取；抓取/复核时间为 `2026-08-27 Asia/Shanghai`，源市场时区为 `America/New_York`，最新完整 RTH 日线为 `2026-08-26`。本轮没有成功调用 Futu MCP，因此这些资产不称为 Futu 或实时数据。原始/解析价格快照在回测目录中保存为历史研究输入。

本轮只使用 COHR、RBLX、MAR 三只符合当时 `$3B–$100B` 研究池且有足够 Daily 历史的美股普通股；市值和流动性是研究时的准入事实，不把本轮结果解释为当前行情结论。所有图像都只用于人工视觉复核，不是扫描器输出。
