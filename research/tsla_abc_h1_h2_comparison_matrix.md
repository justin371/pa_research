# TSLA 三案例比较：ABC、H1/H2 与日线 R/R

## 研究目的与证据边界

这份矩阵比较以下三个 TSLA 案例：

1. `2026-05-20`：深度回调至 EMA50/EMA200 与主要支撑后的强阳线；
2. `2025-09-04`：深回调后的支撑拒绝型 H2-like 信号，但次日跳空进入阻力；
3. `2025-08-22`：两腿下跌至支撑后，强反应并在 `327–328` 附近形成可研究的短线确认。

三者不是三个完全独立的统计样本：`2025-08-22` 与 `2025-09-04` 属于同一段更大级别的 2025-08 至 2025-09 行情 lineage。因此，本文件用于提炼研究假设，不用于宣称胜率。

数据均来自 Futu OpenD 的历史 QFQ 数据；没有下单，也没有把后来的上涨结果当作当时已知证据。

## 2. ABC 的共同结构

### A 腿：都能看到明确的方向性，但强度不等于开放趋势

三个案例的 A 腿都有以下特征：

- 多根 K 线持续推进，而不是单根孤立阳线；
- 价格重新站回或远离部分均线；
- 低周期也能观察到抬高的研究块；
- 后续 B 腿确实是对一段真实买压的回测。

但三个案例也都提醒我们：A 腿必须放回左侧背景。

- `2026-05-20` 的 A 腿包含扩张和跳空，后面有成熟/过热风险；
- `2025-09-04` 前的 A 腿虽然强，但 B 腿之后仍处于支撑反应和过渡阶段；
- `2025-08-22` 的 A 腿发生在财报跳空后形成的更大恢复区间内，`348.68–357.54` 仍是上沿阻力。

因此，A 腿的正确结论不是“可以无条件顺势追”，而是：

> A 腿确认买方曾经控制市场；是否值得在 C 腿介入，还要由 B 腿、左侧位置和第一道阻力决定。

### B 腿：共同模式是“前强后弱”，不是理想的弱回调

三个案例的 B 腿都比较深，而且前段卖压并不弱：

- `2026-05-20`：B 腿跌破 A 腿的 50% 回撤，并接近/测试 EMA200；
- `2025-09-04`：B 腿回撤约 73%，`2025-08-29` 和 `2025-09-02` 仍有明显卖压；
- `2025-08-22`：父级回撤约 81.8%，`2025-08-20` 仍有明显扩张性下跌。

真正重复出现的不是“B 腿一直很弱”，而是：

1. 前段出现强卖压，H1 不应过度乐观；
2. 价格到达主要支撑或 EMA 汇合区；
3. 后段卖压收缩、出现测试或第一次反转；
4. 第二次多头尝试比第一次更有信息量。

这说明我们的 ABC 研究不能只寻找“强 A + 弱 B”的教科书样本，还要覆盖“深 B、前强后弱、支撑处 H2”的实际样本。

## 3. H1/H2 的共同规律

### H1 不是看见第一根阳线就买

三个案例都支持以下判断：

- `2026-05-19` 的支撑反转是第一次尝试或背景证据，但 Daily 计数并不清楚；
- `2025-09-03` 的上影和低收盘只能算低质量 H1；
- `2025-08-18` 虽然阳线收高，但之后 `2025-08-19`–`2025-08-20` 继续下探，H1 失败。

因此，H1 的任务主要是告诉我们“第一次尝试是否失败”，而不是自动授权交易。H1 质量要同时看：

- 是否发生在支撑，而非区间中部；
- B 腿卖压是否已明显减弱；
- 信号 K 是否有可靠收盘；
- 后续是否真正突破并跟随。

### H2 的价值是失败信息，而不是编号本身

在 `2025-09-04` 和 `2025-08-22` 两个案例中，H2-like 结构都来自第一次尝试没有完成确认：

- `2025-09-03` 先冲高后收弱，`2025-09-04` 才出现更好的支撑拒绝；
- `2025-08-18` 先反弹，随后 B 腿继续下探，`2025-08-22` 才在支撑簇强劲收回。

`2026-05-20` 则提醒我们：如果 Daily 上第一次尝试本身不够清楚，就不能为了让案例看起来完整而强行把第二根强阳线命名为 Daily H2。计数周期必须明确。

共同规则可以写成：

> H2 是“第一次尝试失败或不充分之后的第二次有意义尝试”，不是“第二根阳线”，也不是“任何局部高点的第二次突破”。

## 4. 支撑、阻力与 R/R 的共同规律

### 支撑汇合提高形态质量，但不保证交易可做

三个案例都存在 META 式支撑汇合：

- 主要前低/前高角色转换；
- EMA20、EMA50 或 EMA200；
- 回调腿的低点测试；
- 某些案例还包含缺口或 50% 回撤参考。

这解释了为什么形态本身有研究价值。但支撑只回答“可能在哪里反应”，不回答“从哪里买、止损多远、前方有多少空间”。

### 日线第一障碍是三案例共同的否决条件

三个案例中，Daily 直接入场都被第一道阻力/R/R 审计限制：

- `2026-05-20`：第一主要阻力前约 `0.72R`；
- `2025-09-04`：第一近端阻力前约 `0.59R`，次日跳空后原计划失效；
- `2025-08-22`：大阳线高点追入后，`340.55` 与 `348.68–348.98` 阻力太近，无法提供足够空间。

所以当前最强的共同规律是：

> 形态质量与交易几何必须分开评分。形态可以是 A-/B+，但只要第一道独立阻力不到约 1R，Daily 新仓就应标为 no-trade 或降低到另一个明确的低周期 thesis。

### 低周期可以改善 R/R，但不能偷换结构失效位

三个案例都出现低周期改善空间的可能性，但证据强弱不同：

- `2026-05-20`：有低周期二次推动，但没有无争议的完美触发；
- `2025-09-04`：有 15m 反应—回调—再推进，但时间窗口和阻力不理想；
- `2025-08-22`：`327–328` 突破 `2025-08-21` 高点并收回 EMA20，至 `346.46` 约 `1.3R`，是目前三例中最清楚的短线可交易路径。

但低周期止损代表的是低周期 thesis 的失效，不能把它和 Daily 的结构止损混成一个 R/R。若交易理由是“日线主要支撑反转”，止损必须尊重日线支撑；若交易理由是“15m 支撑后的短线延续”，则必须承认这是另一笔更短的交易假设。

## 5. 现阶段可以暂定的 ABC/H1-H2 规则

这些仍是研究规则，不是 Codex Trading 的自动化规则：

1. **先分层看背景。** 先识别大周期交易区间/趋势，再决定 A 腿是否真的处于开放趋势；A 腿强度不能替代背景判断。
2. **B 腿要分前段和后段。** 前段强卖压会降低 H1 质量；后段收缩、支撑测试和重新收回均线，才为 H2 提供条件。
3. **H1/H2 必须同周期、同一回调计数。** Daily、60m、15m 的计数分别记录；C 腿启动后计数重置。
4. **设置 K、确认 K、实际触发分开。** 强阳线只是证据；入场必须有明确触发，不能事后把收盘价当成可成交价。
5. **主要支撑提升形态质量，主要阻力决定能否交易。** 先排阻力，再看 MM、AB=CD 或通道目标。
6. **第一障碍不到 1R 时，Daily 直接交易跳过。** 若低周期能形成独立、可解释、止损不偷换的交易 thesis，才另行评估短线方案。
7. **强 K 线越大，越要检查风险宽度。** 大阳线可以提高方向证据，却可能让结构止损太远；必要时使用低周期确认、减仓，或不做。
8. **H3/L3 暂不从这三个案例冻结。** 三例没有足够清楚的 H3/L3 样本，下一步需要专门找第三次尝试且能区分衰竭与趋势延续的案例。

## 6. 当前研究结论

### 已得到较强支持的结论

- ABC 更适合描述“方向性 A 腿—回调 B 腿—恢复 C 腿”，而不是固定波浪模板；
- 深 B 腿不能自动排除交易，但通常需要等待 H2 或第二次确认；
- 形态质量、计数质量和交易几何是三个不同维度；
- 主要阻力和第一障碍优先于 MM；
- “形态有效、交易跳过”是正确且有价值的研究结果；
- `2025-08-22` 的 `327–328` 短线路径是目前最适合继续细化的执行例子，但仍只有一个样本。

### 仍未解决的问题

- 何种 B 腿卖压强度仍允许 H1，而不是必须等待 H2；
- 低周期触发与大周期结构止损如何正式分层；
- H3/L3 何时表示衰竭，何时只是趋势延续；
- `1R` 第一障碍标准在不同波动率和交易风格下是否需要分档；
- 这些结论在其他标的、空头案例和不同市场背景下是否成立。

### 对称空头补充样本

独立的 TSLA 空头案例 `2025-02-19`–`2025-03-10` 已单独记录于 [TSLA 空头 ABC 与 L1/L2/L3 复核](tsla_l1_l2_l3_case_study_2025-02-19_2025-03-10.md)。它暂时支持多空对称的研究假设：L1/L2 也必须经过位置、触发、第一障碍和 R/R 审计；L3/第三推可能是趋势延续或卖出高潮，不能自动当作反转。
