# ABC 与 H1/H2/H3、L1/L2/L3 研究范围

## 状态

- 类型：PA Research 研究范围与候选定义
- 状态：工作假设，尚未通过样本统计验证
- 当前重点：ABC 回调结构、H1/H2/H3、L1/L2/L3

## 1. ABC 的工作定义

这里的 ABC 是 Price Action 的操作性描述，不引入 Elliott Wave：

- `A`：有方向性的上涨或下跌腿，重点观察买压/卖压、重叠、收盘位置和推进质量；
- `B`：对 A 的回调或反向测试，重点观察回调力度、腿数、关键位置和是否出现 second-leg trap；
- `C`：回调结束后的恢复或延续腿，必须通过实际的信号 K、触发和跟随来确认。

A、B、C 的边界是暂定的。局部一腿可能嵌套在更大一腿中，所以记录时应同时保留 local leg 和 parent leg，不要过早冻结锚点。

## 2. H1/H2/H3 与 L1/L2/L3

### 多头方向

- `H1`：上涨背景或支撑测试中的第一次有意义的多头尝试；
- `H2`：第一次尝试失败、不充分或没有跟随后，回调中的第二次多头尝试；
- `H3`：前两次尝试之后的第三次多头尝试，通常需要更重视位置、空间和趋势是否已经衰竭。

### 空头方向

- `L1`：下跌背景或阻力测试中的第一次有意义的空头尝试；
- `L2`：第一次尝试失败、不充分或没有跟随后，回调中的第二次空头尝试；
- `L3`：前两次尝试之后的第三次空头尝试，通常需要更重视位置、空间和趋势是否已经衰竭。

H/L 编号描述的是尝试序列，不是自动买卖信号。必须同时检查大周期背景、支撑阻力、A/B 压力、信号 K、触发、止损和第一道阻力/支撑。

## 3. H3/L3 与三推的关系

在我们的研究语境里，H3/L3 应该纳入三推研究，因为第三次尝试经常对应第三个推动点。但两者要分开记录：

- H3/L3 是计数语言，回答“这是同一回调中的第几次尝试”；
- 三推楔形是结构语言，回答“多个推动是否出现衰竭、收敛、重叠增加或反转压力”；
- 当三次尝试逐步减弱，并且发生在主要支撑/阻力、交易区间边缘或 measured-move 区域时，H3/L3 与三推楔形的重叠质量更高；
- 如果第三次尝试仍然强、收盘接近极值、回调很浅且有跟随，那么它可能只是趋势延续，不应只因为编号为 3 就预测反转。

因此，`H3/L3 = 三推候选入口` 是可以采用的研究表达；`H3/L3 = 必然三推反转` 则不能冻结为规则。

## 4. 计数纪律

1. 同一计数必须使用同一周期；Daily、4H、1H、15m 分开记录。
2. 只在同一回调腿中继续计数；出现新趋势极值、回调演变成新交易区间或结构已改变时，重新评估并可能重置计数。
3. 不把每一个微小局部高点/低点都算作一次尝试；必须是有意义的价格行为、位置和失败/跟随。
4. 先记录 setup/count bar，再记录 confirmation/trigger bar；强确认 K 不能事后把相反方向的 setup bar 改写成优质信号。
5. 如果形态在交易区间中部，H1/H2/H3 或 L1/L2/L3 降级；边缘、主要支撑阻力和 META 汇聚区优先级更高。
6. 计数完成后仍需检查第一道障碍和 R/R；H2 或 H3 编号不能抵消近端阻力。

## 5. 当前研究顺序

`大周期背景 → A 腿买压/卖压 → B 腿回调力度 → 主要/次要支撑阻力 → H/L1-3 计数 → 信号 K → 触发与跟随 → 结构止损 → 第一障碍 → MM/AB=CD 目标`

Measured Move 和 AB=CD 先作为空间、目标和管理工具，不独立授权入场。突破交易另行建立 BOP 研究文件，不与本文件的 H/L 计数混用。

## 6. 待验证问题

- H3/L3 在不同市场环境下，究竟何时是衰竭信号，何时只是趋势延续；
- 三推中每一推的“变弱”应如何用可重复的价格行为语言描述；
- 交易区间边缘的 H3/L3 与趋势回调中的 H3/L3 是否需要不同的质量等级；
- H3/L3 的信号 K、触发和仓位管理是否需要单独模板；
- 需要用多个代表性案例比较，而不是凭一个案例冻结规则。
