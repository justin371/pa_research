# TSLA 空头 ABC 视觉审计：2026-02-11 至 2026-03-20

## 研究状态与目的

这是一个第一阶段的视觉研究案例，不是量化规则、胜率结论或实盘授权。它的价值不在于证明后面确实跌了，而在于检查：完整图表上看起来像空头 ABC 时，A 腿锚点、B 腿边界、L1/L2 订单、第一支撑和 measured move 是否能在当时分别说清楚。

数据来自 Futu OpenD 的收盘后历史 QFQ 数据，使用 Daily、研究用 240m 和 15m；只读，不是实时行情。

当前标签：

```text
pattern_like / bearish-ABC-candidate / strong-A-candidate
A-anchor-ambiguity / L1-L2 / first-obstacle-boundary / valid-no-trade
```

## 先说最重要的边界：A 腿低点不能事后固定

早期筛选曾把 `2026-02-11` 的高点约 `436.35` 到 `2026-03-03` 的低点约 `385.39` 当作 A 腿，并把 `2026-03-04`–`2026-03-11` 当作 B 腿。但完整 Daily 数据还显示：

- `2026-03-09` 最低约 `381.40`，低于 `2026-03-03` 的 `385.39`；
- 因而 `2026-03-03` 不能继续被无条件称为整个 A 腿的终点；
- 如果在 `2026-03-12` 做决策，当时已经知道 `2026-03-09` 的下探，不能悄悄保留旧锚点，再用旧锚点计算漂亮的 MM。

因此本例保留两个视觉解释，但不把它们混成一个结论：

1. **早期画法**：`2026-02-11`–`2026-03-03` 像第一条下跌腿，随后出现反弹；`2026-03-09` 的下破使这个画法降级为“局部 A / 锚点待定”。
2. **决策时更稳的画法**：把 `2026-03-09` 的 `381.40` 视为更晚的 A 腿终点，`2026-03-10`–`2026-03-11` 的反弹到 `416.38` 视为一个较短、较快的 B，`2026-03-12` 之后才是 C 的恢复。

这个差异不是小数点误差，而是会改变 B 的定义、MM 锚点和对“强 A、受控 B”的评价。视觉助手应把它报告出来，而不是强行选一个让结果最漂亮的版本。

## 大周期背景

`2026-02-11` 之前价格从约 `397` 一带上行到 `436.35`，随后转弱。`2026-02-12` 是明显的反向扩张日，后面几周虽然有反弹和重叠，但整体高点逐步受压。到 `2026-03-09` 出现向下探底后收回，市场状态更接近：

```text
高位转弱 → 方向性空头推进 → 深度反弹/重新测试 → 空头恢复
```

因此它可以作为空头 ABC 的视觉候选，但不应直接当作“开放空头趋势中段的教科书样本”。`2026-03-09` 的长下影/收回也提醒我们：这段曾经出现过下破失败或波动扩张，A 腿质量应评为“中等偏强但不够干净”，而不是最高等级。

## A 腿：有方向性，但存在锚点歧义

### 共同可见的方向证据

- `2026-02-11` 高点约 `436.35`；
- `2026-02-12` 高约 `436.23`、低约 `414.00`、收盘约 `417.07`，是明显的空头扩张；
- `2026-02-23`、`2026-02-26`、`2026-03-03` 等日线继续出现较低位置；
- 整体从 `436.35` 向 `381.40` 移动，方向不是单纯的慢速宽通道。

### 需要降级的地方

- `2026-02-13`–`2026-02-27` 有较多重叠和反弹，A 腿并非连续三根干净大阴线；
- `2026-03-09` 先下探至 `381.40` 再收回约 `398.68`，这会把它从普通推进升级为带有失败下破/波动扩张特征的复杂段；
- 因此当前只写为 `strong-A-candidate`，不写成“强 A 已冻结”。

## B 腿：两种画法的质量不同

### 旧锚点画法

如果把 `2026-03-03` 当 A 低点，那么 `2026-03-04`–`2026-03-11` 看起来是一个反弹到 `416.38` 的 B。但 `2026-03-09` 已经跌破了旧 A 低点，说明这个 B 的内部并不完全受控；不能只因为后来反弹到 `416.38`，就把整个区间重新包装成标准 B。

### 决策时更稳的画法

以 `2026-03-09` 为较晚的 A 终点时：

- `2026-03-10` 高约 `406.59`、收约 `399.24`；
- `2026-03-11` 高约 `416.38`、收约 `407.82`；
- 这是快速、深度的反弹/重新测试，靠近前方高点和 EMA200 一带；
- 它没有突破 `2026-02-11` 的 `436.35`，所以较大空头背景仍未被破坏；
- 但 B 很短且力度不弱，不能把它描述成“弱反弹、几乎没有买压”。

结论：B 可作为空头恢复前的重新测试，但质量是“深/快/位置明确”，不是“浅/弱/高度受控”。这解释了为什么 L1/L2 值得研究，却不自动获得高质量评级。

240m 上，`2026-03-12` 早段冲到 `406.50` 后，后段持续压低，最后一个 240m 区段最低约 `394.98`、收约 `395.01`。这支持“空头恢复开始”，但不能把它等同于已经拥有足够的目标空间。

### 15m 订单时序

如果把 `2026-03-12` 的低点 `394.65` 作为研究 sell-stop 触发区：

- `2026-03-13 10:45` 的 15m K 线最低约 `394.13`，价格第一次穿过该区域；
- `2026-03-13 11:00` 最低约 `392.37`，说明触发后有进一步跟随；

这更像一个有实际触发和跟随的 L1，而不是只在收盘后凭结果贴标签。研究订单应写成：

```text
order: sell stop
trigger: 2026-03-12 low 394.65 下方的研究区域
actual trigger window: 2026-03-13 10:45–11:00 ET 附近
not allowed: 用 2026-03-13 的最低点 389.95 反推更好的入场
```

### L1 的止损分支

这里必须把两个止损合同分开，不把它们混成一个 R/R：

| 止损口径 | 参考位置 | 约略风险（以 394.65 触发） | 适用含义 |
| --- | ---: | ---: | --- |
| 局部信号 K 口径 | `406.50` 上方 | `约 11.85` | 较紧，但容易被正常重新测试影响 |
| B 结构口径 | `416.38` 上方 | `约 21.73` | 更保守，表示重新突破 B 高点才否定空头背景 |

两者都可以作为研究分支，但不能用紧止损的 R/R 宣传形态，又在失败时要求宽止损的保护。

### L1 入场时真正可见的第一支撑

在 `2026-03-13` 触发时，`2026-03-13` 当天的 `389.95` 低点尚未提前知道，不能拿它作为事前第一目标。此时可见的左侧低点主要是：

若按 `385.39–381.40` 的支撑簇看：

所以 L1 的形态和低周期跟随可以保留，但 Daily 新仓的第一障碍并不稳定地达到 `1R` 以上；它更适合作为“形态成立、空间边界明显”的研究样本。

## C 腿与 L2：`2026-03-16`–`2026-03-19`

### L2 的形成

`2026-03-16`–`2026-03-17` 出现反弹/整理：

- `2026-03-16` 高约 `403.73`；
- `2026-03-17` 高约 `400.12`；

`2026-03-18` 高约 `403.06`，低约 `392.31`，收约 `392.78`。这可以标为 C 内的第二次空头尝试，即 L2-like 信号。

### 低周期时序

240m 和 15m 都显示，`2026-03-18` 早段先冲到约 `403.06`，真正的下破集中在后半段：

- `15:00` 低约 `394.90`；

- `15:45` 低约 `393.30`；
- `16:00` 最低约 `392.31`，收约 `392.78`。

因此如果以 `392.31` 下方挂 sell-stop，它是一个很晚的触发，不能把 `2026-03-19` 开盘约 `387.27` 当成原始成交价。`2026-03-19` 的低开已经是新的状态：它跳过了 `389.95` 附近的第一支撑，也改变了实际成交和管理合同。

### L2 的止损、第一支撑与 R/R

以 `392.31` 研究触发、最近反弹高点 `403.73` 上方作结构止损：

```text
风险约 = 403.73 - 392.31 = 11.42
```

在 `2026-03-18` 触发前已经可见的障碍可以分层：

| 目标/障碍 | 触发前是否已知 | 距离触发价 | 粗略空间 |
| --- | --- | ---: | ---: |
| `2026-03-13` 低点 `389.95` | 是 | `约 2.36` | `约 0.21R` |
| `2026-03-03` 低点 `385.39` | 是 | `约 6.92` | `约 0.61R` |
| `2026-03-09` 低点 `381.40` | 是 | `约 10.91` | `约 0.96R` |

这说明 L2 的结构比 L1 更清楚，但第一道支撑非常近，深一层支撑才接近 `1R`。所以它是一个很好的“形态与交易几何分离”样本：

```text
L2 形态：pattern_like，触发真实，低周期有跟随
Daily 新仓：valid_no_trade，第一障碍拥挤
已有 L1 仓位：属于管理/减仓/保护问题，不应重新当作一笔完整 L2 新仓
```

## Measured move：两组锚点都只能是参考

### 旧锚点投影

如果暂时使用 `436.35` 到 `385.39`：

```text
第一段高度 = 436.35 - 385.39 = 50.96
从 B 高点投影 = 416.38 - 50.96 = 365.42
```

`2026-03-20` 最低约 `364.46`，看起来非常接近这个目标。但这不是理由去把 `385.39` 事后冻结成唯一 A 终点，因为 `2026-03-09` 已经下探到 `381.40`。

### 较晚锚点投影

如果以 `2026-03-09` 的 `381.40` 作为 A 腿终点：

```text
第一段高度 = 436.35 - 381.40 = 54.95
从 B 高点投影 = 416.38 - 54.95 = 361.43
```

这个投影更接近后面 `2026-03-27` 约 `359.47` 的区域。它同样只是事后比较，不能在 `2026-03-12` 或 `2026-03-18` 用未来的到达结果授权入场。

本例的真正结论是：A 腿锚点尚未稳定时，MM 只能写成“候选目标区”，不能写成精确目标；更不能让 MM 覆盖 L1/L2 触发下方的第一支撑。

## 这个案例对视觉助手的贡献

1. **先看起来像，再检查锚点。** 视觉上能看到空头 A、反弹 B 和两次 L 尝试，但后续极值可能迫使我们把 A 终点改成“待定”。
2. **同日后续低点不属于触发前信息。** `2026-03-13` 的 `389.95` 不能用于事前 L1 目标；它只能在 L2 决策时作为已知左侧位置。
3. **L1 与 L2 是两个订单分支。** L1 触发在 `2026-03-13` 上午，L2 触发在 `2026-03-18` 收盘前；不能用 `2026-03-19` 的低开替代任何一个成交价。
4. **紧止损和结构止损不能混算。** 局部 K 线止损与 B 高点止损分别给出不同的 R/R，研究报告必须同时公开，而不是只挑有利的一组。
5. **形态像不等于应该交易。** 本例的 L2 比 L1 更清楚，但第一支撑只有约 `0.21R`，所以“观察/不做”是正确输出。
6. **MM 不是入场理由。** 365 附近或 361 附近的投影只帮助规划目标和停顿，不改变背景、支撑和订单时序。

## 后续使用方式

以后遇到类似图表，先输出：

1. A 腿终点是否已经被后续 K 线重新定义；
2. B 腿是弱反弹、深但受控，还是复杂转区间；
3. L1/L2 的真实触发时刻和订单类型；
4. 触发前已经知道的第一支撑；
5. 紧止损与结构止损下的两套粗略 R/R；
6. MM 是否依赖一个尚未稳定的锚点。

这套输出保持视觉筛选优先，不把判断变成量化扫描器，也不修改 Codex Trading。
