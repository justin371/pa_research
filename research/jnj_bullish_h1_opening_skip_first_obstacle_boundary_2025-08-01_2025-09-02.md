# JNJ 多头 H1-like：板块配合但触发被小缺口跳过、B 高点形成首阻力（2025-08-01 至 2025-09-02）

状态：`pattern_like / strong-looking-A / controlled-B / bullish-H1-like / sector-aligned / opening-skip / first-obstacle-crowded / valid_no_trade / event-context-pending`

## 1. 研究目的与数据

- 标的：`US.JNJ`；板块参考：`XLV`；
- 周期：完整 Daily 背景，再用 60m 和 15m 核对 `2025-08-29`–`09-02` 的触发顺序；
- 数据：Futu OpenD 历史 QFQ，收盘后读取；不是实时行情，没有下单；
- 目的：记录一个视觉层质量不错、板块方向配合，但订单和首障碍仍然否决直接入场的普通 H1-like 窗口。

## 2. A、B 与 H1-like

### A 腿

从 `2025-08-01` 到 `2025-08-15`，价格由约 `160.77` 的低点推进到约 `172.94` 的高点。中间收盘大多沿高位推进，重叠相对少，先记为 `strong-looking-A`；这里仍是视觉标签，不冻结成固定涨幅阈值。

### B 腿

`2025-08-18`–`08-28` 回到约 `171.62`，时间上有整理、后段压力收窄，但 `08-22` 的高点仍达到约 `176.74`，说明 B 内部并非一条简单的浅回调。更准确的标签是 `controlled-B`，同时保留“B 期间有更高反向测试”的风险。

### C / H1-like

`2025-08-29` 开盘约 `172.94`，收盘约 `174.12`，最高约 `174.35`，实体和收盘位置都不错，视觉上可作 B 后第一次恢复的 `bullish-H1-like`。但它的信号质量不能替代触发和空间审计。

## 3. 订单与低周期顺序

- 研究 buy-stop 参考：`174.35` 上方；
- `2025-08-29` 的 15m 在约 `15:15` 最高触碰 `174.35`，没有证明已经越过“上方一点”的 buy-stop；
- `2025-09-02` 开盘约 `174.41`，已经略高于原触发。原价精确成交不能从 OHLC 推断，原 stop、开盘重订和放弃交易必须分开；
- 这不是无缺口直接成交样本，也不能把 `09-02` 的高点约 `176.11` 倒灌成 `08-29` 入场时已知的跟随证据。

## 4. 第一阻力、结构止损与 R/R

### 第一独立障碍

触发前可见的最近高点是 `2025-08-22` 的约 `176.74`，它属于 B 期间的反向高点，但仍然是买入触发上方必须处理的价格记忆。触发约 `174.35` 到该高点约 `2.39`，并不宽。

### 结构止损

日线 H1 thesis 的结构止损应观察 B 低点约 `171.62` 下方；用 15m 的局部小低点压窄风险，会改变交易 thesis。按这个结构观察区，首障碍给出的粗略空间不足 `1R`，因此直接日线新仓判为 `valid_no_trade`。

### 板块与事件

- `XLV` 同期整体保持向上背景，板块方向可以记为 `sector-aligned`；
- 财报/重大事件日期在本案例中未单独核验，保留 `event-context-pending`；
- 板块配合只能提高候选质量，不能取消开盘跳过或近端首阻力。

## 6. 可复用结论

1. 板块顺势、强-looking A 和漂亮 H1-like 信号 K，可以让候选值得复核，但不等于订单可成交；
2. B 期间产生的更高反向测试仍然是触发前的阻力，不因它被叫作“回调”就从空间审计中删除；
3. 15m 只触碰信号高点时，不能把“等于触发价”写成“已经突破”；
4. 小缺口后的开盘重订必须单独重算首障碍和结构止损；
