# 紧通道、宽通道与趋势状态切换：视觉研究框架 v0.1

日期：2026-08-23  
状态：`framework / partial / provisional / not-quantitative`

这是一份 Al Brooks Price Action 的视觉工作框架，不是量化识别器。它先回答“现在是紧通道、宽通道、区间，还是仅仅一条趋势线候选”，再决定 H/L、突破、反向和订单。

## 1. 最小定义

### 紧通道（tight channel）

- 单方向压力持续，回调通常很浅，常见为一至三根 K 线或短时间整理；
- 重叠少，收盘经常靠趋势方向的一侧，反向信号很快失败；
- 默认尊重惯性：紧牛通道优先做多，紧熊通道优先做空；
- 不能仅凭一根反向 K 线做主要反转，必须看到明显通道破坏、反向跟随和后续测试。

### 宽通道（broad channel）

- 仍有方向性，但双方参与明显增加；回调更深、重叠更多、上下边界反复测试；
- 至少需要多个可见运行和大致平行边界才称为通道；只有两个高点或低点，先称趋势线候选；
- 上边界、下边界和中线都可能成为磁铁；中间位置通常不适合追单；
- 宽通道可以是潜在旗形，也可以逐渐转成交易区间，不能自动当成反转形态。

### 不要误叫通道

- 一条强方向 A 腿后只有两点连线：先记为趋势线候选；
- 成熟区间内的上下摆动：先用区间边缘逻辑；
- 一次缺口冲击或单根大 K：先记为冲量/重新定价，不凭外观命名为通道；
- 后见之明中能画出漂亮平行线，不代表当时已经有可交易通道。

## 2. 状态切换

按当时已经看到的证据，状态可以这样切换：

| 当前状态 | 可见变化 | 下一状态与处理 |
| --- | --- | --- |
| 紧牛/紧熊通道 | 回调变深、重叠增加、反向低点/高点开始持续，微型通道线被破坏 | 先切到 `transition / small range`；不要立即宣布 MTR |
| 宽通道 | 上下边界反复、边界逐渐水平化、价格频繁穿越中线 | 切到交易区间；边缘优先，中部减少交易 |
| 宽通道/区间 | 强 K 收盘离开边界、后续跟随、回踩守住旧边界 | 切到 BOP/突破回踩；旧区间反转剧本失效 |
| 任一趋势通道 | 只出现一次趋势线刺破，没有跟随，价格仍在原通道极端附近 | `observation / transition`，不能反向追单 |
| 紧通道末端 | 扩张 K、高潮或多次失败推进，随后形成小区间/两腿回调 | 先期待小反转或平衡，再看是否形成 MTR/Final Flag |

“通道变宽”是状态变化证据，不是空头或多头反转信号本身。主要反转仍需要强反向压力、结构破坏、第二次确认和足够空间。

## 3. 浅回调、深回调和 H/L

- 紧通道中的浅回调若很快恢复、没有反向接受，可研究顺势 H1/L1；但信号 K、首障碍和止损仍要单独检查。
- 回调变深或走两腿时，H1/L1 优先级下降；若位置仍在通道边界/支撑阻力处，再观察 H2/L2。
- 宽通道边缘的 H2/L2 不能直接当趋势二次入场；先确认是在上边界做空、下边界做多，还是发生了突破后的新趋势。
- 通道中线或宽通道中部出现的局部 H/L，通常只保留为观察，避免把摆动计数伪装成方向性回调。
- 反向 H/L 只有在通道破坏、反向跟随和回测确认后，才可升级为 MTR/Final Flag 候选；否则只是小反转或获利回吐。

## 4. 订单、结构止损与 R/R

| 分支 | 适用情形 | 研究限制 |
| --- | --- | --- |
| `stop-confirmation` | 紧通道回调恢复、宽通道边缘出现 H/L、或通道外突破确认 | 触发价必须在当时冻结；宽 K 或晚触发要降低仓位/重算风险 |
| `limit-retest` | 宽通道边缘、通道外侧角色转换、突破后的旧边界回测 | 只在结构区预先挂单；未回测不算成交，不能事后补成交 |
| `market/close` | 通道外强突破、收盘接受和跟随同时出现 | 追价需接受更宽结构止损；接近另一侧磁铁时空间不足就跳过 |
| `observation-only` | 只有两点趋势线、边界不平行、通道中部、状态切换不清或首障碍太近 | “没有交易”是正确的研究输出 |

紧通道顺势交易的结构止损应放在能破坏最近有意义回调/通道结构的位置外；不要把止损压在单根小 K 线下方。宽通道边缘交易的止损应放在边界和最后一次测试极端外；中线不是止损依据。

目标顺序：

1. 先看入场前已知的最近独立支撑/阻力；
2. 紧通道顺势可看下一推进或通道边界，宽通道边缘先看中线/另一边界；
3. 只有前方结构被接受后，才看 MM、AB=CD 或通道扩展。

研究过滤参考仍是首障碍约 1R、完整波段接近 2R；这不是固定胜率规则。宽通道如果从边缘到中线都不足以覆盖结构风险，即使方向后来正确，也记为 `valid_no_trade`。

## 5. 少量案例审计

### KLAC：2025-03-17–03-26，宽熊旗上边界的空头恢复

- `2025-02-20–03-11` 父级明显偏空；`03-17/19/24` 三次上探 `71.78/72.36/72.87`，更像宽熊旗或宽通道上边界，而不是独立多头 ABC。
- `03-25` 低点约 `71.16` 下方作为空头 stop；`03-26` 15m 实际触发，之后价格接受更低位置。
- 主结构止损约 `74.50` 上方；第一支撑/管理区约 `66.6–65.1`，粗略约 `1.4R–1.9R`；更远 `61–62` 只作延伸。
- 结论：`broad-bear-channel/flag-edge / L1-after-H3-like-failure / research-positive-conditional`。它支持“宽通道上沿顺势做空”，不支持在通道中部追空，也不证明第三推必然反转。

### TSLA：2025-08-22–08-25，强多头推进与通道线候选

- `08-20` 到 `08-22` 的买方推进强，`08-22` 低周期越过 `08-21` 高点约 `324.90`；若用 `326.65` 附近 buy stop、`318.68` 下方止损，第一阻力 `340.55` 约有 `1.7R` 的低周期研究空间。
- 但 `07-21` 与 `08-11` 两个高点只能先构成上方阻力趋势线候选；没有确认平行下边界，不能把 `346–352` 直接叫成熟上升通道。
- 日线在 `340.25` 上方追入时，近端阻力和结构风险不匹配；低周期分支可以研究，但不能用窄止损替代日线 thesis。
- 结论：`tight-trend / channel-line-candidate / low-cycle-conditional`。这是“强趋势不等于已经确认通道”的多头边界。

### XOM：2024-07-25–08-02，宽熊旗第三次上探扩张

- `07-18` 后有空头 A；`07-25/30/31` 三次上探 `109.82/110.34/111.43`，第三次范围没有收缩，反而扩张。
- `08-01` 空头反应后，低点约 `108.26` 下方可研究 sell stop；`08-02` 开盘约 `107.90` 跳过原触发，必须重订成交。
- 结构止损约 `111.43–111.60` 上方；第一支撑约 `105.20`，理想触发约 `1R`，开盘重订后约 `0.7R`，因此应观望或等待新回测。
- 结论：`broad-channel/flag-expansion / L1-like / gap-reprice / valid_no_trade`。第三次上探扩张时，不把宽通道顶部误叫衰竭楔形；订单重订和首支撑进一步否决交易。

## 6. 与相邻形态的边界

| 相邻形态 | 通道研究中的处理 |
| --- | --- |
| 普通 ABC/H1/H2 | A 腿和 B 腿仍是主要结构；若 B 变宽并反复运行，降级为宽通道，不强行保持简单 ABC |
| 交易区间 | 边界变平、双方反复、价格穿越中线后，区间边缘优先；中部 H/L 不交易 |
| BOP | 强收盘离开通道/区间，跟随并回踩守住后，切换到突破接受；旧通道反转假设失效 |
| Final Flag | 趋势末端压缩；通道变窄或小区间不自动等于 Final Flag，需看位置和后续反向确认 |
| MTR | 需要通道破坏、反向压力、测试和第二次确认；第一次刺破只是过渡 |
| 三推/楔形 | 三次测试可发生在通道里，但第三推扩张与第三推减弱必须分开；次数本身不授权反转 |

当前结论：紧通道的核心是尊重惯性，宽通道的核心是位置和双方交易，状态切换的核心是“重叠、回调深度、边界接受和跟随”。本轮没有把任何案例升级成固定胜率规则；干净的紧通道正向样本仍需后续遇到新证据时补充，不为填数量重复旧案例。
