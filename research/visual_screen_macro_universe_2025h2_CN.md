# 2025 H2 宏观与跨行业日线视觉筛选

日期：2026-08-23
状态：`visual-screen / stage-1 / not-quantitative`

## 这轮筛选的目的

这不是扫描器，也不是胜率统计。本轮只用完整的日线窗口，先把“看起来像普通 ABC、H1/H2 或 L1/L2”的图形和明显不是该逻辑的图形分开；没有为每个候选补 15m 订单、精确止损或精确 R/R。

第一阶段只问：

1. 左侧是不是趋势，而不是区间中部；
2. 是否能看见方向性 A 腿；
3. B 回调是否还保持受控，还是已经变成新的区间/反向趋势；
4. 原方向是否出现值得继续研究的 H/L 尝试；
5. 事件跳空、明显缺口或尺度嵌套是否让 lineage 变得不可靠。

## 数据与视觉范围

- 标的：`JPM`、`GS`、`BAC`、`XOM`、`CVX`、`MCD`、`KO`、`PG`、`WMT`、`LLY`、`UNH`、`SPY`；
- 周期：Daily QFQ；窗口约为 `2025-06-01`–`2025-12-31`；
- 来源：Futu OpenD 历史数据，收盘后读取；不是实时行情；
- 图上 EMA20/EMA50 只作视觉辅助，不单独创造 pattern；
- 本轮没有把财报日、低周期触发或后续盈利结果写成已验证证据；进入第二轮前仍需单独核对。

## 暂存的两个训练重点

### `SPY`：指数层的视觉基准

`SPY` 的价值不是给出交易信号，而是提供一个相对少受单一财报影响的背景基准：在完整日线里，趋势腿、时间整理、浅回调和再次推进都比较容易看见。后续可以用它先练习“这是不是开放趋势中的 B”，再把同一逻辑放回个股。

但指数也会有宏观事件跳空和快速状态切换；`2025-07-07`–`2025-07-18` 的局部窗口已经完成一轮订单与首阻力审计，但这不代表整段 SPY 历史都通过了交易筛选。

### `JPM`：金融股普通延续候选

`JPM` 的多个上涨—回调—恢复片段比 `XOM/CVX/MCD/KO` 更接近普通趋势延续。当前最重要的未决问题不是“能不能找到一个 H2 标签”，而是：完整图表里看到的两次尝试，是否属于同一回调，还是前一次已经结束、后一次应重新计数为 H1-like。

因此暂存为 `pattern_like`，不先写成 H2 正例，也不使用后面的上涨结果证明前面的入场清楚。

## 这轮得到的研究结论

1. 视觉筛选的第一价值是快速分离“值得放大”和“明显不属于普通 ABC”的图，不是制造更多交易样本。
2. 同一行业的多张图同时变好，可能只是共同市场环境，不能直接当作多个独立证据。
3. 强趋势、宽区间、事件恢复和普通回调在缩小窗口后都可能长得相似；必须保留完整左侧背景。
4. 第一阶段看到像就足够进入候选；只有进入第二阶段后，才有必要核对订单、结构止损、第一障碍、财报过滤和止盈路径。
5. 当前仍没有理由把这些视觉候选交给 Codex Trading 或 Execution Agent。

## 下一步

SPY 的局部窗口已经完成第二阶段放大；下一步只需把它作为“形态像但首阻力否决”的控制样本，与 JPM 或新的普通个股窗口比较，不再把后续上涨当成必须深入的理由。JPM 仍需先解决多尺度暂停和计数重置问题。

## 放大后的结果

对原始宏观候选继续放大后的结果如下：

- `SPY`：`2025-08-01` 附近的原始大窗口仍有跳空状态切换，不能冻结唯一 H1/H2；但单独抽出的 `2025-07-07`–`2025-07-18` 局部段，日线 A/B 外形和 15m/60m 触发顺序可以审计。`07-17` 仍保留 H1/H2 两种计数，且 `619.4–620.0` 第一阻力过近，归档为 `pattern_like / low-cycle-trigger-confirmed / first-resistance-blocked / valid_no_trade`。详见独立案例文件。
- `JPM`：`2025-08`–`2025-09` 的上行方向比区间型标的清楚，但中间有多个不同尺度的暂停和回撤；目前无法确认它们属于同一条 B 回调，还是几次已经结束后重新开始的局部结构。状态降为 `pattern_like / lineage-ambiguous`。

这次放大没有产生新的条件正向样本，但它确认了两个入口规则：**完整图表里“总体很强”不等于局部 H1/H2 计数已经清楚；即使低周期触发真实，第一阻力过近仍应输出不做。** 第一阶段保留候选即可，不能为了继续做订单审计而硬数。
