# 双顶/双底、MTR 与 Final Flag：视觉边界对照 V0.1

状态：`visual-research / provisional / comparison-layer / not-quantitative`

这份文件是一个**分类入口**，不是新的胜率规则。它把四种容易混淆的视觉叙事放在一起：

1. 普通趋势回调或 ABC 延续；
2. 成熟交易区间边缘的双顶/双底反应；
3. 趋势末端压缩后的 Final Flag；
4. 主要趋势反转（MTR）候选。

双顶/双底首先是一个位置和形状描述，不是自动反转信号。MTR 需要成熟趋势、重要位置、反向结构破坏、第二次确认和空间；Final Flag 需要趋势已经走了一段并在末端压缩；普通回调则通常仍由原趋势控制。

## 1. 统一的视觉问题

按决策时点依次回答：

1. **父级状态是什么？** 开放趋势、成熟区间、通道，还是状态转换？
2. **第二次测试在哪里？** 前高/前低、区间边缘、通道边界、缺口边缘，还是区间中部？
3. **两次测试之间有分离吗？** 是否有清楚的反应和可识别的中间摆动？
4. **原方向还有控制吗？** 推进、回调和跟随是否仍然支持原趋势？
5. **反向发生了什么？** 只有减速、第一次反向，还是已经突破局部结构并得到第二次确认？
6. **第一障碍在哪里？** 实际订单成交后，结构止损外到第一独立支撑/阻力是否有基本空间？

如果第 1、2 或 6 项不清楚，先不要用“双顶/双底”这个名字授权交易。

## 2. 四种状态的最小区分

| 状态 | 必须看到的东西 | 默认解释 | 可研究的订单 |
| --- | --- | --- | --- |
| `ordinary_pullback` | 原趋势仍有方向和跟随；反向回调未破坏主要结构 | 先看 H1/H2 或 L1/L2 延续 | 位置好的 stop；首障碍不足则观望 |
| `range_edge_double_top_bottom` | 父级区间已成熟；第二次测试发生在上沿/下沿；边缘反应清楚 | 区间边缘反转或失败突破二次入场 | 边缘 limit-retest、反向 stop；中部不交易 |
| `final_flag_candidate` | 趋势末端、运行已久、末端压缩/窄区间；最后一次尝试待确认 | 原方向可能延续，也可能先出现小反转/区间 | 接受则 BOP；失败后等反向二次确认 |
| `MTR_candidate` | 成熟趋势 + 主要位置 + 双顶/双底/失败突破 + 反向结构破坏 + 第二次确认 | 市场状态可能改变，但仍需失效和空间审计 | 反向 stop、结构回测 limit；强收盘才考虑 market |

外形相似时，优先级是：**父级状态 → 位置 → 接受/失败 → 反向跟随 → 订单几何**。形状名称放在最后。

## 3. 双顶/双底的最低视觉条件

### 3.1 两次测试必须有分离

- 两个高点/低点不要求精确同价，可以略高、略低或一次刺破后收回；
- 两次测试之间要有可见反应或中间摆动，不能只是连续几根 K 的影线；
- 第二次测试应发生在同一母级结构区域，若已经离开原区域并建立新趋势，旧双顶/双底叙事要重置；
- 双顶/双底可以是区间边缘二次测试、Final Flag 内部结构或 MTR 的位置证据，不能单独决定归类。

### 3.2 反转要看触发，不看名字

第二次测试后的第一根反向 K 只能标为 `reversal_attempt`。更可靠的确认包括：

- 反向 stop 突破信号 K 或局部颈线/中间摆动；
- 第一次反向后没有跟随，第二次反向再次突破；
- 失败突破重新回到原区间，并在边缘形成有跟随的二次入场；
- 回测双顶/双底颈线或突破边界后守住。

如果原方向强势收盘越过第二次测试并获得跟随，双顶/双底反转假设应标为 `failed-thesis`，切换到 BOP/延续分支。

### 3.3 颈线不是自动目标

颈线/中间摆动是确认结构和第一管理点，不等于必到的目标；最近左侧支撑/阻力优先于远端 MM。MM 只有在第一障碍被接受后，才作为后续路径。

## 4. MTR 与 Final Flag 的分界

### MTR 需要“状态改变”的证据

MTR 不是“双顶/双底 + 一根反向 K”。至少要把以下内容串起来：

```text
成熟趋势/主要位置
→ 第二次测试或失败突破
→ 第一反向运动
→ 第一次反向失败/跟随不足
→ 第二次反向确认
→ 结构接受、跟随和有空间
```

若只走到第一反向运动，使用 `reversal_attempt` 或 `small_reversal_or_range`；若第一障碍紧贴触发，使用 `valid_no_trade`；若原趋势重新接受极端，使用 `failed-MTR-thesis`。

### Final Flag 更强调“末端压缩”

Final Flag 的核心不是双顶/双底，而是持续趋势已经较晚，最后一段出现小回调或窄区间。最后一次突破：

- 被接受：归入趋势延续/BOP；
- 失败：才进入反向小反转、区间或 MTR 审计；
- 没有明确接受或失败：保持观察，不提前做反向。

普通趋势中段的小旗形不叫 Final Flag；成熟区间边缘的双顶/双底也不必叫 Final Flag。

## 5. 无后见之明的订单和风险协议

### 分支 A：反向 stop

在第二次测试形成信号 K 后，在其外侧等待反向确认。记录：

- 原始触发价和实际成交价；
- 是否跳空越过触发；
- 结构止损是在第二次测试极端外，还是在母级主要高/低点外；
- 第一独立支撑/阻力和粗略 R/R。

### 分支 B：结构回测 limit

只有双顶/双底颈线、失败突破边界或支撑阻力转换已经存在，才单列 limit-retest。未回到区域前不能假设成交；跳空后旧合同作废，不能用理想触发价计算 R/R。

### 分支 C：market/close

仅在反向收盘很强、结构已破坏、等待会明显错过且第一障碍仍有空间时研究。大 K 若同时是事件/高潮 K，优先降级或观望。

### 分支 D：observation-only

出现以下任一项就保留观察：

- 只有双顶/双底形状，没有反向跟随；
- 父级是区间中部或状态转换，计数不稳定；
- 第一障碍不足约 1R，或结构止损必须压进正常波动；
- 原方向已经强势突破并接受；
- 财报/重大事件使普通几何失真。

## 7. 可迁移工作结论

1. 双顶/双底是**位置 + 两次有分离的测试**，不是自动做空/做多；
2. 区间边缘的双顶/双底，先用区间边缘二次入场逻辑；不要把区间摆动写成 MTR；
3. Final Flag 要求趋势末端压缩；若原方向突破接受，它就是延续/BOP，不是反转；
4. MTR 需要第一反向、第二次确认、结构接受和空间；第一反向本身通常只支持小反转/区间预期；
5. 主要高/低点、失败突破边界和第一障碍优先于 MM；静态 R/R 不能替代路径审计；
6. 只要原方向重新接受极端，原双顶/双底、Final Flag 或 MTR thesis 必须结束并重新分类。

## 8. 当前缺口与停止条件

当前已有多空、区间边缘、Final Flag 延续、MTR 边界和 BOP 否定对照，但仍缺一个无事件、首障碍宽裕、反向二次确认清楚且过程完整的标准 MTR 正例。这个缺口不允许用更多相似的 NFLX/TSLA 边界案例掩盖。

只有出现以下新证据才继续增加案例：

- 一个事件干净、成熟趋势极端、双顶/双底或失败突破明确的反向二次入场；
- 一个相同外形但原方向被接受、可明确归入普通延续或 BOP 的对照；
- 一个能清楚分开区间边缘和 Final Flag 的新案例。

在此之前，本文件和相关框架均保持 `provisional`，只服务于视觉筛选、观望和研究记录，不进入 Codex Trading 或 Execution Agent。
