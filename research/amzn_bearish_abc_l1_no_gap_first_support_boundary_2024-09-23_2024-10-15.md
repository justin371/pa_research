# AMZN 空头 ABC / L1-like：无缺口触发但首支撑边界（2024-09-23 至 2024-10-15）

状态：`pattern_like / ordinary-or-directional-A / deep-B / L1-like / no-gap-trigger / first-obstacle-borderline / sector-mixed / earnings-filter-passed / pending`

## 1. 证据头

- 标的：`US.AMZN`
- 周期：先看 Daily 完整窗口 `2024-08-01`–`2024-10-31`，再用 60m/15m 核对 `2024-10-11`–`2024-10-16`。
- 数据：Futu OpenD 历史 QFQ，收盘后读取；不是实时行情，没有下单。
- 目的：这是一个不依赖缺口重订的独立边界样本。它能画出 A→B→L1-like，但没有明显的首障碍余量，且板块许可不完整；用于防止“无缺口 + 形态像”被误当成正向交易。

## 2. 视觉结构

### A 腿：有方向性，但不是最干净的强 A

`2024-09-23`–`2024-09-24` 的高点约 `194.45–195.37` 后，价格逐步向下推进：`09-27` 低点约 `187.34`，`09-30` 约 `184.65`，`10-01` 约 `183.45`，`10-03` 低点约 `180.88`。低点下移和方向性都能看见，但中间仍有重叠，视觉质量低于 TSM 或 KLAC 那种更干脆的 A。

所以第一阶段标为 `ordinary / directional-A`，而不是强行定义为教科书级 strong A。它仍足以进入候选，但需要更重视 B 的质量和第一障碍。

### B 腿：较深、持续时间较长，但仍低于 A 起点

`2024-10-04`–`2024-10-11` 从 `180.88` 附近反弹到约 `189.93`，没有收回 A 起点 `195.37`。反弹内部有多次往返，属于深且较长的 B；但截至 `10-11`，它还没有明确演化成完全开放的多头趋势。

`2024-10-14` 低点约 `187.36`，没有跌破 `10-11` 低点约 `186.30`。这一天不能提前称为 L1；它更像 B 后的压缩/等待。这个时间点很重要，因为不能把 `10-15` 的结果倒灌到 `10-14`。

### C / L1-like：无缺口的第一次空头恢复

`2024-10-15` 开盘约 `187.63`，没有跳过预设触发区。日内先在 `187–188` 一带波动，随后在 `10:45` 左右的 15m K 线最低约 `184.58`，跌破前一段 `10-11` 低点约 `186.30`。从完整图表回看，这可以标为 B 后第一次清楚的空头恢复，即 `L1-like`。

这里必须把低周期时点说准确：不是把 `10:30` 的 K 线误当成已跌破；实际越过 `186.30` 的过程出现在约 `10:45`。这是一笔无开盘跳过的可重建触发，但不代表它值得交易。

`2024-10-16` 的继续下跌先作为 L1 后跟随记录；没有新的反向 B 和独立第二次空头尝试，不能事后加成 L2。

## 3. 订单分支：无缺口也要先冻结触发

### 分支 A：sell-stop

- 若在 `2024-10-11` 低点约 `186.30` 下方挂 sell-stop；
- `2024-10-15` 盘中约 `10:45` 才按低周期顺序穿越该区域；
- 因为不是开盘跳过，不需要创建 gap-reprice 分支；但成交仍应按实际穿越价和当时的 15m 结构审计，不能直接用日线收盘价代替。

### 分支 B：过早的 `10-14` 交易

`10-14` 没有跌破 `10-11` 的低点，因此不应因为它位于 B 后段就提前卖出。若要把它当作观察日，订单类型应为 `observation-only`，等待新的低点突破或清楚的信号 K；否则会把“等待”误写成 L1 入场。

## 4. 结构止损、第一支撑与粗略 R/R

### 结构止损

若研究 `10-15` 的 L1-like 触发，保守结构止损放在 B 高点 `189.93` 上方并留缓冲，约看 `190.7–191.2`。不能用 `10-15` 盘中局部小高点压窄风险，因为那会隐藏 B 的结构失效。

### 第一独立支撑

入场时左侧仍可见的第一支撑区先看 `2024-10-03`–`10-07` 的低点簇，约 `180.25–180.88`。`10-15` 后面形成的更低点和随后的跌幅不能倒灌为当时目标。

## 7. 可复用结论

1. 无缺口只说明订单触发更容易审计，不说明形态或交易质量自动更高。
2. 普通或不够干净的 A 仍可进入视觉候选，但需要更严格地检查 B 是否已经变成宽区间，以及第一支撑是否有空间。
3. B 后的第一天没有跌破前低时，不能提前贴 L1 标签；`10-14` 是观察，`10-15` 才出现可重建的 L1-like 低周期下破。
4. `10-16` 的连续下跌不自动增加 L2；没有新的反向 B 和独立第二次尝试，就先记为 L1 后跟随。
5. 这个案例补足了 TSM/NKE 之外的第三种订单结果：没有 gap-reprice 问题，但形态仍因普通 A、深 B、板块混合和首障碍边界而不能升级为正向样本。
6. 视觉助手的正确输出可以是“pattern-like，但不值得做”，而不是为了寻找交易而强行挑出入场点。
