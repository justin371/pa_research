# LRCX 空头 ABC / L1-like：强 A、受控 B、开盘跳过与首支撑边界（2024-07-10 至 2024-07-25）

状态：`pattern_like / bearish-ABC-candidate / strong-A-gap-impulse / controlled-B-conditional / L1-gap-trigger-reprice / sector-aligned / first-support-borderline / earnings-filter-passed / valid_no_trade`

## 1. 证据头

- 标的：`US.LRCX`
- 周期：Daily 完整窗口 `2024-05-01`–`2024-08-15`；60m/15m 核对 `2024-07-19`–`2024-07-26`。
- 板块参考：`US.SOXX`、`US.SMH`。
- 数据：Futu OpenD 历史 QFQ，收盘后读取；不是实时行情，没有下单。
- 目的：这是一个比 DIS 更干净的视觉空头候选：父级先上涨，A 方向清楚，B 没有收回 A 起点，L1 也能按当时的 K 线画出。它最终仍被订单和首支撑边界挡住，因此用于训练“形态通过后还要审计成交合同”，不是生产规则。

## 2. 背景：先有开放的上涨，再出现局部空头 A

`2024-05-01`–`2024-07-10` 大体是从约 `85` 向 `111` 推进的上涨背景。到 `2024-07-10` 高点约 `111.03`、`07-11` 高点约 `111.08` 后，价格出现明显转弱；这比 DIS 的父级区间背景更清楚，初步可以按开放上涨后的空头反转/延续候选观察。

这里仍不把 `07-11` 一根大阴线自动当作完整 A。A 的方向性要看后续是否有持续接受：`07-17` 开盘约 `100.18`，相对 `07-16` 收盘约 `105.77` 明显跳低，收盘约 `95.13`；`07-18`、`07-19` 又分别收在约 `93.64`、`90.15`。因此更稳妥的局部 A 是 `07-10/11` 高点到 `07-19` 低点，而不是只取一根反转 K。

## 3. A 腿：强方向、低重叠、缺口强化

从 `2024-07-10/11` 高点约 `111.08` 到 `2024-07-19` 低点约 `90.00`，可见的 A 腿有几项支持：

- `07-11` 先出现大范围反转 K，随后没有迅速收复高位；
- `07-17` 出现明显向下跳空，开盘接受后继续收在低位；
- `07-17`–`07-19` 连续更低低点，K 线重叠较少；
- `SOXX` 同期从约 `258.63` 降到 `233.59`，`SMH` 从约 `271.66` 降到 `246.28`，板块方向与 LRCX 一致。

视觉层可标为 `strong-looking-A / gap-impulse-A`。它不是无缺口普通 A，但“强 A 让我们优先寻找 L1”这一逻辑在这里比 DIS 更清楚。

## 4. B 腿：短、深度有限，后段转弱

`2024-07-19` 低点约 `90.00` 后，`07-22` 反弹到约 `96.46`，`07-23` 高点约 `96.07` 但收盘回到约 `94.34`。这段 B 有以下特征：

- 没有回到 A 起点 `111.08`，也没有覆盖整个空头 A；
- 反弹持续时间短，幅度相对 A 约 `30%`，不属于深反向趋势；
- `07-22` 虽然反弹很强，但 `07-23` 没有继续接受更高价格，收盘转弱；
- 这更接近 `controlled-B-conditional`，而不是 DIS 那种连续三日强反弹的深 B。

因此，`07-23` 的低点约 `93.98` 下方可以先画成第一次空头恢复，即 `L1-like`。不能把 `07-24/25` 连续下跌事后再数成 L2；它们更像 L1 触发后的跟随。

## 5. L1 信号与订单分支

### 分支 A：原始 sell-stop

- `07-23` 低点约 `93.98` 下方挂 sell-stop；
- `07-24` 开盘约 `93.39`，已经低于原触发价；
- 15m 第一根约 `09:45` 的范围约 `92.19–93.61`，说明价格从开盘就处在触发位下方；
- 原始订单不能按 `93.98` 精确成交。若不允许开盘重订，应该记为 `original-stop-not-filled / skipped`。

### 分支 B：开盘接受 / gap-reprice

如果事先明确允许“开盘低于触发就按可接受的开盘价重新签订合同”，研究成交应按约 `93.39`，而不是沿用 `93.98`。这是一条独立分支，不能和理想价分支合并。

### 分支 C：sell-limit 等待回测

若在 `93.98` 附近等待反弹回测，`07-24` 当日高点约 `93.61`，没有回到原触发位，因此该 limit/retest 分支没有成交。后面继续下跌不能证明它本来会成交。

### 分支 D：低周期确认

`07-24` 15m 开盘即向下，之后到 `10:15` 附近低点已到约 `91.56`，到日内后段又接近 `89.34`。等低周期确认虽然能减少“只因开盘跳过而追入”的歧义，但成交已经更低，且第一支撑更近；不能把它当作原始 L1 的同一合同。

## 6. 结构止损、第一支撑与粗略空间

### 结构止损

B 的高点区约为 `96.46–96.07`。研究止损应放在该 B 结构上方并留缓冲，可先观察 `96.9–97.2` 上方；不能用 `07-24` 盘中小高点压窄成另一种未经声明的 thesis。

### 第一独立支撑

触发前已经可见的近端支撑先分层看：

- `07-19` A 末端低点约 `90.00`；
- 更早的 `05-17` 低点约 `88.88`、`05-31` 低点约 `88.62`、`05-14` 低点约 `87.97`，可合并为下一层 `87.97–88.88` 支撑簇。

因此不能直接把 `08-02` 的约 `74.51` 或远端 MM 当作第一目标。`07-24` 当天低点约 `89.34` 已经触碰/略破 `90.00` 第一层，说明入场后很快就要面对首障碍。

这是一段比 DIS 更值得深入的形态，但实际执行分支并没有形成宽裕首段空间：原价分支没有成交，开盘接受分支到第一支撑只有边界级别，低周期晚确认又把空间进一步压缩。因此最终仍记为 `valid_no_trade / first-support-borderline`，而不是无条件正例。

## 7. Measured Move：目标清楚，但不能越过近端支撑

用局部 A 的粗略高度：

```text
A 高度 ≈ 111.08 - 90.00 = 21.08
B 高点向下投影 ≈ 96.46 - 21.08 = 75.38
```

`75.38` 与 `08-02` 附近约 `74.51` 的后续价格接近，说明这个 MM 作为事后过程目标有参考价值；但在 `07-24` 触发时，`90.00` 和 `88.88–87.97` 早已是左侧支撑，MM 必须放在第二层目标，不能直接决定入场。

## 8. 板块与事件过滤

## 10. 可复用结论

1. **这是比 DIS 更好的视觉候选，但视觉质量与成交质量仍是两层。** 父级、A、B 和板块都比 DIS 清楚，仍不能替原始 stop 制造成交。
2. **开盘小幅跳过也要重算。** 只要开盘已经低于 sell-stop，就不能按理想触发价统计；开盘接受是另一份合同。
3. **第一支撑可以在同一根触发日被触及。** 即使远端 MM 很漂亮，若首层支撑已经在入场后的第一天出现，首段空间仍应单独审计。
4. **短 B 不自动等于浅而优质。** 这里的 B 时间短、后段转弱，因此可保留为受控 B 候选；但开盘订单和首支撑仍足以否决交易。
5. **L1 后的连续下跌不自动增加 L2。** 没有新的反向 B 和第二次独立测试时，`07-25` 只是 L1 跟随。
6. **板块顺势只是 META 加分项。** SOXX/SMH 同向提高候选优先级，却不能取消订单重订和首障碍边界。

本案例保留为 LRCX 空头 `strong-A / controlled-B-conditional / L1-gap-reprice / first-support-borderline` 对照，不进入 Codex Trading 生产规则，也不交给 Execution Agent。
