# 趋势后段入场 / 追价过滤视觉证据审计

日期：`2026-08-24`  
状态：`visual-research / cross-pattern / provisional / not-statistical`

## 审计目的

后段过滤不是预测趋势何时结束，而是审计新增仓位的时机和空间。必须把“后来继续上涨/下跌”与“当时值得追”分开：

```text
背景与左侧 → 当前阶段 → 位置/首障碍 → 回调或接受证据
→ 订单与结构止损 → 实际成交/路径 R/R → 追、等、改合同或观望
```

## 当前工作合同

### C1：趋势强度不等于追价许可

强 A、连续大 K、跳空和收盘靠极值是方向压力证据，但同样可能意味着趋势已经靠近主要磁铁或进入高潮。只有在位置、空间和订单合同同时可接受时，才保留新增仓位。

### C2：后段仍可有受控回调

“后段”不是自动否决。若回调短而受控、卖方没有连续跟随、价格回到结构位，并出现高质量 H1/H2 或 L1/L2，保留 `late-but-controlled-pullback`；但要按当前价格重新计算首障碍和 R/R。

### C3：突破接受必须重建合同

阻力下观望与阻力上 BOP 是两个市场状态。强收盘越过、跟随、回测守住后，旧的反转/观望假设失效，创建新的 BOP/回踩合同；不能用后来的延伸证明原本阻力下就应该追。

### C4：目标/高潮处优先管理而非新增追单

进入主要高低点、MM、通道边界或连续扩张后，实体变小、重叠增加、跟随失败和长影线支持分批减仓/观望。已有仓位的管理不能被误写成新仓入场。

### C5：订单和路径不能被后见之明修正

跳空越过触发价、开盘接受或低周期重订都要记录实际成交分支。高周期结构止损、低周期短线止损、首障碍和真实 R/R 分开；若结构止损先失效，保留 `path-invalidated-before-target`。

## 四类最低证据

### 1. 早期或中段的可做回调

KLAC `2025-05-07`–`2025-06-03` 的 H2 研究提供了较早的结构位、EMA 和支撑汇合；它不是无条件正例，但说明在价格尚未贴近远端目标时，回调后的第二次入场比趋势末端追价更容易冻结订单、结构止损和首障碍。它还提醒：回调缩量是重要参考，不是必要条件。

### 2. 后段形态像但空间不足

TSLA `2025-08`、NFLX 和 VRT 都说明：形态清楚、趋势方向正确，仍可能因为首障碍太近而 `valid_no_trade`。不能用后续 MM、后来的最高/最低或窄低周期止损拯救高周期交易。

### 3. 突破接受后应重建合同

TSLA `2025-09` 的 `2025-09-08`–`2025-09-10` 仍是阻力测试；`2025-09-11` 才出现强收盘、15m 跟随和回测守住。此后可以研究 BOP 或回踩，但这不是对原来阻力下追价的补证。

### 4. 高潮/成熟通道不追

COIN 和 XOM 覆盖跳空、范围扩张、第三推变强和首支撑拥挤；NFLX 覆盖高位多次测试与近端支撑。它们的共同结论是：当价格已经进入后段，新增交易的第一任务是保护路径 R/R，而不是为趋势延续找一个漂亮标签。

## 当前结论

目前最稳的可迁移语言是：

1. 强趋势可以继续，但越靠近主要障碍，新增仓位越需要新的空间和接受证据；
2. 优先等回调/二次入场，回调后要重新判断压力是否收缩；
3. 单根大 K 不足以授权追价；突破接受后的追入属于新 BOP 合同；
4. 低周期可以优化时序，不能消除高周期首障碍或把父级止损变成不存在；
5. 目标/高潮附近可以分批管理已有仓位，不能把管理动作当成新仓正例；
6. 跳空、财报、板块和市场背景先改变订单与风险，再谈形态；
7. 后续结果不能升级当时的 `valid_no_trade`，也不能把路径先失效改写为成功。

本层仍为 `provisional`，不产生胜率、不进入 Codex Trading，不连接 Execution Agent。只有出现事件干净、首障碍宽裕、回调/接受证据和完整成交路径都能重建的新案例，才继续增加样本。
