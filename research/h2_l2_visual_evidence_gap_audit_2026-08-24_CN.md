# H2/L2 第二次入场视觉证据缺口审计（2026-08-24）

日期：2026-08-24  
状态：`visual-research / conditional / not-statistical`

## 1. 本轮问题

本轮只审计 `H2/L2`：同一回调 lineage 中，第一次方向尝试没有被接受，第二次在更有意义的位置重新测试，并出现可以被订单确认的信号。重点不是再找一张“像 H2/L2”的图，而是回答四个更实际的问题：

1. 第一次尝试是否真的失败或没有跟随，而不是事后把第二根 K 线编号为 H2/L2；
2. 第二次尝试是否发生在支撑/阻力、EMA、角色转换或前高前低等位置；
3. 触发、结构止损、第一独立障碍和粗略 R/R 是否属于同一个交易合同；
4. 形态成立、日线可交易和低周期管理合同是否必须分开。

本文件是视觉研究和证据管理，不是胜率统计，也不把 H2/L2 变成量化扫描条件。

## 2. 统一审计顺序

```text
完整背景 → 父级趋势/区间状态 → A 腿方向性
→ B 回调的同一 lineage 与后段压力 → 第一次尝试是否失败
→ 第二次位置测试 → 信号 K → 订单合同
→ 结构止损 → 第一独立障碍 → 路径 R/R → 事件过滤
```

每一个字段都只使用触发时可见的信息。后续达到 MM、先到支撑或最终盈利，只用于路径审计，不得倒灌成入场时证据。

### 2.1 H2/L2 的最小定义

- **H2**：上涨背景或支撑反应中，同一回调里的第一次多头尝试失败/无跟随，之后第二次有意义的多头尝试在结构位置出现，并由信号 K 和 buy-stop 或明确收盘确认触发。
- **L2**：下跌背景或阻力反应中，同一回调里的第一次空头尝试失败/无跟随，之后第二次有意义的空头尝试在结构位置出现，并由信号 K 和 sell-stop 或明确收盘确认触发。
- “第二次”不是第二根阳线/阴线，也不是任意局部突破；若出现新趋势极值、回调已经被接受为反向趋势、或父级进入交易区间，旧计数必须重置。
- 第三次及以后属于 H3/L3、三推或 MTR 研究，不在本文件中无限延长计数。

### 2.2 可交易性分级

| 标签 | 含义 |
| --- | --- |
| `pattern_like` | 视觉上接近 H2/L2，但至少有一个关键字段没有锁定 |
| `research_positive_conditional` | 结构、触发、风险和空间都能形成条件性合同，但有事件、深 B、低周期或其他限制 |
| `valid_no_trade` | 形态可识别，但首障碍、事件、跳空、结构止损或父级状态否决交易 |
| `process-stop-first` | 静态目标看起来有空间，但真实路径先触发结构失效，不能称为正向交易样本 |
| `no-new-positive` | 本轮没有发现符合指定缺口的更干净正例；不是说形态不存在 |

## 3. 多头 H2 对照

### 3.1 KLAC：位置最清楚，但日线首障碍并不宽

来源：[`KLAC 多头 H2 案例`](klac_h2_case_study_2025-05-07_2025-06-03.md)。

- `2025-05-07`–`2025-05-14` 是方向性较清楚的上涨 A 腿；后续没有把 5 月 23 日的第一次反应直接当成成功延续。
- `2025-05-23` 在 EMA20/左侧支撑附近出现第一次多头尝试，但没有形成持续扩张；`2025-05-30` 再次下探，`2025-06-02` 收回并站稳 EMA20，第二次测试更有意义。
- 订单应写成：以 `2025-06-02` 信号 K 高点上方的 buy-stop，`2025-06-03` 的 15m 突破是确认；不能把信号日收盘和低周期成交混成一个时点。
- 结构止损研究在约 `72`，而不是只放在信号 K 低点下方；这样能容纳重复支撑的正常测试，但也扩大风险。
- 触发附近第一独立阻力先看 `79.03–79.79`；以约 `75.90` 触发、`72` 止损估算，第一障碍约 `0.8R–1.0R`，`87` 左右的 MM 只能作为延伸目标，不能用来掩盖首障碍狭窄。

**结论：** `research_positive_conditional`。它是目前最适合说明“支撑簇 + 深一点的第二次测试 + EMA + 信号确认”的多头 H2 案例，但不是宽空间的日线基准。若采用低周期管理，必须另写低周期合同。

### 3.2 CRWD：深 B 只有后段稳定后才恢复 H2 资格

来源：[`CRWD 多头 H2 深 B 案例`](crwd_bullish_h2_deep_b_late_stabilization_2024-09-11_2024-10-11.md)。

- `2024-09-11`–`2024-09-20` 的 A 腿有足够方向性，但包含跳空/加速，因此不能把它当作完全普通的趋势样本。
- `2024-09-23`–`2024-10-01` 的 B 前段卖压并不弱；只有在 `68.17` 附近出现后段稳定后，才保留第二次多头恢复的 H2-like 解释。
- `2024-10-02` 的恢复与 `2024-10-03` 的 15m buy-stop/收盘确认要分开记录；低周期确认不能倒灌成日线入场已经确定。
- 结构止损研究约 `67.4–67.8`；第一阻力 `75.11–75.54`，粗略约 `1.5R–1.9R`，仍不是非常宽裕的空间。
- 财报前三个交易日过滤通过，但 incident context 仍需单列，不能伪装成普通无事件基准。

**结论：** `research_positive_conditional / incident-context-pending`。本案例新增的是“深 B 可以保留，但必须看到后段稳定”的分支，不是“深 B 也和浅 B 一样强”。

### 3.3 TSLA：结构成立不等于日线值得追入

来源：[`TSLA 多头 H2 案例`](tsla_abc_h1_h2_case_study_2025-08-06_2025-08-22.md)。

- `2025-08-06`–`2025-08-12/13` 是多头 A 腿；`2025-08-13`–`2025-08-21` 的 B 前段卖压较强，但后段在 `314.60–320.11` 支撑与 EMA20/50 附近稳定。
- `2025-08-18` 的第一次尝试没有被接受；`2025-08-22` 的强收多头 K 是第二次位置测试后的 H2-like 信号。
- 日线若以 `340.25` 上方 buy-stop、完整结构止损约 `314.60`，最近阻力 `340.25–340.55` 过近，直接日线合同应 `no-trade`。
- 15m 若以 `326.64` 上方触发、`318.68` 下方低周期止损，第一阻力约 `340.55`，可得到约 `1.7R` 的短线合同；但这不是同一个日线结构止损合同。
- 财报过滤通过，板块/市场方向也较配合；主要否决来自日线空间和合同层级，而不是 H2 形态本身。

**结论：** `research_positive_conditional / daily-no-trade / low-cycle-contract-separate`。这是必须保留的边界：低周期可以有可管理的短线合同，不代表日线直接追入也合格。

### 3.4 NVDA 与 AMZN：支持同一条规则，但没有填补纯净基准缺口

- `NVDA 2024-09-24`：第一次尝试失败、第二次在支撑处恢复，60m/15m 触发约 `1.9R`，但宽结构止损约 `0.9R`，且事件检查未完成；说明窄止损合同与高周期合同不能合并。
- `AMZN 2024-12-11`：强背景、浅而受控的 B，H2-like 视觉清楚；但首障碍仍未证明宽裕，事件上下文也未完全关闭。

二者都支持“先锁合同，再讨论 R/R”，但没有提供一个事件干净、父级开放、首障碍明显宽裕的普通多头 H2 基准。

## 4. 空头 L2 对照

### 4.1 TSLA 2024-03：无事件、静态空间正，但过程先止损

来源：[`TSLA 空头 ABC/L2 案例`](tsla_bearish_abc_case_2024-03-04_2024-03-14.md)。

- `2024-03-04`–`2024-03-06` 是三根连续强空头 K 组成的方向性 A 腿。
- `2024-03-07`–`2024-03-11` 是向上 B；`2024-03-12` 跌破前低，第一次 L1 失败/恢复；`2024-03-13` 再次跌破并收在低位，L2 的计数和低周期跟随都比 L1 清楚。
- 结构止损约在 B 高点 `182.87` 上方；左侧第一支撑约 `152.37–153.75`，静态几何约 `1.6R–1.9R`，MM 约 `153.93` 也落在同一支撑簇附近。
- 但实际路径在第一支撑到达前先回升并于 `2024-03-26` 左右突破结构止损。不能因为静态目标有空间，就把它记录为成功的 L2 交易。
- 这段更接近区间上沿/局部反转边缘，而不是父级开放空头趋势中部的普通 L2；没有财报事件并不等于父级状态合格。

**结论：** `pattern_like / process-stop-first / range-edge-boundary`。它是很有价值的空头反例：L2 计数可以清楚，静态 R/R 可以漂亮，但交易路径仍可能先失效。

### 4.2 TSLA 2024-07：几何不错，但财报驱动不能当普通基准

来源：[`TSLA 空头 ABC/L2 案例`](tsla_bearish_abc_case_2024-07-11_2024-08-05.md)。

- `2024-07-11` 的强空头冲量提供 A 腿；随后在 `233–235` 阻力附近出现两次反应，`2024-07-30` 可作 L1，`2024-08-01` 的再次跌破更像 L2。
- 以 B 高点上方结构止损、下方 `195` 与 `183–185` 分层目标，L2 的几何约约 `1.5R`；MM 约 `183.79` 与更强支撑重叠。
- `2024-07-24` 财报缺口改变了波动与成交语义，所以不能把它和无事件开放趋势 L2 混为一类。

**结论：** `research_positive_conditional / event-driven`。它证明 L2 可以在阻力簇和强空头压力后提供交易合同，但不填补“无事件、开放趋势”的空头基准缺口。

### 4.3 ANET、QCOM、UBER：形态边界比正例更有信息

- ANET 的 L2-like 受事件上下文和首障碍限制；保留为 `valid_no_trade / event-context-pending`。
- QCOM 的 L2-like 受财报/跳空和板块边界限制，不能把 gap 后走势倒灌为普通 L2。
- UBER 的 L2-like 虽然计数可讨论，但第一支撑约只有 `0.2R–0.3R`，正确输出是 `valid_no_trade`。

这些案例共同说明：空头 L2 目前可以审计失败、事件和空间边界，但尚未找到一张同时满足“事件干净、父级开放、第二次尝试清楚、首支撑宽裕”的纯净正例。

## 5. 跨案例发现

### 5.1 H2/L2 是失败信息，不是计数装饰

第一次尝试必须留下可观察的失败或无跟随。若第一次尝试只是连续 K 线中的一个小波动，不能为了得到 H2/L2 而强行计数。第二次必须发生在新的位置测试或重复压力之后，否则只是同一段冲量的延续。

### 5.2 视觉质量与交易可行性必须分栏

`KLAC` 的形态清楚但首阻力近，`TSLA 2025-08` 的低周期合同可行但日线合同不行，`TSLA 2024-03` 静态空间好但过程先止损。三者都不能用一个“成功/失败”标签压平。

### 5.3 高周期结构止损和低周期管理止损是不同合同

低周期确认可以改善入场时序，但只有在明确改变持仓周期、止损、目标和失效条件时，才算独立合同。低周期窄止损不能美化高周期日线 R/R。

### 5.4 第一独立障碍优先于 MM

MM、AB=CD 和延伸目标只能在首个主要支撑/阻力被接受后继续使用。若第一障碍只有约 `0.2R–1.0R`，形态再漂亮也应优先 `no-trade` 或降低合同级别；不能用远端 MM 覆盖近端结构。

### 5.5 静态 R/R 不等于路径 R/R

入场时看起来到远端支撑有 `1.6R–1.9R`，不代表价格会先到那里。若价格在第一目标前先破坏结构止损，标签应是 `process-stop-first`，而不是正向样本。TSLA 2024-03 是这一点的明确反例。

### 5.6 深 B 的处理是“后段稳定”，不是“深度越大越好”

深 B 前段仍有强反向压力时，H1 应降级；只有在后段停止扩张、支撑/阻力重新被拒绝后，H2/L2 才重新获得条件性资格。深度本身不是 META 优势，稳定位置和空间才是。

### 5.7 事件过滤是前置条件，不是事后注释

财报前三个交易日不建立新合同。事件后缺口、波动和成交量必须单列；事件型案例可以帮助研究订单分支，但不能代表普通趋势基准。

## 6. 本轮结论

| 方向 | 状态 | 结论 |
| --- | --- | --- |
| H2 | `conditional / provisional` | 多头视觉定义和合同分支已经足够继续使用；KLAC 是位置主案例，CRWD 是深 B 后段稳定分支，TSLA/NVDA 说明日线与低周期合同必须分离。仍没有新的事件干净、开放趋势、首障碍宽裕的普通基准。 |
| L2 | `conditional / provisional / no-new-positive` | 计数和失败语义已有多个案例；TSLA 2024-03 是无事件但区间边缘且过程先止损的反例，TSLA 2024-07 是事件驱动的条件例。仍缺事件干净、父级开放、首障碍宽裕的对称正例。 |

因此，本轮不冻结 H2/L2 为生产规则，也不再为了“对称”把边界案例升级成正例。下一步只在出现新信息时继续深审：

- 空头开放趋势中的无事件 L2；
- 多头开放趋势中首障碍明显宽裕的 H2；
- 同一案例内 stop、收盘确认、limit-retest 和低周期合同的真实分支；
- H2/L2 与区间边缘、MTR、三推之间的状态切换。
