# ABC / H1-H2 / L1-L2 视觉研究阶段性综合

日期：2026-08-23  
状态：`visual research synthesis / not production`

## 这份摘要解决什么问题

PA Research 当前要培养的是一个能看懂完整 PA 图表的助手，而不是量化扫描器。助手的第一项工作是从完整图表中筛出“看起来像”的 ABC、H1/H2、L1/L2 或 H3/L3 候选；第二项工作才是优化位置、订单、结构止损、第一障碍和止盈路径。

所以，`pattern_like` 是有效的第一阶段结论。它表示视觉结构值得继续研究，不表示胜率、成交或自动交易授权。

第一阶段和第二阶段的字段、状态和退出条件见[`PA Pattern 视觉筛选协议`](visual_pattern_triage_protocol_CN.md)。后续新增案例先按该协议做视觉分层，不因第一轮尚未精确计算 R/R 就丢弃候选。

## 目前相对稳定的视觉共性

### 1. 背景先于标签

先判断左侧是开放趋势、成熟交易区间、区间边缘还是过渡/高潮，再数 H/L。区间中部的小波动不能因为出现两次高点或低点就强行变成 ABC；区间边缘的反应应另按区间逻辑记录。

### 2. A 腿决定先看 H1/L1 还是等待 H2/L2

- 强 A：方向性收盘、重叠较少、连续推进和跟随清楚。B 到达有意义的位置并且压力收缩时，H1/L1 值得优先评估。
- 普通 A：重叠多、宽通道、推进不干脆或大背景不清楚。H1/L1 先作为观察，通常等待第一次尝试失败/没有跟随后再看 H2/L2。
- 这是筛选优先级，不是概率承诺；前方障碍、信号 K 和风险几何仍可否决交易。

### 3. B 腿不能只用“深/浅”判断

真正要看的是压力如何变化：

- 前段有回撤、后段逐渐缩小并在关键位置拒绝：可以标为受控 B；
- 前段反向压力明显、后段在支撑/阻力处收缩：标为深但后段受控 B，H1/L1 降级，H2/L2 仍可研究；
- 反向推进持续扩张、关键结构被接受性突破或已形成新趋势：标为未受控 B，不用 H2/L2 标签挽救。

### 3A. A 腿终点也必须经过稳定性检查

视觉上先画出的 A 腿终点，不一定是决策时可以冻结的终点。如果后续在同一回调上下文中出现更低的低点，至少要保留“旧锚点/较晚锚点”两种画法，并重新检查 B、MM 和第一支撑。不能因为某一组锚点事后更接近目标，就把它提升为唯一正确答案。

TSLA `2026-02-11`–`2026-03-20` 是当前边界：`03-03` 低点约 `385.39` 后，`03-09` 又下探到约 `381.40`。它仍然像空头 ABC，且 `03-13` L1、`03-18` L2 有真实低周期触发，但 A/B 被降级为锚点待定；这正是视觉助手应输出的优化结果。

### 4. 计数是局部描述，不是信号本身

同一个周期、同一个回调上下文中，才继续数 H1/H2/H3 或 L1/L2/L3。新的趋势极值、回调转成交易区间或结构发生改变时要重新评估。设置/计数 K 和确认/触发 K 分开记录。

H3/L3 可以作为第三次尝试的视觉入口，但不等于三推楔形，也不等于反转。第三次尝试仍然强并有跟随时，可能只是趋势延续。

### 5. 形态质量和交易可行性分开

形态很像，但触发价上方/下方的第一独立阻力或支撑太近，仍应输出 `valid_no_trade`。反过来，形态只是 B 级候选，但位置、订单和空间更合理，也值得继续审计。不能用 MM、AB=CD、EMA 或后续盈利覆盖近端障碍。

## 当前研究状态

| 能力 | 当前状态 | 现阶段可以做什么 | 还不能声称什么 |
| --- | --- | --- | --- |
| 完整图表视觉筛选 | 可用的研究能力 | 找出 pattern-like 候选，描述趋势/区间/位置 | 不能声称自动识别全部形态 |
| A/B/C 与 H/L 计数 | 工作假设较清楚 | 按同周期、同回调记录局部结构 | 不能声称固定阈值已经验证 |
| H1/L1 与 H2/L2 优先级 | 跨案例有重复支持 | 强 A 优先看第一次，普通 A 等第二次 | 不能直接等同于高胜率 |
| H3/L3 | 有视觉对照和边界 | 记录第三次尝试、衰竭或延续候选 | 不能冻结成三推反转规则 |
| 订单分支 | 已形成研究协议 | 区分 stop、limit-retest、market-close、观望 | 不能交给执行 Agent |
| 止损与第一障碍 | 可做粗略结构审计 | 找失效区、近端支撑/阻力、粗略 R/R | 不能用固定数字替代结构判断 |
| 胜率/量化回测 | 尚未建立 | 只保留案例、反例和未决边界 | 不能报告已验证胜率 |

## 代表性证据如何使用

- [`TSLA 2025-03-04 284 回测`](tsla_abc_playbook_2025-03-04_284_retest.md)：说明跳空会切换订单状态，回测 limit 是独立分支。
- [`TSLA 2024-03-04–03-14`](tsla_bearish_abc_case_2024-03-04_2024-03-14.md)：无事件区间边缘 L2 的空间基准。
- [`KLAC 2025-06-02/03`](klac_h2_case_study_2025-05-07_2025-06-03.md)：视觉 H2 质量高，但第一阻力仍可能过近。
- [`KLAC 2025-03-24/26`](klac_h3_bear_flag_case_2025-03-12_2025-03-28.md)：目前最接近正向研究基准的 H3/L3 候选；第三次上探后，`2025-03-26` 首根 15m K 线无跳空跌破，SOXX 同步走弱，且 `2025-04-30` 财报日期不在触发前三个交易日内。它仍只能证明“值得深入”，不能证明 H3 是高胜率规则。
- [`TSLA 2025-08-06/22`](tsla_abc_h1_h2_case_study_2025-08-06_2025-08-22.md)：深但后段受控 B 后出现强 H2；`10:15` 15m 从 `325.75` 上穿 `326.64`，没有从开盘直接跳过触发。若接受低周期 `318.68` 下方止损，入场前第一主要阻力 `340.55` 约 `1.7R`；若使用 `313.5–314` 的日线结构止损，则不足 `1R`。因此是 `research_positive_conditional`，不是无条件波段正例。
- [`SNOW 2026-08-14/17/21`](snow_bullish_h2_first_obstacle_boundary_2026-08-14_2026-08-21.md)：形态像、信号强，但首障碍拥挤，说明观望本身是结果。
- [`COST 2024-07-11/18`](cost_bearish_abc_climax_boundary_2024-07-11_2024-07-18.md)：上涨末端剧烈反转形成强 A，浅 B 后出现 L1-like 下破，但支撑簇贴近触发；说明“强 A + 清楚触发”仍可能是 valid no-trade。
- [`LLY 2024-06-06/13`](lly_bullish_abc_h1_h2_first_obstacle_boundary_2024-06-06_2024-06-13.md)：上涨背景中的恢复看起来像 H1/H2，但 B 含大范围反向冲击，信号 K 不够优质，触发上方首阻力只有约 `0.5R–0.6R`；说明“恢复跟随 + 低周期强度”仍不能替代 B 质量、信号 K 和第一障碍审计。
- [`BKNG 2024-06-12/18`](bkng_bullish_h2_gap_trigger_boundary_2024-06-12_2024-06-18.md)：A 方向明确、B 浅且受控、信号 K 质量较好，但 `06-17` 跳空越过原 buy stop，实际成交后首阻力贴近；说明形态质量可以为正，而原始订单仍必须重算或跳过。
- [`XOM 2024-07-18–08-02`](xom_bearish_h3_flag_expansion_boundary_2024-07-18_2024-08-02.md)：空头 A 后三次上探，第三次更高且范围扩张；`08-01` 有 L1-like 空头反应，但 `08-02` 跳空重订成交、首支撑约 `0.7R`，因此保留为 C 类扩张边界和 valid no-trade。
- [`WMT 2024-06-24–06-27`](wmt_bullish_h1_gap_pullback_boundary_2024-06-24_2024-06-27.md)：上涨背景中一次深 gap pullback 后强收回，视觉上像 H1-like；但结构止损下第一阻力只有约 `1R`，且信号 K 不够优质，因此保留为多头边界而非正例。
- [`RBLX 2024-03-18–04-05`](rblx_range_edge_not_abc_boundary_2024-03-18_2024-04-05.md)：局部可画出 A/B/C，但 B 回到 A 起点和父级区间下沿；`04-04` 盘中冲高后收盘很差，后续 `04-05` 恢复不能倒灌为趋势 H1。它把“区间边缘反应”和“趋势 ABC 延续”明确分开。
- [`GOOGL 2024-03-04–03-22`](googl_bullish_h1_gap_trigger_boundary_2024-03-04_2024-03-22.md)：强 A 后浅 B 的 H1-like 外形存在，但 `03-18` 跳空从约 `141.92` 直接开到约 `147.30`，原 buy stop、结构止损和首障碍几何都必须重算；limit-retest 未成交，后续上涨不能倒灌。
- [`HD 2024-07-01–07-31`](hd_bullish_h1_ema200_sector_boundary_2024-07-01_2024-07-31.md)：深 B 到达 `332.3–333.6` 左侧支撑后出现 H1-like 多头尝试；但 `07-25` 信号 K 收盘质量一般，EMA200 几乎贴着触发价，且 XLY/SPY 同期转弱。它说明“支撑反应 + 形态像”仍可能是 `valid_no_trade`，动态障碍和板块许可必须放在 MM 之前。
- [`QCOM 2024-07-17–07-30`](qcom_bearish_abc_l1_l2_gap_sector_boundary_2024-07-17_2024-07-30.md)：空头 A 与 SOXX 同向，L1/L2-like 都能看见；但 L1 跳空把理想 `1.37R` 压成约 `0.48R`，L2 第一支撑约 `0.87R` 且进入财报前 3 天。它把“强 A、板块顺势、第二次机会”仍不能越过订单与事件过滤记录下来。
- [`UBER 2024-07-17–07-26`](uber_bearish_h3_l2_first_support_boundary_2024-07-17_2024-07-26.md)：三次上探后又出现更高、更宽的扩张，H3 计数必须降级；`07-26` 低周期没有从开盘跳过原触发，但左侧第一支撑只有约 `0.2–0.3R`。它是计数复杂与首障碍过滤的独立边界。
- [`AAPL 2024-05-03–05-09`](aapl_bullish_h1_event_driven_a_2024-05-03_2024-05-09.md)：财报后跳空带来方向性局部 A，浅 B 在 `178.47–179.49` 附近收缩，`05-08` 小实体/长下影后由 `05-09` 15m 从触发价下方上穿确认；`184.98` 首阻力只给约 `1.1R–1.4R`，而且 A 是事件驱动，所以是条件正向样本，不是普通趋势 H1 的纯净正例。
- [`NVDA 2025-06-23–07-03`](nvda_bullish_abc_h1_visual_candidate_2025-06-23_2025-07-03.md)：普通上涨背景中的强方向腿、短但偏深的 B，以及 `07-02/03` 的 H1-like 恢复；当前只作为第一阶段视觉候选，A 锚点、H1/H2 计数、事件/板块和低周期订单尚未优化。
- [`LOW 2024-06-11–06-24`](low_bullish_h1_h2_first_obstacle_boundary_2024-06-11_2024-06-24.md)：急跌后的方向性 A、回调和 H1/H2-like 恢复都能从完整图表中看见，但父级仍是过渡，Daily 信号 K 与计数不够干净，且 `221.92–223.01` 的前高簇贴近触发；它是“像 ABC/H1-H2、但不做”的视觉边界。
- [`ASML 2025-05-23–06-13`](asml_h3_l3_range_transition_boundary_2025-05-19_2025-06-13.md)：三段修正标签不等于视觉三推，区间过渡必须单独识别。
- [`TSLA 2026-02-11–03-20`](tsla_bearish_abc_anchor_ambiguity_l1_l2_2026-02-11_2026-03-20.md)：空头 A/B/C 和 L1/L2 外形存在，但 `03-09` 下破旧 A 低点使锚点不稳定；L1/L2 的真实触发不能抵消第一支撑过近，保留为 `pattern_like / valid_no_trade` 边界。

这些案例不能当作彼此独立的胜率样本；同一父级趋势中的多个触发点要保留 lineage。

## 助手每次筛图的最低输出

```text
1. 左侧背景：趋势 / 区间 / 过渡 / 高潮
2. pattern-like 类型：ABC、H1/H2/H3、L1/L2/L3 或其他
3. A 腿质量：强 / 普通 / 不清楚
4. B 腿压力：受控 / 深但后段受控 / 未受控 / 不清楚
5. 位置：主要支撑阻力、区间边缘、EMA、缺口、META 汇聚
6. 当时可见的信号 K 与触发
7. 订单分支：stop / limit-retest / market-close / observation-only
8. 结构止损与失效条件
9. 第一独立障碍、粗略空间和可能的止盈区
10. 仍不确定什么，以及是否值得补 4H/60m/15m
```

价格和日期允许先用区域或近似值；不能近似的是因果时点、订单语义、结构失效和是否使用了后见之明。

### 普通 A 腿筛选的最新对照

`MSFT`、`AMZN`、`META`、`NFLX`、`CAT` 的人工窗口都呈现出“普通强 A → B → H1/H2-like 恢复”的外形，但触发附近已有前高/主要阻力，首障碍没有足够空间。它们被保留为 `pattern_like / valid_no_trade`，而事件状态仍单独标记为待核验；普通 A 的初步形态本身不自动等于交易质量更高。详情见 [`ordinary_a_visual_screen_2024-05_2024-07_CN.md`](ordinary_a_visual_screen_2024-05_2024-07_CN.md)。下一轮应优先寻找 B 结束后仍明显低于 A 高点、而不是已经贴近前高的窗口。
