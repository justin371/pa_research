# ABC / H1-H2 / L1-L2 视觉研究阶段性综合

日期：2026-08-23  
状态：`visual research synthesis / not production`

## 这份摘要解决什么问题

PA Research 当前要培养的是一个能看懂完整 PA 图表的助手，而不是量化扫描器。助手的第一项工作是从完整图表中筛出“看起来像”的 ABC、H1/H2、L1/L2 或 H3/L3 候选；第二项工作才是优化位置、订单、结构止损、第一障碍和止盈路径。

所以，`pattern_like` 是有效的第一阶段结论。它表示视觉结构值得继续研究，不表示胜率、成交或自动交易授权。

第一阶段和第二阶段的字段、状态和退出条件见[`PA Pattern 视觉筛选协议`](visual_pattern_triage_protocol_CN.md)。后续新增案例先按该协议做视觉分层，不因第一轮尚未精确计算 R/R 就丢弃候选。

## 目前相对稳定的视觉共性

### 1. 背景先于标签

先判断左侧是开放趋势、成熟交易区间、区间边缘还是过渡/高潮，再数 H/L。区间中部的小波动不能因为出现两次高点或低点就强行变成 ABC；区间边缘的反应应另按区间逻辑记录。

### 2. A 腿决定先看 H1/L1 还是等待 H2/L2

- 强 A：方向性收盘、重叠较少、连续推进和跟随清楚。B 到达有意义的位置并且压力收缩时，H1/L1 值得优先评估。
- 普通 A：重叠多、宽通道、推进不干脆或大背景不清楚。H1/L1 先作为观察，通常等待第一次尝试失败/没有跟随后再看 H2/L2。
- 这是筛选优先级，不是概率承诺；前方障碍、信号 K 和风险几何仍可否决交易。

### 3. B 腿不能只用“深/浅”判断

真正要看的是压力如何变化：

- 前段有回撤、后段逐渐缩小并在关键位置拒绝：可以标为受控 B；
- 前段反向压力明显、后段在支撑/阻力处收缩：标为深但后段受控 B，H1/L1 降级，H2/L2 仍可研究；
- 反向推进持续扩张、关键结构被接受性突破或已形成新趋势：标为未受控 B，不用 H2/L2 标签挽救。

### 3A. A 腿终点也必须经过稳定性检查

视觉上先画出的 A 腿终点，不一定是决策时可以冻结的终点。如果后续在同一回调上下文中出现更低的低点，至少要保留“旧锚点/较晚锚点”两种画法，并重新检查 B、MM 和第一支撑。不能因为某一组锚点事后更接近目标，就把它提升为唯一正确答案。

TSLA `2026-02-11`–`2026-03-20` 是当前边界：`03-03` 低点约 `385.39` 后，`03-09` 又下探到约 `381.40`。它仍然像空头 ABC，且 `03-13` L1、`03-18` L2 有真实低周期触发，但 A/B 被降级为锚点待定；这正是视觉助手应输出的优化结果。

### 4. 计数是局部描述，不是信号本身

同一个周期、同一个回调上下文中，才继续数 H1/H2/H3 或 L1/L2/L3。新的趋势极值、回调转成交易区间或结构发生改变时要重新评估。设置/计数 K 和确认/触发 K 分开记录。

H3/L3 可以作为第三次尝试的视觉入口，但不等于三推楔形，也不等于反转。第三次尝试仍然强并有跟随时，可能只是趋势延续。

### 5. 形态质量和交易可行性分开

形态很像，但触发价上方/下方的第一独立阻力或支撑太近，仍应输出 `valid_no_trade`。反过来，形态只是 B 级候选，但位置、订单和空间更合理，也值得继续审计。不能用 MM、AB=CD、EMA 或后续盈利覆盖近端障碍。

## 当前研究状态

| 能力 | 当前状态 | 现阶段可以做什么 | 还不能声称什么 |
| --- | --- | --- | --- |
| 完整图表视觉筛选 | 可用的研究能力 | 找出 pattern-like 候选，描述趋势/区间/位置 | 不能声称自动识别全部形态 |
| A/B/C 与 H/L 计数 | 工作假设较清楚 | 按同周期、同回调记录局部结构 | 不能声称固定阈值已经验证 |
| H1/L1 与 H2/L2 优先级 | 跨案例有重复支持 | 强 A 优先看第一次，普通 A 等第二次 | 不能直接等同于高胜率 |
| H3/L3 | 有视觉对照和边界 | 记录第三次尝试、衰竭或延续候选 | 不能冻结成三推反转规则 |
| 订单分支 | 已形成研究协议 | 区分 stop、limit-retest、market-close、观望 | 不能交给执行 Agent |
| 止损与第一障碍 | 可做粗略结构审计 | 找失效区、近端支撑/阻力、粗略 R/R | 不能用固定数字替代结构判断 |
| 胜率/量化回测 | 尚未建立 | 只保留案例、反例和未决边界 | 不能报告已验证胜率 |

## 新增跨案例观察：形态层与订单层的四种结果

目前几类案例已经足以建立一个实用的视觉分层，但还不足以声称胜率：

| 类型 | 代表案例 | 视觉结论 | 订单结论 |
| --- | --- | --- | --- |
| 无跳空、低周期顺序清楚 | `KLAC 2025-03-24/26`、`TSLA 2025-08-22` | 形态和局部恢复都可直接继续审计；TSLA 过程路径已到达第一阻力 | 最容易冻结触发、结构止损和首障碍；仍需把过程到达与交易结果分开 |
| 小缺口、重订后仍有空间 | `TSM 2025-03-26` | 强 A、受控 B、L1-like 形态保留 | 原 stop 失效；旧价 limit 未成交；gap-reprice 分支后来到达首支撑，因此只增加过程证据，不升级为统计结论 |
| 小缺口、重订后空间被压缩 | `NKE 2025-10-28` | 形态像，B 仍低于 A 起点 | sell-limit/retest 可研究；若只能在缺口后追入，首障碍约 `0.5R`，偏 no-trade |
| 计数/市场状态发生改变 | `CRM 2025-03-26`、`QCOM 2025-03-28` | 不能只凭第二次下跌继续沿用旧 L2 | CRM 默认重置为新 L1-like；QCOM 优先改用区间逻辑 |
| 无缺口、触发可重建但空间边界 | `AMZN 2024-10-15` | L1-like 视觉清楚，但普通 A、深 B、板块许可混合 | 不需要 gap-reprice；仍因首支撑约 `1.1R–1.4R` 和板块混合保留为边界/观察 |
| 无缺口、低周期顺序清楚且首障碍有空间 | `NFLX 2025-03-28` | 方向性 A 更清楚，B 深但仍低于 A 起点；09:45 盘中刺破、10:15 收盘确认 | sell-stop 与收盘确认分开；首支撑约 `1.4R–1.9R`，可进入条件正向研究，但不自动视为已验证正例 |
| 无缺口、H2 低周期空间明显优于日线 | `NVDA 2024-09-24` | 强 A、深但后段受控 B、H1 失败后 H2；原触发未被开盘跳过，SOXX 同向 | 日线宽结构止损首阻力约 `0.9R`；若明确采用 60m/15m thesis，窄止损分支约 `1.9R`；两者不能混算 |

可复用的视觉助手顺序因此更清楚：

1. 先判断 A、B、C 是否像一个同周期的开放趋势结构；
2. 再判 H/L 计数是否仍属于同一回调，还是已经重置/区间化；
3. 然后才看原始 stop 是否真实可成交；
4. 若发生跳空，分别审计回测 limit、缺口重订和观望，不把它们合成一笔；
5. 最后用当时可见的第一支撑/阻力和结构止损判断是否值得继续。

这套分层服务于“看懂图、筛选机会、给出人工优化入口”，不是量化扫描器，也不授权自动执行。

## 新增跨案例观察：哪些图值得先深入

把最近的条件正向样本和边界样本放在一起，当前可以形成一套定性优先级，但还不应压成评分：

| 视觉组合 | 代表案例 | 当前含义 |
| --- | --- | --- |
| `strong-looking-A + controlled/deep-but-late-controlled-B + no-gap trigger + first obstacle has room` | `NFLX 2025-03-28` | 最值得继续补低周期和过程结果；事后 `03-31` 已触及预先标出的首支撑，但仍保留盘中刺破与收盘确认两个订单分支 |
| `strong-A + controlled-B + small gap + reprice keeps space` | `TSM 2025-03-26` | 形态层和空间层偏正，但原始订单已失效；只能作为重订后的条件候选 |
| `ordinary-A + deep-B + no-gap trigger + first obstacle borderline` | `AMZN 2024-10-15` | 形态像且订单干净，但不值得因为“无 gap”而升级 |
| `strong-A + controlled-B + small gap + space compressed` | `NKE 2025-10-28` | 形态层可以保留，交易层倾向观望或等回测，不追着缺口成交 |
| `strong-A + H2-like support reaction + first resistance crowded` | `TSLA 2025-08-22`、`KLAC 2025-10-23` | 多头形态可能成立，但首障碍先决定能否做；MM 不能覆盖近端阻力 |
| `strong-A + weak-B + L2 static-space-positive + stop-first-path` | `TSLA 2024-03-13` | 形态、位置和静态 R/R 看起来合格，但目标后来到达不等于原交易路径成立；先审计失效位与首支撑的先后顺序 |

当前可复用的人工筛选语言是：先问“这是不是一个方向性母腿”，再问“反向 B 的压力有没有在后段减弱”，最后问“信号 K 出现在有意义的位置后，前方第一道障碍是否给它呼吸空间”。三项都较好时才进入低周期审计；只满足一两项时，继续保留为边界样本。

这不是新的量化规则，也不是胜率结论，而是帮助助手在完整图表上优先选择值得人类深入的 pattern-like 结构。

## 当前人工训练优先级：四种普通 ABC/H1-H2/L1-L2 结果

下面不是排名、评分或胜率表，而是给视觉助手安排下一轮人工复核的代表性样本。它们分别覆盖“形态和订单都较清楚”“形态清楚但缺口改变成交”“形态正向但日线空间不足”和“多头 H2 的不同交易 thesis”。

| 代表案例 | 视觉层 | 订单/风险层 | 训练重点 |
| --- | --- | --- | --- |
| `NFLX 2025-02-14–03-28` | 强方向 A → 深但后段受控 B → L1-like 空头恢复 | 无开盘缺口；`09:45` 盘中刺破与 `10:15` 收盘确认分开；首支撑约 `1.4R–1.9R` 粗略空间 | 当前最适合训练“看清 A/B、再分订单合同、最后看首支撑”的普通空头 ABC；不把后续盈利升级成规则 |
| `TSM 2025-02-14–03-28` | 强 A → 受控 B → L1-like 恢复 | 原 sell-stop 被小缺口越过，旧价 limit 未成交；只有事先允许的 gap-reprice 分支后来到达首支撑 | 训练“原订单未成交”和“重订分支”不能混成一笔，也不能用后续路径替代成交证据 |
| `CRWD 2024-09-11–10-11` | 多头强 A → 深 B 后段稳定 → H2-like | `10-03` 15m 触发可重建；宽日线结构止损下首阻力有空间但不宽，事件背景另列 | 训练“深 B 不是自动否决，但必须写清后段稳定”，以及 H2 价值来自新的位置测试而不是数阳线 |
| `NVDA 2024-09-11–09-25` | 多头强 A → 深但后段受控 B → H1 失败后 H2 | 原触发未跳空；日线宽结构止损下首阻力约 `0.9R`，低周期 thesis 才有更宽空间 | 训练不同时间周期的止损不能互换；低周期空间更好不等于日线交易也成立 |

这四类样本共同说明：视觉上先判断“像不像”，再判断“哪一种订单和风险合同值得研究”；同一形态不能因为换一个窄止损就被包装成更高质量的交易。它们仍是条件正向或边界研究样本，不是已验证策略。

## 助手每次筛图的最低输出

```text
1. 左侧背景：趋势 / 区间 / 过渡 / 高潮

7. 订单分支：stop / limit-retest / market-close / observation-only
```

价格和日期允许先用区域或近似值；不能近似的是因果时点、订单语义、结构失效和是否使用了后见之明。
