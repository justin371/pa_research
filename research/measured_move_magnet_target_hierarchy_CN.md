# Measured Move、磁铁与目标层级：视觉管理框架 V0.1

状态：`visual-research / provisional / cross-pattern / not-quantitative`

本文件不是重新发明 MM 公式，而是把不同目标放进同一条视觉决策顺序。Measured Move、AB=CD、区间高度和缺口都可以帮助估计价格可能走到哪里，但它们不能跳过已经存在的主要支撑/阻力，也不能单独授权入场。

## 1. 先分清两种语言

### 1.1 Price Action 的结构语言

PA 里的 `A`、`B`、`C` 首先描述方向腿、回调和原方向恢复。它回答的是：市场是否仍由原方向控制、回调是否受控、下一次尝试在哪里。

### 1.2 测量语言

几何 `AB=CD` 或 `Leg 1 = Leg 2` 描述的是距离投影。它回答的是：如果第二段复制第一段，可能到哪里。

两者必须分栏记录：

```text
结构：A 腿 → B 回调 → C 恢复
测量：A/B 的距离 → 从 C 投影 D
```

不能因为某个价格刚好符合 `AB=CD`，就把它自动叫成 C 腿、H2、反转或入场信号。

## 2. 常用测量类型

### 2.1 方向腿等距 / AB=CD

在多头案例中，先冻结 A 腿低点、B 腿高点和 C 的回调终点：

```text
多头 D = C + (B - A)
空头 D = C - (A - B)
```

这里的 A、B、C 是测量锚点，不一定等同于研究标签中的 A/B/C。允许记录 `接近等距`、`明显扩展` 或 `明显不足`，不能为了得到漂亮的 1:1 事后移动锚点。

### 2.2 Leg 1 = Leg 2

第一条方向腿、一次回调、第二条方向腿，是 ABC 延续中最常见的测量。它适合做空间参考，但第二腿可能：

- 在近端主要阻力前停住；
- 因强趋势扩展而超过 1:1；
- 在区间中部根本不应被当成趋势第二腿；
- 被更大的父级腿包住，后来需要同时保留局部目标和父级目标。

### 2.3 区间高度、突破高度与 measuring gap

成熟交易区间的高度、已被接受的突破结构高度和 measuring gap，都必须先有一个真实边界。若第一下只是刺破、收回或没有跟随，不能先拿区间高度投影，再把后来走势解释成已经接受的突破。

### 2.4 结构磁铁

前高、前低、区间边缘、支撑转阻力、阻力转支撑、明显缺口边缘和通道边界都属于磁铁。它们不是数学目标，但往往比孤立的 MM 更早影响价格路径。

## 3. 目标层级：固定顺序

每一笔研究候选按下面顺序列目标，不允许先写远端 MM 再寻找理由：

```text
入场
  ↓
第一独立障碍/磁铁
  ↓ 只有接受、穿越或明确反应后
第二道结构障碍或角色转换区
  ↓ 只有路径仍然开放时
AB=CD / Leg 1 = Leg 2 / 区间高度 / breakout height
  ↓
更大父级腿的延伸目标
```

### 3.1 第一独立障碍

第一障碍是从入场方向看最先遇到的、真正可能改变路径的区域，不一定是全图最强的那一个。按现有支撑/阻力层级，先检查：

1. 近端已反复反应的主要摆动高低点或角色转换区；
2. 成熟区间的上沿/下沿；
3. 突破区、缺口边缘、通道边界和反复验证的次要结构；
4. 低周期局部高低点，只在研究低周期合同的时候使用。

同一价格簇中的前高、MM、缺口边缘和 EMA 只算一个障碍，不能把四个标签相加伪装成四道阻力。

### 3.2 结构接受后的 MM

如果价格强势收盘越过第一主要阻力，有跟随，并在回测中守住新角色，那么原阻力可以降级为已接受的支撑，MM 才有机会成为下一目标。若只有一根影线或单根大 K，状态仍是测试/候选，不是自动切换。

### 3.3 延伸目标

更大的父级腿可以提供第二个 MM，但必须标成新的层级。局部腿完成并不意味着父级目标已经完成，父级目标也不能反过来授权局部入场。两个目标若落在同一区域，只保留一个目标簇。

## 4. 入场前的空间审计

目标审计在入场之前完成，而不是盈利之后补写：

| 问题 | 研究记录 |
| --- | --- |
| 入场合同是什么？ | stop、limit-retest、market/close 或 observation-only；冻结触发和实际成交假设 |
| 结构止损在哪里？ | 形态失效点、母级主要极端或支撑/阻力外；不能只用方便计算的局部 K 线极值 |
| 第一障碍是什么？ | 指出来源、价格区域和它为什么独立；与 MM 重叠时只记一个区域 |
| 到第一障碍有多少空间？ | 用实际入场和结构止损粗略估算 R；若首障碍小于约 1R，默认降级或不交易 |
| MM 是否已经穿过障碍？ | 若是，不能假定强趋势；要先等待接受，或把障碍作为管理区 |
| 事件和跳空是否改变合同？ | 财报前三个交易日不做新仓；跳空越过触发后重算成交、止损和空间 |

“MM 看起来很远”不能替代第一障碍空间。一个候选可以形态漂亮、MM 很远，但仍然因为入场后马上遇到左侧阻力而是 `valid_no_trade`。

## 5. 持仓后的路径管理

### 状态 A：尚未到第一障碍

若价格沿原方向推进但仍未到第一障碍，重点观察是否出现强趋势跟随、通道减速、缺口回补或信号失败。不要因为 MM 在更远处就忽略局部买卖压变化。

### 状态 B：进入第一目标区

Measured Move 是目标区域，不是必须精确触碰的点。价格进入目标区后，如果出现以下证据，分批止盈是合理的：

- 实体变小、重叠增加；
- 多次冲高/下探没有跟随；
- 上影或下影反复出现；
- 通道成熟，且目标区与主要阻力/支撑重合；
- 缺口回补或磁铁到位后出现明显反应。

默认研究模板是：第一目标区减一部分，剩余仓位再看精确 MM、第二道结构目标或延伸；若后续出现明确反向结构，退出剩余仓位。不能为了多拿最后几个价格单位而把全部利润暴露给第一障碍的反应。

### 状态 C：第一障碍被强势接受

若出现连续强收盘、跟随和回测守住，记录 `obstacle-accepted`，再把下一个 MM 作为主要目标。此时交易状态已经改变；原来“阻力前管理”的合同，不能与“突破后回踩”的新合同混算。

### 状态 D：第一障碍拒绝或突破失败

如果在第一障碍出现反转 K、跟随失败或重新回到区间，优先保护已实现利润或退出剩余仓位。若要反向交易，必须另建失败突破/第二次入场合同；不能用原多头/空头的 MM 直接反向。

## 6. 局部腿与父级腿

不要把时间窗口看得过短。一个局部上涨或下跌可能是更大腿里的嵌套腿：

- 局部腿可以提供近端目标和短线管理；
- 父级腿可以提供更远的目标和背景；
- 当局部腿没有完成或父级结构尚未清楚时，两套锚点可以并存；
- 只有在锚点在当时可见、定义稳定且没有事后移动时，两个投影才有研究价值。

因此记录格式使用：

```text
local_measure: 锚点、目标区、第一障碍、状态
parent_measure: 锚点、目标区、第一障碍、状态
```

如果两者指向同一支撑/阻力簇，合并为一个目标区域；如果一个投影穿过已知主要障碍，先暂停该投影，不用远端数字替代障碍。

| [`NFLX 2024-08-05–09-26`](nflx_three_push_top_boundary_2024-08-05_2024-09-26.md) | 反向触发下方的 `66.54–65.98` 首支撑很近，远端目标不能越过它 | 先标 `valid_no_trade`；后续顶部重新被接受也不能美化原 R/R | 形态/触发存在，但第一障碍先决定不能交易 |

这些案例共同说明：MM 的价值不在于“预测精确点位”，而在于帮助判断空间、管理路径和目标层级。它必须和父级状态、主要高低点、第一障碍以及实际成交合同同时使用。

## 8. 可迁移结论

1. 入场前先问第一独立障碍在哪里，再问 MM 能到哪里。
2. 阻力/支撑的强度与距离是两个维度；最强区域不一定是第一遇到的区域，第一遇到的区域也不能被跳过。
3. MM、缺口、EMA、50% 回调和前高如果在同一价格簇，只计一个主要区域，再记录各自的来源。
4. MM 到位后默认预期反应或停顿，不自动预期反转；反转需要失败突破、结构破坏和第二次确认。
5. 强趋势可以穿越主要阻力，但要看到强收盘、跟随和回测接受；不确定时，已有仓位优先分批管理，新的追单要等待新合同。
6. 目标附近动能减弱时，提前或分批止盈优于机械等待精确点；剩余仓位是否保留必须以结构和路径为依据。
7. 局部腿和父级腿可以同时测量，但不能用父级远端目标为局部入场背书，也不能事后移动锚点。
8. 目标完成与交易完成不是同一件事：若结构止损先失效，记录 `path-invalidated-before-target`，不要把后来到达 MM 记成原计划成功。

## 9. 当前状态与停止条件

当前框架仍为 `provisional`。它可以用于视觉筛选、入场前空间审计和持仓管理，但不进入 Codex Trading 生产规则。

只有在新案例同时提供以下证据时才继续扩大深审：

- 入场前锚点清楚，第一障碍和 MM 不被事后移动；
- 多空至少各有一个可重建的订单合同；
- 能区分首障碍先到、MM 先到、结构止损先失效和分批止盈路径；
- 有一个阻力被强势接受后切换到 MM 的对照，而不是只收集“目标未到”的边界案例。
