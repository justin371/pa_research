# 主要趋势反转（MTR）：视觉工作框架 v0.1

状态：`visual-research / provisional / not-quantitative`

这份文件定义 Al Brooks Price Action 语境下的 Major Trend Reversal（MTR）如何被视觉助手识别和复核。它不是“看到双顶/双底就反转”的规则，也不是胜率表、量化扫描器或自动下单授权。

## 1. MTR 先回答什么问题

MTR 不是普通回调的另一个名字。它要回答的是：

> 原来的趋势是否已经在主要位置失去控制，并出现了足以改变市场状态的反向尝试？

因此，完整图表上的观察顺序是：

```text
成熟趋势/通道
→ 趋势末端或主要位置的反转尝试
→ 双顶/双底、失败突破或通道/趋势线破坏等证据
→ 第一次反向尝试
→ 第一次失败或跟随不足
→ 第二次反向尝试（H1/H2 或 L1/L2 语义）
→ 触发、结构止损、第一障碍和粗略 R/R
```

后面的 C 腿、MM 到位或最终盈利不能倒灌成入场时已经知道的证据。

## 2. MTR 的最低视觉条件

以下条件不是固定数值门槛，但缺少其中多项时，最多只能标为 `reversal_attempt`，不能升级为 MTR 候选。

### 2.1 有成熟的原趋势背景

- 左侧有清楚的方向性趋势，至少出现多次推进、通道或连续的更高高点/更高低点，或相反的更低低点/更低高点；
- 价格已经到达主要高点/低点、通道边界、长期支撑阻力、旧突破区或明显的市场极端；
- 不是刚出现第一根回调 K 线，就把普通趋势回调叫成 MTR；
- 若父级已经变成成熟交易区间，优先使用区间边缘逻辑，不能把区间中部摆动硬套成 MTR。

### 2.2 有反转尝试，而不只是动能减弱

趋势变慢、K 线重叠增加、上影/下影增多，只能说明“可能成熟或平衡”，还不等于反转。还要看到至少一种方向性证据：

- 主要高点/低点附近的双顶或双底、二次测试失败；
- 突破前高/前低后不能接受，重新收回旧结构，形成失败突破；
- 趋势线或通道边界被有效破坏，并有后续跟随；
- 反向大 K 线在关键位置出现，收盘靠近反向极值；
- 反向尝试突破信号 K 或关键小结构后，价格没有马上回到原趋势一侧。

这些证据可以重叠，但同一价位簇不能重复计数。比如双顶和失败突破若发生在同一个前高，只算一个主要位置证据，另加“失败接受”证据。

### 2.3 有第二次反向机会或等价确认

第一根反向 K 线通常只是第一次尝试。MTR 研究优先寻找：

- 第一次反向尝试失败、没有跟随，随后回到反转区域；
- 第二次反向尝试出现更好的信号 K，或突破第一次尝试的信号结构；
- 触发后有跟随，或者回测反转区域后仍守住新方向。

多头反转可用 `H1/H2-like` 描述，空头反转可用 `L1/L2-like` 描述；这里的 H/L 是反转方向的尝试序列，不等于把 MTR 偷换成普通趋势中的 H2/L2。计数不清楚时写 `reverse-attempt-2-like`，不要强行冻结。

## 3. 双顶、双底、通道和失败突破怎么配合

### 双顶/双底

- 两次测试不需要精确在同一价格；允许略高、略低或一次刺破后失败；
- 两次测试之间必须有可识别的分离和反应，不能只是连续几根 K 线的影线；
- 第二次测试后要看反向触发和接受，而不是只看“出现两个高点/低点”；
- 双顶/双底可以是 MTR 的位置证据，也可能只是交易区间边缘的普通二次入场。

### 通道/趋势线破坏

- 只有两个点时，称为趋势线候选；要有平行边界和多次运行，才更有资格称为通道；
- 跌破/突破趋势线本身不等于趋势反转，至少要结合主要位置、反向信号和跟随；
- 通道破坏后若价格仍在原趋势极端附近横向交易，先标为过渡，不急于授权反向交易。

### 失败突破

失败突破比单纯“碰到前高/前低”更有信息量：价格先越过已知结构，随后收回并接受在结构另一侧。原突破方向和失败突破后的反向订单是两份不同合同；不能把它们合并成一笔交易。

## 4. MTR 与相邻结构的边界

| 看起来相似的结构 | 应优先归类为 | 什么时候才可进入 MTR 审计 |
| --- | --- | --- |
| 趋势中的普通 A→B→C | `ordinary_pullback / ABC continuation` | 价格到达主要极端，原趋势恢复失败，并出现反向二次确认 |
| 成熟区间上沿/下沿的二次测试 | `range_edge_reversal` | 只有区间边缘之外出现失败突破、重新进入并形成新的反向接受，才另开 MTR 分支 |
| 三推或 H3/L3 | `exhaustion_candidate`、`continuation_or_climax`、`range_repeat_test` 或 `channel_continuation` | 三推减弱、位置重要、反向触发和风险几何同时成立；三推数量本身不够 |
| 趋势线第一次被刺破 | `transition / observation` | 破坏后有收盘接受、跟随或回测守住，且未立即回到趋势通道 |
| 急跌后的第一根反弹 K | `reversal_attempt` | 后续 H1/H2-like 反向恢复和结构接受清楚，且不被近端阻力否决 |

MTR 与区间边缘可以重叠，但研究记录必须保留两个标签：`range-edge-overlap` 和 `MTR-candidate`。不能用区间中部的后续上涨证明早先的趋势反转成立。

## 5. 订单、止损和第一障碍

### 5.1 订单分支

1. **Stop confirmation**：在反向信号 K 或第二次尝试结构外等待 buy stop/sell stop；最适合需要市场证明已经改变方向的情况。
2. **Limit-retest**：只有已经存在的旧支撑转阻力、旧阻力转支撑、失败突破边缘或缺口边缘，才可研究回测限价单；不能把限价单随意放在当前价格附近。
3. **Market-close**：只在反向 K 极强、收盘接受清楚、等待可能错过主要运动且首障碍仍有空间时研究；不能默认使用。
4. **Observation-only**：MTR 外形存在，但计数、结构止损、事件或第一障碍不清楚时，观望是有效输出。

### 5.2 结构止损

- 看空 MTR：止损通常在主要双顶/反转尝试高点或失败突破极端上方，并留出正常测试空间；
- 看多 MTR：止损通常在主要双底/反转尝试低点或失败突破极端下方；
- 不用单根信号 K 的窄极值替代母级结构止损；若改用低周期短止损，必须另记为短线合同；
- 如果原趋势极端被重新接受，MTR thesis 失效，不因为后来又跌/涨回来而保留原标签。

### 5.3 第一独立障碍与粗略 R/R

入场前先排序：

1. 最近的左侧主要高点/低点或角色转换区；
2. 失败突破边缘、区间边缘、缺口起点或通道边界；
3. 更远的主要结构；
4. 最后才看 AB=CD 或 measured move。

第一障碍贴近、落在正常波动内，或不足以覆盖结构风险时，标记 `valid_no_trade`。有基本空间但不宽裕时，标记 `conditional/borderline`。只有空间合理时，才进入 `research_positive_conditional`。`1R/2R` 仅用于粗略沟通，不是固定胜率门槛。

## 6. 无后见之明案例审计

### A. TSLA 2024-03-04–03-14：区间上沿重叠的空头 MTR 候选

- 背景：前方约 `190–205` 的局部区间上沿；`2024-03-04–03-06` 出现连续强空头 A，说明上沿突破没有被接受。
- 反转证据：`2024-03-07–03-11` 反弹较弱，`182.87` 形成结构高点；`2024-03-12` L1 失败，`2024-03-13` L2 以较强阴线和低周期跟随向下。
- 订单：`172.41` 下方 sell stop；结构止损 `182.87` 上方；入场前可见左侧支撑 `152.37–153.75`，静态约 `1.6–1.9R`。
- 过程边界：后来 `2024-03-26` 高点约 `184.25` 先破坏结构止损，早于 `2024-04-16` 到达支撑；因此是 `MTR-candidate / range-edge-overlap / process-stop-first`，不是过程正例。
- 价值：说明“形态方向对、静态空间够”和“实际路径先到目标”是不同问题。

### B. NFLX 2024-08-05–09-26：高位多次测试的空头 MTR 边界

- 背景：`2024-08-05` 至 `2024-08-20` 强多头 A 到约 `71.13`，随后在高位多次测试。
- 反转证据：`2024-08-22/27/30` 和 `2024-09-03` 构成高位多次测试，`09-03` 出现明显空头反应；但测试次数、重叠和高点关系使三推计数不够干净。
- 订单：`67.10` 下方 sell stop，`09-06 10:15` 低周期才实际越过；结构止损应在 `71.60–71.70` 上方。
- 第一障碍：`66.54–65.98`，只给约 `0.1–0.25R`；因此即使有反向触发也应观望。
- 过程边界：`2024-09-24` 又越过顶部，说明原反转 thesis 后续失效。
- 标签：`MTR-like / H3-like / first-support-crowded / valid_no_trade / later-structure-invalidated`。

### C. TSLA 2025-09-08–09-12：双高/三推反转尝试被突破接受否定

- `2025-09-08–09-10` 在 `355.39–357.54` 主要阻力下反复上探，影线越过但收盘不能接受；当时可以保留 `bearish-reversal-attempt`，等待空头触发。
- `2025-09-11` 以接近高位的强 K 收在主要阻力上方，15m 随后跟随并回测不跌回旧阻力；市场状态切换为 `BOP acceptance`。
- 结论：在突破前观望或只研究失败突破空头是合理的；突破被接受后，原 MTR 假设失效，不能继续因为三推/双高而逆势做空。
- 标签：`reversal-attempt / failed-MTR-thesis / BOP-acceptance`。

### D. PLTR 2024-12-24–2025-01-08：普通 A 与双顶样 B 的空头边界

- `2024-12-24` 后的 A 有方向性但重叠较多；`2025-01-03/06` 反弹形成近似双顶，`01-07` L1-like 下破。
- 双顶使结构更容易阅读，但 A 不够强，且 `69.75` 第一支撑相对 `80.06` 结构止损不足约 `1R`。
- 结论：这是 `ordinary_pullback / early-reversal-candidate / valid_no_trade`，不能因为后来继续下跌而升级成 MTR 正例。

### E. ASML 2025-05-19–06-13：双底样结构但实际是区间过渡

- 前级上涨后深回撤，`715–718` 附近两次测试，外形像双底；随后价格横向重叠并向上扩张。
- 缺少第三次同级别衰竭推进、清楚的反向二次触发，以及在触发前冻结的订单几何。
- 结论：`range-transition / double-bottom-like / not-MTR`。它提醒我们不要把双底样式自动升级为主要趋势反转。

### F. LOW 2024-06-11–06-24：低位反转尝试但父级尚未确认

- 急跌后出现方向性多头 A，回调在低位支撑附近稳定，随后有 H1/H2-like 恢复。
- 但父级仍是急跌后的过渡，`221.92–223.01` 第一阻力贴近，结构止损下首障碍不足；没有可靠的波段新仓几何。
- 结论：`bullish-reversal-attempt / parent-transition / H1-H2-like / valid_no_trade`，不是已确认 MTR。

## 7. 当前工作结论

目前可以稳定使用以下视觉语言：

1. `reversal_attempt`：趋势极端处出现反向压力，但尚未完成第二次确认；
2. `MTR-candidate`：成熟趋势、主要位置、反转证据、反向二次确认都具备，进入订单/RR 审计；
3. `MTR-confirmed-for-research`：反向触发后有接受和跟随，且未被原趋势极端重新接受；这仍不是胜率结论；
4. `failed-MTR-thesis`：原趋势突破/接受重新出现，反转假设失效；
5. `valid_no_trade`：形态像，但第一障碍、事件、计数或结构止损否决交易。

当前还没有足够证据把 MTR 冻结为生产规则，也没有一个无事件、双向、首障碍宽裕且过程完整的“标准正例”。这不是缺陷，而是本轮研究应明确保留的边界：先能正确区分“反转候选”和“普通回调/区间反应”，再继续找少量真正填补缺口的案例。

## 8. 后续最小验证任务

只在以下情况出现时继续加案例：

- 出现一张无事件、成熟趋势极端、双顶/双底或失败突破清楚、反向二次触发不跳空的图；
- 新案例能补一个此前没有的方向或订单合同；
- 新案例能明确区分 MTR 与普通回调、区间边缘或三推延续。

每个新案例只需要补：完整背景、反转尝试、第二次确认、订单、结构止损、第一障碍、粗略 R/R 和失效路径。达到一个多空各有条件候选、至少两个边界反例后，不再为了“完美案例”无限扩展。
