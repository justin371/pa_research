# 开盘反转（Opening Reversal）视觉研究框架 v0.1

日期：2026-08-23  
状态：`framework / partial / provisional / not-quantitative`

这是一份视觉研究框架，不是实盘规则、胜率结论或量化扫描器。它用于区分四种经常被混在一起的情况：开盘反转、开盘后趋势延续、跳空后的回测，以及交易区间边缘的反应。

## 1. 工作定义

开盘反转不是“第一根 K 线反向”或“缺口一定要回补”。本项目暂时把它定义为：

1. 开盘前已经存在可见背景：趋势、区间、隔夜缺口、前日高低点、主要支撑/阻力或事件重定价；
2. 开盘第一方向先向某个磁铁或结构位推进；
3. 这个方向没有被接受，出现明显失败、长尾、收回、重叠增加或第一次反向尝试；
4. 反向方向形成 H1/L1，随后最好出现 H2/L2 或同等清楚的第二次确认；
5. 入场时仍有结构止损和第一独立支撑/阻力提供的空间。

缺少第 3 或第 4 项时，只能写成“开盘反应候选”或 `observation-only`，不能把一次缺口回补直接叫开盘反转。

## 2. 无后见之明的观察顺序

不要先看当天收盘或后续大行情再给开盘贴标签。每个案例只按当时已经知道的顺序记录：

| 顺序 | 要问的问题 |
| --- | --- |
| 1 | 左侧是开放趋势、成熟区间、过渡还是高潮？前日高低点和主要支撑/阻力在哪里？ |
| 2 | 今日开盘相对前收、前日高低点和区间边缘是缺口、越过、区间内还是直接重叠？ |
| 3 | 最初几根 K 线的压力是否有方向性、收盘是否靠极值、跟随是否出现？ |
| 4 | 第一个方向是在继续接受，还是在磁铁/结构位处失败并回到原区域？ |
| 5 | 反向尝试是 H1/L1 还是第一次失败后的 H2/L2？信号 K 和确认价是否已经冻结？ |
| 6 | 订单成交后，第一道独立支撑/阻力和结构止损之间是否有足够空间？ |

“前几根 K 线”是观察窗口，不先硬编码成固定根数。强开盘需要跟随和空间；两边都有长影线、重叠增加、价格反复穿越开盘区间时，应优先考虑交易区间。

### 开盘的三个临时状态

- `opening-drive-continuation`：开盘方向强、收盘靠极值、跟随清楚，且没有先出现失败接受；先按趋势/BOP 研究，不反向猜顶。
- `opening-reversal-candidate`：第一方向在可见磁铁或结构位失败，反向信号形成，并且有第二次确认路径。
- `opening-range-transition`：早期双向、重叠多、边界反复；先按开盘区间或交易区间边缘处理，不强行计数。

## 3. 缺口与第一波失败

缺口只是背景变量，不是方向授权：

- 缺口后强跟随、远离前方障碍：更像 `gap-and-go` 或开盘趋势；不要因为缺口存在就做反向交易。
- 缺口快速回补、重新接受前日区间、反向 K 线增强：可以进入开盘反转候选，但仍需反向触发。
- 开盘直接越过原 stop：原订单的成交价、止损和 R/R 必须重算；不能把理想触发价保留下来。
- 缺口进入前日高低点、区间边缘或其他磁铁：先看该位置的反应；缺口回补可以是目标，也可以只是中途测试。

事件或财报驱动的缺口单独标记。若在财报前 3 个交易日内，按本项目的交易纪律默认不建立新仓；事件后的方向性 K 线也不能直接并入普通开盘反转样本。

## 4. H/L 第二次入场逻辑

方向对称地看：

- 缺口下开或开盘先下跌，随后在支撑/前低/缺口边缘收回：多头第一次恢复可记为 H1-like；H1 失败后再下探并重新恢复，才进入 H2-like 候选。
- 缺口上开或开盘先上涨，随后在阻力/前高/缺口边缘受压：空头第一次恢复可记为 L1-like；L1 失败后再次上探并重新转弱，才进入 L2-like 候选。
- 第一根反向 K 线不是自动入场。信号 K、触发 K、确认 K 和订单成交要分栏记录。
- 如果开盘后只是继续沿原方向形成普通 H1/H2 或 L1/L2 回调，不要事后把它改称开盘反转。

## 5. 订单分支、止损与空间

| 分支 | 适用情形 | 关键限制 |
| --- | --- | --- |
| `stop-confirmation` | 反向信号 K 后，价格越过其高/低点或开盘区间边界 | 跳空越过触发位时，按实际可成交价格重订；不能沿用理想价格 |
| `limit-retest` | 反向后回测前日高低点、缺口边缘或角色转换位 | 必须先冻结回测位置；与原 stop 合同分开，不能事后补单 |
| `market/close-confirmation` | 反向收盘很强、第一障碍较远、接受更大滑点和更宽止损 | 强 K 末端可能已经接近磁铁；空间不足就不追 |
| `observation-only` | 第一方向仍有跟随、反向证据弱、事件未清、首障碍太近或止损不可承受 | 这是有效结论，不是漏掉交易 |

特别注意订单含义：市场价在 `284.65` 附近时，挂在下方 `284.50` 或 `277.00` 的卖出限价单通常是可立即成交的 marketable limit，不是“等价格下跌到那里再卖”。等待向下跌破应使用 sell stop；等待跳空后反弹回测才是新的 sell-limit/retest 合同。

结构止损先放在开盘反转极端、前日结构位或 B 腿失效点外，并留出正常测试空间；不要把止损压在第一根小 K 线的另一侧。先看入场时已知的第一独立障碍，再看 MM：研究上第一障碍至少要有约 1R 的粗略空间，完整波段通常希望接近 2R，但这只是过滤参考，不是固定胜率阈值。MM 不能越过一个已经贴近入场的主要高点/低点。

## 6. 与相邻形态的边界

| 相邻形态 | 先判它是什么 | 何时才可进入开盘反转分支 |
| --- | --- | --- |
| `BOP / gap-and-go` | 开盘方向被接受，收盘和后续跟随仍强 | 原方向先失败并重新接受反向区域后，才另开反转假设 |
| `Final Flag` | 长趋势末端的小回调或窄区间；不一定发生在开盘 | 开盘只是触发最后一次失败并出现反向 H/L 确认时，允许重叠，但不能把旗形本身当反转 |
| `MTR` | 更大级别趋势线/通道破坏、极端测试和第二次反向尝试 | 开盘反转只能是 MTR 的早期证据，不能用一根开盘反向 K 证明主趋势已反转 |
| `Range edge` | 价格位于成熟区间顶部/底部，区间逻辑优先 | 边缘失败突破后重新进入区间，再有二次入场时，按区间边缘框架记账 |
| 普通 `H1/H2` 或 `L1/L2` | 趋势中的回调延续，没有开盘第一方向失败 | 保持普通趋势回调标签，不事后改名 |

## 7. 历史案例审计

### RBLX：2024-04-04，开盘上冲失败但不值得交易

- 完整 Daily 背景约为 `35.8–39.0` 的宽交易区间；局部 A→B→C 不能覆盖区间事实。
- `2024-04-04` 开盘约 `36.97`，已经越过 `2024-04-03` 高点约 `36.66`；盘中一度上冲约 `38.09`，但收约 `36.80`，接近日内低位，开盘多头方向没有被接受。
- 这可以进入“开盘上冲失败/空头反应候选”，但信号 K 质量差，且区间中部约 `37.3–37.8` 很近。区间下沿结构止损约在 `35.79` 下方，首目标顺序应先看中部、再看上沿 `39.0–39.2`。
- 结论：`opening-reversal-candidate / range-edge / valid_no_trade`。不能用 `2024-04-05` 后来恢复上涨，倒灌成 `04-04` 的优质 H1 或趋势 ABC。

### COIN：2024-01-09，空头开盘反应存在但首支撑拥挤

- `2024-01-02–03` 已有强下跌和缺口压力，`01-04–08` 反弹到约 `161.38`；`2024-01-09` 15m 开盘约 `159.60`，先上探约 `159.99`，随后第一根大阴线低到约 `153.29`。
- 视觉上这是高位反向的 L1-like 开盘反应；若等低点下方 sell stop，方向触发存在，但 `148.81`、`146.51`、`144.11` 等左侧支撑在入场前已经可见。
- 结构止损应放在约 `161.38` 上方；到最近支撑的空间只有约 `0.25–0.5R`，不支持完整日线新仓。`2024-01-10` 低开越过原 L2 触发位，不能把它当成更好的原价订单。
- 结论：`opening-reversal-candidate / H3-like-expansion-boundary / valid_no_trade`；第三次上探范围扩张，不足以证明楔形衰竭。

### VRT：2026-04-17，开盘接受，不是开盘反转

- `2026-04-14` 有明显缺口冲击型多头 A，`04-15/16` 深 B；`04-17` 开盘约 `298.64` 后守住并继续向上，较像 B 后的开盘接受与 H1-like 恢复。
- 原先约 `296.46` 的 buy stop 已被开盘越过；若重新等 `305.53` 上方触发，第一阻力 `310.94–312.40` 只剩约 `0.42–0.53R`。
- `298.64` 附近若要研究，必须另定义“开盘接受”合同，不能把高开自动当作低风险入场。
- 结论：`opening-acceptance boundary / original-stop-opening-skip / first-obstacle-boundary`，不是 opening reversal。

### TSLA：2025-03-04，跳空延续与回测，不是开盘反转

- `2025-03-03` 的空头信号 K 低点约 `277.30`；`2025-03-04` 直接约 `270.93` 低开，原 sell stop 被跳过，不能按 `277` 假设成交。
- 若在开盘后市场仍约 `284.65` 时挂下方 sell limit，它可能立即成交，不是等待下跌；真正等待价格反弹到 `284.0–284.3` 的 limit-retest 是一笔新的合同。
- 这是缺口延续/角色转换回测案例。它用于校正订单语义，不应被命名为开盘反转。

## 8. 当前结论与最小复核卡

当前没有一个同时满足“事件干净、反向确认清楚、首障碍宽裕、订单合同完整”的双向标准正例。因此本框架暂定为 `partial / provisional`，但已经足够作为视觉筛选语言使用。

以后只需记录以下字段，不再为每个案例写成 ABC 长篇：

```text
contract_scope: deep_review / historical_context_only
pre_open_context / market_state
gap_or_open_position
first_opening_pressure
failure_or_acceptance
parent_state: open_trend / trading_range / range_edge / transition / climax / unclear
direction: long / short / no_valid_direction
primary_pattern: ABC_CONT / BOP / H1_L1 / H2_L2 / H3_L3 / RFB / MTR / other
internal_label: H1 / H2 / L1 / L2 / H3 / L3 / none / pending
signal_bar:
new_trigger:
order_branch: stop_confirmation / limit_retest / market_close / stop_limit / observation_only
structural_stop:
first_independent_obstacle / measured_move
rough_R_R
event_and_sector_filter
outcome_at_decision_time
```

本卡中的 `pre_open_context`、开盘压力和事件字段是开盘专用补充；canonical `direction`、`primary_pattern` 和 `internal_label` 仍按统一合同填写，不能用 `market_state` 或旧的 H/L 合并字段代替。
