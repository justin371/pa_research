# H1/L1、H2/L2 与 ABC 证据缺口审计（2026-08-23）

日期：2026-08-23  
状态：`visual-research / evidence-gap-audit / not-statistical`

## 1. 这轮审计要回答什么

本轮只补查 `H1/L1`、`H2/L2` 和 `ABC continuation` 的代表性视觉证据，不把 PA Research 变成 Codex Trading 的量化扫描器。判断顺序固定为：

```text
完整图表背景 → 父级是趋势还是区间 → A 腿方向性
→ B 回调 lineage 与后段压力 → H/L 计数
→ 信号 K 与订单合同 → 结构止损 → 第一独立障碍 → 粗略 R/R
```

一张图只有同时能回答这些问题，才值得升级到条件性正向候选：

- 事件窗口：触发前后三个交易日不在财报禁区；其他事件单独标记，不能伪装成普通趋势样本；
- 父级状态：局部窗口不是交易区间中部，也不是已经被接受的新反向趋势；
- A/B：A 方向清楚，B 仍属于同一回调且没有被后续结果倒灌；
- H/L：只数同一周期、同一回调 lineage 中有意义的尝试；
- 订单：stop、收盘确认、limit-retest、开盘重订分别记录，不能假设未发生的成交；
- 风险：结构止损和第一独立支撑/阻力先于 MM，首障碍空间不能靠远端目标美化。

## 2. 本轮真正新增的证据

### 2.1 CRWD：多头 H2-like 的“深 B、后段稳定、低周期确认”分支

来源：[`CRWD 多头 H2-like 案例`](crwd_bullish_h2_deep_b_late_stabilization_2024-09-11_2024-10-11.md)。

- `2024-09-11`–`2024-09-20` 的 A 腿方向性足够清楚，先标为 `strong-looking-A`；但 A 内含跳空/加速，不能作为完全干净的普通趋势基准。
- `2024-09-23`–`2024-10-01` 的 B 较深，前段卖压并不弱；后段在 `68.17` 附近稳定，故保留为 `deep-B-late-stabilization`，不能像浅 B 一样优先假设 H1。
- `2024-10-02` 是第二次有意义的多头恢复，先记为 `H2-like`；`2024-10-03` 的 15m buy-stop 与收盘确认分支可以分别重建。
- 结构止损观察在 B 低点 `68.17` 下方，研究区约 `67.4–67.8`；触发附近第一阻力为 `75.11–75.54`，粗略约 `1.5R–1.9R`，但不是宽裕正例。
- 财报前三日过滤通过，但 CrowdStrike 的历史事件背景仍需单列，所以状态保持 `research_positive_conditional / incident-context-pending`。

**本案例新增的不是“又一张 H2 图”，而是一个边界分支：深 B 只在后段稳定后才恢复 H2；低周期触发清楚，也不能取消首阻力和事件背景。**

### 2.2 TSM：空头 L1/ABC 的“原 stop 未成交、缺口后重订”分支

来源：[`TSM 空头 ABC/L1 案例`](tsm_bearish_abc_l1_gap_reprice_space_2025-02-14_2025-03-28.md)。

- `2025-02-14`–`2025-03-11` 的 A 腿方向性明显；`2025-03-12`–`2025-03-25` 的 B 仍低于 A 起点，后段可先标为 `controlled-B`。
- `2025-03-26` 是 B 后第一次清楚的空头恢复，先记为 `L1-like`；`03-27/28` 的继续下跌不能事后增加 L2。
- 在 `177.22` 下方的原始 sell-stop 被 `03-26` 的开盘缺口越过，不能假设按旧价成交；旧价附近的 sell-limit/retest 也没有回测成交。
- 若计划允许接受小缺口后重订，`176.66` 附近或后续 15m 确认是独立的新合同；结构止损放在 B 高点 `180.30` 上方，研究约 `181.0–181.5`。
- 第一支撑先看 `167.99–165.05`，重订分支粗略保留约 `1.6R–1.9R` 到支撑上沿的空间；这一空间属于重订合同，不属于原始 stop。
- `SOXX/SMH/SPY/QQQ` 同步走弱，板块与市场许可较好；财报前三日过滤通过。

**本案例新增的是订单和成交语义：形态可以保留，原订单可以失效；只有重新冻结 entry、stop、首支撑后，才能独立审计 gap-reprice 分支。**

## 3. H1/L1：当前仍是 `no-new-positive`

本轮复核的重点不是形态有没有出现，而是有没有新的、事件更干净、父级开放、首障碍有空间的 H1/L1 基准。现有材料给出的原因如下：

| 候选 | 为什么不升级为新的普通基准 |
| --- | --- |
| [`AAPL 2024-05-03–05-09`](aapl_bullish_h1_event_driven_a_2024-05-03_2024-05-09.md) | 形态和低周期确认清楚，但 A 是财报后事件驱动，首阻力也只是边界；保留为事件型条件候选。 |
| [`COST 2024-05-13–05-16`](cost_bullish_h1_first_obstacle_boundary_2024-05-13_2024-05-16.md) | A 与信号 K 都像，触发上方首阻力却几乎贴近，正确输出是 `valid_no_trade`。 |
| [`JNJ 2025-08-29–09-02`](jnj_bullish_h1_opening_skip_first_obstacle_boundary_2025-08-01_2025-09-02.md) | 结构和板块配合不错，但原触发被开盘越过且首阻力拥挤，必须走重订/观望分支。 |
| [`JPM 2025-08-22–09-05`](jpm_bullish_h1_first_obstacle_failure_2025-08-22_2025-09-05.md) | H1 低周期确实触发，但第一阻力只有约 `0.39R`，属于首障碍否决和跟随失败。 |
| [`ADBE 2026-01-12–01-27`](adbe_bearish_abc_l1_visual_screen_2026-01-12_2026-01-27.md) | L1-like 和首支撑空间较好，但父级是过渡转空且市场逆势，不能当作普通开放空头基准。 |
| [`NVDA 2025-06-23–07-03`](nvda_bullish_abc_h1_visual_candidate_2025-06-23_2025-07-03.md) | 形态积极，但原 stop 与开盘重订语义仍是边界，不能把后续上涨倒灌给旧成交。 |

因此本轮的正式结论是：

> `H1/L1 / ordinary-open-trend / event-clean / first-obstacle-space-positive`：**no-new-positive**。

这不表示 H1/L1 不存在，而是当前证据库仍缺一张可以同时通过父级、事件、订单和首障碍审计的纯净基准。继续重复找“强 A + 漂亮信号 K + 近阻力”的图，只会增加同质边界，不会增加研究信息。

## 4. H2/L2：条件性覆盖扩大，但不冻结规则

### 多头 H2

- `KLAC 2025-05-07–06-03` 继续作为支撑簇、EMA 汇合、H2 信号与确认分开的主要案例；
- `CRWD 2024-09-11–10-11` 新增深 B 后段稳定和低周期确认分支；
- `TSLA 2025-08-06–08-22`、`SNOW 2026-08-14–08-21` 继续承担首阻力拥挤或日线/低周期合同分离的边界作用。

这说明 H2 不能只写成“第二根阳线”：它更像是第一次恢复没有被接受后，在新的支撑测试和 B 后段稳定区域重新出现的方向尝试。

### 空头 L2

本轮没有新增一个满足“事件干净、父级开放、第二次空头尝试清楚、首支撑宽裕”的纯净 L2 基准。`TSM` 是 L1 和 gap-reprice 订单分支，不应为了对称而事后写成 L2；`QCOM`、`COIN`、`ANET` 等已有案例主要承担跳空、事件或首支撑边界。

因此 `L2` 仍为 `conditional / provisional`，下一次只有发现新的第二次尝试、计数 lineage 或订单合同信息时才值得继续深审。

## 5. ABC 延续：方向对照与订单分支已更清楚

当前最有信息量的组合不是把所有案例并成一个胜率，而是保留三种不同合同：

| 角色 | 案例 | 训练重点 |
| --- | --- | --- |
| 空头无缺口基准 | [`NFLX 2025-02-14–03-28`](nflx_bearish_abc_l1_no_gap_space_2025-02-14_2025-03-28.md) | 强 A、深但后段受控 B、无缺口 L1、首支撑可审计；sell-stop 与收盘确认分开。 |
| 空头缺口重订 | [`TSM 2025-02-14–03-28`](tsm_bearish_abc_l1_gap_reprice_space_2025-02-14_2025-03-28.md) | 原 stop 未成交、limit 未回测、gap-reprice 重新冻结 R/R。 |
| 多头深 B/H2 | [`CRWD 2024-09-11–10-11`](crwd_bullish_h2_deep_b_late_stabilization_2024-09-11_2024-10-11.md) | 深 B 不是自动否决，但后段稳定、首阻力和事件背景决定是否只保留条件候选。 |

`RBLX`、`QCOM`、`ADBE`、`MCD` 等继续作为区间/过渡、首障碍、市场逆势或宽 B 的边界，不把它们升级成正向样本。

## 6. 本轮结论与工作边界

| Pattern | 本轮状态 | 研究结论 |
| --- | --- | --- |
| H1/L1 | `no-new-positive / boundary-covered` | 普通开放趋势的纯净基准仍缺；已有事件、跳空、首障碍和跟随失败边界足够防止误读。 |
| H2/L2 | `conditional / provisional` | 多头新增 CRWD 分支；KLAC 仍是主要条件案例；空头 L2 仍缺干净正例。 |
| ABC continuation | `conditional / evidence-expanded` | NFLX 与 TSM 提供无缺口/缺口重订对照，CRWD 补多头深 B；不形成统计胜率。 |

本轮不做：

- 不把 `no-new-positive` 改写成“没有这种 pattern”；
- 不把 TSM 的重订路径写成原始 stop 已成交；
- 不把 CRWD 的后续越过首阻力倒灌成入场时已知；
- 不修改 Codex Trading，不创建量化扫描器，不连接 Execution Agent。
