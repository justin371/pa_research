# Triangle / 三角形专项视觉证据缺口审计

日期：2026-08-24  
状态：`framework / partial / provisional / no-new-positive`

本审计把三角形作为“区间里面的区间”来研究：先看父级和双方试探，再看收缩/扩张、突破接受或失败。它不把两点趋势线、Inside Bar、旗形或后续上涨倒灌成三角形。

## 1. 当前合同

| 合同 | 当时需要看到的证据 | 当前结论 |
| --- | --- | --- |
| 收缩三角形突破 | 双向摆动、两侧多次测试、边界收窄、突破收盘和跟随 | 视觉合同已形成；尚无事件干净、首障碍宽裕、路径完整的独立正例 |
| 区间内区间 | 父级成熟区间、小级别双向压缩、边缘/中线位置清楚 | ASML/RBLX 提供边界；内部突破不能自动改变父级 |
| 扩张三角形 | 高低点外扩、范围增大、第三次测试不收缩 | COIN/XOM 提供否决样本；扩张不自动等于衰竭反转 |
| 突破接受 | 强收盘外侧接受、跟随、回测守边 | TSLA 提供 BOP 状态切换；不是提前的三角形反转交易 |
| 失败突破/二次机会 | 刺破后重新进入、第二次边界失败、反向触发 | RBLX 提供首障碍与信号质量否决；仍无完整标准正例 |
| 旗形/微型压缩对照 | 单方向趋势、测试不足、原方向惯性强 | KLAC 提供非三角形边界，避免过度命名 |

## 2. 案例审计

### 2.1 ASML 2025-05-23–06-11：区间内重复测试

- `2025-05-23` 和 `2025-05-30` 在 `715–718` 下沿附近反复测试，之后进入高重叠区间并向上扩张。
- 局部可以画出收窄边界，但完整图表更像父级区间下沿的重复测试和状态转换；没有足够清楚的两侧边界、触发和独立首障碍。
- 后续上涨不能证明事前已经存在三角形多头突破；结论为 `range_inside_range / not_triangle_frozen / observation-only`。

这是“看起来像收敛，但父级区间优先”的条件边界。

### 2.2 TSLA 2025-09-08–09-12：压缩后突破接受

- `2025-09-08–10` 在 `355.39–357.54` 主要阻力下多次试探，影线越过但收盘没有接受，可以记录为高位压缩/triangle-like boundary。
- `2025-09-11` 强阳线收在约 `368.81`，越过阻力并有 15m 跟随，随后回测守住旧阻力。
- 状态应切到 `breakout_acceptance / BOP`；原先的失败突破或三角形反向假设失效，新交易要用新的突破合同。
- 仍需先检查更远左侧阻力和实际成交，不能因强阳线自动追入。

这个案例是三角形研究中的条件性状态切换候选，不是预先冻结的三角形正例。

### 2.3 RBLX 2024-03-18–04-05：宽区间中的局部内区间

- 父级约为 `35.8–39.0` 的宽交易区间；`03-18–28` 上涨后，`04-01–03` 回到下沿，局部有收缩和反复测试。
- `04-04` 盘中冲到约 `38.09` 后收约 `36.80`，向上突破没有接受；`04-05` 的恢复不能倒灌成顺势三角形突破。
- 原 buy stop 约 `36.66` 被开盘约 `36.97` 越过；止损应在 `35.79` 下方，区间中部 `37.3–37.8` 很快成为第一障碍。
- 结论：`range_inside_range / failed_breakout_candidate / valid_no_trade`。

这个案例强调父级区间、信号质量、成交重订和第一障碍必须同时审计。

### 2.4 COIN 2024-01-04–01-10：扩张边界

- 同一空头 A 后的 B 腿中，`01-04/05/08` 多次上探，第三次范围扩大并回到约 `161` 阻力；高点与范围没有逐步收缩。
- `01-09` 低周期出现向下反应，但下方 `148.81` 首支撑相对于 `161.38` 结构止损只提供约 `0.25–0.5R`；`01-10` 开盘重订进一步改变原 L2 合同。
- 结论：`expanding_triangle_boundary / continuation_or_climax / valid_no_trade`；扩张表示波动加剧，不是自动空头反转。

它是收缩三角形的反例，也是“第三次测试更强时不要硬套衰竭”的边界。

### 2.5 XOM 2024-07-18–08-02：扩张与跳空重订

- `07-25/30/31` 三次上探约 `109.82/110.34/111.43`，第三次抬高并扩大范围；更像扩张/延续边界而不是收缩三角形。
- `08-01` 出现空头反应，`08-02` 开盘约 `107.90` 跳过原 sell stop；首支撑约 `105.20`，重订后粗略空间约 `0.7R`。
- 结论：`expanding_boundary / gap_reprice / valid_no_trade`。形态方向、订单成交和空间必须分开。

### 2.6 KLAC 2025-10-14–10-24：趋势旗形而非三角形

- 强多头腿后 `10-22` 出现单日回调，`10-23` 强阳线突破并在 `10-24` 接受前高；可以观察成小型压缩或 flag-like 结构。
- 没有两侧多次分离测试，不能称成熟三角形；父级趋势旗形解释更直接。
- 触发上方 `115.49–115.63` 左侧高点贴近；严格日线分支 `valid_no_trade`，强趋势磁铁分支只是条件性研究。

这个对照防止把每个收窄小平台都升级为 Triangle。

## 3. 可复用视觉规则

1. **三角形先是双向压缩**：没有两侧测试、分离和父级位置，就只记趋势线候选。
2. **区间内区间不改变父级**：内部突破先按子结构处理；强收盘、跟随和回测守住后才重建新趋势。
3. **收缩与扩张相反**：收缩降低波动并等待突破；扩张增加波动和不确定性，不自动授权反向。
4. **第一突破不是自动成功**：只有被接受才转 BOP；重新进入后才开启失败突破/二次机会分支。
5. **内部 H/L 不继承开放趋势计数**：三角形中的局部 H1/H2、L1/L2 要结合边界位置重新解释。
6. **订单合同分开**：原突破 stop、失败后的反向 stop、角色转换后的 limit-retest 不能合并成一个理想成交。
7. **首障碍先于三角形高度/MM**：目标投射撞左侧主要阻力/支撑，直接降低交易质量或 no-trade。
8. **完整图表不能倒灌**：后续成功突破只用于路径审计，不证明当时三角形已经冻结。

## 4. 最小视觉复核卡


## 5. 当前缺口与停止条件

- 尚无事件干净、两侧边界清楚、测试足够、突破接受和首障碍宽裕的标准收缩三角形正例；不为填数量把 TSLA 或 ASML 改写成正例。
- 扩张三角形已有 COIN/XOM 边界，但尚缺一个能区分扩张后延续、高潮和 MTR 的低周期完整对照。
- 新案例只有在填补收缩突破、失败后二次机会、父级区间切换、扩张订单或首障碍几何之一时才值得深审；同质的“阻力下压缩”不重复收集。
