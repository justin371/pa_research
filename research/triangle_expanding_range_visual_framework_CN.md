# 三角形、扩张三角形与区间内区间：视觉研究框架 V0.1

状态：`visual-research / partial / provisional / not-quantitative`

PAHubCN 26A–26B 的核心描述是：三角形是“区间里面的区间”，波动收缩但双方仍在试探；第一下突破可能失败，应该等待突破、跟随或失败后的第二次机会。最终旗形和扩张三角形可以是变体，但形状本身不提供方向授权。

本文件把三角形和以下结构分开：Inside Bar/IOI、普通趋势旗形、成熟交易区间、BOP 接受和失败突破。当前仓库还没有一个事件干净、边界/触发/首障碍完整且空间宽裕的标准三角形正例，因此所有案例先保持 `triangle-like / boundary`。

## 1. 最小视觉定义

### 1.1 收缩三角形

研究候选至少要有：

- 同一父级背景内的双向摆动；
- 上方高点逐步降低、下方低点逐步抬高，或至少有两侧边界收窄的证据；
- 两侧各有可见的测试/反应，而不是只用两点画一条趋势线；
- 波动或摆动幅度逐步收缩，但双方仍在试探；
- 形态发生的位置和突破前的磁铁可以事前确定。

对视觉助手而言，三角形首先是压缩中的双向市场，不是“看起来像旗形就做顺势”。如果只有一个高点和一个低点，标记为 `trendline_candidate`，不要叫三角形。

### 1.2 扩张三角形

扩张三角形表现为高点更高、低点更低，波动边界向外扩张。它说明双方都能把价格推得更远，方向优势反而可能下降；若发生在趋势末端，也可能与高潮、Final Flag 或 MTR 早期证据重叠。

扩张不等于衰竭，也不等于必然反转。第三次或后续测试若范围扩大、收盘靠极端、跟随增强，应优先防范原方向延续或波动扩大，而不是只因“扩张”就做反向。

### 1.3 区间内区间

成熟大区间内部出现一个更小的收缩区间时，优先记录 `range_inside_range`。它可以向上或向下突破，但第一下仍可能失败；内部突破不能自动改变父级区间状态。

只有小区间外出现收盘接受、跟随和回测守住，才逐步把它升级成新趋势的 A 腿。若价格重新回到小区间，回到父级中部，原突破合同失效。

## 2. 与相邻结构的边界

| 结构 | 核心特征 | 不能混淆的地方 |
| --- | --- | --- |
| Inside Bar / IOI | 一根或多根 K 的范围压缩，母 K 关系清楚 | 是微观平衡/突破触发，不自动等于三角形；需要更大级别边界和多次摆动 |
| 普通趋势旗形 | 趋势中的反向小回调，原方向惯性仍强 | 没有双方多次试探和收窄边界时，不叫三角形 |
| 成熟交易区间 | 上下沿反复测试，中部双向交易 | 三角形可能是区间内部的子结构；区间边缘逻辑优先于内部局部三角形 |
| BOP 接受 | 突破收盘强、外侧停留、后续跟随/回测守住 | 突破前不能假设 BOP；突破失败要另开反向/区间合同 |
| 失败突破 | 越过事先可见边界后重新回到原侧 | 第一根刺破不是失败确认；需要收盘回归和反向跟随 |
| Final Flag | 长趋势末端的压缩小回调/窄区间 | 三角形可成为 Final Flag 变体，但末端背景和突破结果必须另外确认 |
| H1/H2、L1/L2 | 回调中的尝试次数和信号序列 | 三角形内部的局部 H/L 不自动继承为开放趋势计数 |

## 3. 无后见之明的观察顺序

1. 先判断父级是开放趋势、成熟区间、通道还是过渡；
2. 标出三角形的上沿、下沿和形态内部的中线/磁铁；
3. 确认两侧是否有足够的测试和分离，避免两点趋势线误标；
4. 记录当前价格位于上沿、下沿还是中部；
5. 观察第一突破是接受、失败、还是尚未确认；
6. 若第一突破失败，等待重新进入和第二次尝试，不直接反向追；
7. 冻结订单、结构止损、第一独立支撑/阻力和粗略 R/R；
8. 只使用决策时已经出现的 K 线，后续方向和 MM 只做结果审计。

推荐状态：

- `triangle_candidate`
- `range_inside_range`
- `expanding_triangle_boundary`
- `breakout_acceptance_candidate`
- `failed_breakout_candidate`
- `triangle_middle_no_trade`
- `valid_no_trade`

## 4. 突破的两种合同

### 4.1 突破接受 / BOP 分支

多头突破需要看到：收盘站在上沿外、上方拒绝有限、后续继续走或回测上沿守住。空头对称处理。突破 K 很大时，可以降低初始风险或等待低周期回测，不要因为收盘很强就用正常仓位追在首障碍前。

三角形的高度、边界距离或 MM 可以作为目标参考；如果目标投射直接撞上左侧主要阻力/支撑，先处理第一障碍。

### 4.2 失败突破 / 二次入场分支

第一下刺破后重新回到三角形内部，只说明原方向没有被接受。更清楚的反向合同通常是：

- 重新进入后，第二次测试边界失败；
- 反向信号 K 突破三角形内的局部摆动；
- 反向回测边界被拒绝并出现跟随。

原突破 stop、失败突破后的反向 stop、结构回测 limit 是三份不同合同，不能用一份理想入场价合并。

## 5. 订单、结构止损和首障碍

### Stop-confirmation

- 多头：上沿外的确认 K 高点上方 buy stop；
- 空头：下沿外的确认 K 低点下方 sell stop；
- 失败突破反向：在重新进入后反向信号 K 外等待确认；
- 开盘跳过或大缺口越过触发时，按实际成交重算，旧价位作废。

### Limit-retest

只在三角形边界、突破区、角色转换区已经清楚时研究。回测未发生前不能假设成交；如果价格直接穿过边界进入另一结构，必须改成新的合同。

### 结构止损

- 收缩三角形突破：止损不能只放在最近一根 inside K 外，至少要覆盖突破边界和最近的有效摆动；
- 扩张三角形反向：止损应放在最后一次测试极端外，正常波动往往更大；
- 区间内区间：若 thesis 依赖小区间突破，止损应覆盖小区间失效；若依赖父级边缘，则使用更宽的父级结构止损；二者不能混写；
- 结构止损太远而首障碍太近时，直接标 `valid_no_trade`。

### 首障碍和粗略 R/R

第一目标优先看入场方向上最近的独立支撑/阻力、三角形另一侧边界或父级区间中线。三角形高度、MM 和远端边界只能在近端区域被接受后使用。

第一障碍不足约 1R 时不交易；完整波段约 2R 只是参考，不是固定阈值。一个三角形突破即使最终走得很远，也不能用后续路径把原来拥挤的第一障碍改写掉。

## 6. 案例审计

### A. ASML 2025-05-23–06-11：区间内重复测试，不冻结三角形

- `2025-05-23` 和 `2025-05-30` 在 `715–718` 下沿附近反复测试，随后进入高重叠区间并向上扩张。
- 局部可以画出收缩边界，但完整图表更像父级区间下沿的重复测试和状态转换；没有清楚的两侧边界、突破触发和独立首障碍。
- 结论：`range_inside_range / not_triangle_frozen / observation-only`。后续上涨不能倒灌成预先存在的三角形多头突破。

### B. TSLA 2025-09-08–12：阻力下压缩后向上接受

- `2025-09-08–10` 在 `355.39–357.54` 主要阻力下多次试探，影线越过但收盘没有接受；这可以记录成高位压缩/triangle-like boundary，但不提前称反转。
- `2025-09-11` 强阳线收在 `368.81` 附近，越过阻力并有 15m 跟随，随后回测守住旧阻力。
- 结论：`breakout_acceptance_candidate / BOP`。原来的失败突破或三角形反向假设失效；新交易需要按接受突破合同重建。
- 风险：突破触发附近必须先检查更远左侧阻力和实际成交；如果第一阻力太近，不因强阳线而自动追入。

### C. RBLX 2024-03-18–04-05：宽区间中的局部三角形/内区间

- 父级是约 `35.8–39.0` 的宽区间；`03-18–28` 的上涨、`04-01–03` 的回到下沿，局部有收缩和反复测试。
- `04-04` 盘中冲高约 `38.09` 后收盘约 `36.80`，向上突破没有被接受；`04-05` 的恢复不能把前一日改写成顺势三角形突破。
- 原 buy stop 约 `36.66` 被开盘约 `36.97` 越过；结构止损应在 `35.79` 下方，区间中部 `37.3–37.8` 很快成为第一障碍。
- 结论：`range_inside_range / failed_breakout_candidate / valid_no_trade`。区间逻辑优先，止损和空间不支持直接交易。

### D. COIN 2024-01-04–09：扩张三角形边界而非收缩突破

- 同一空头 A 后的 B 腿中，`01-04/05/08` 多次上探，第三次范围扩大并回到约 `161` 阻力；高点关系和 K 线范围都不是逐步收缩。
- `01-09` 低周期有向下反应，但下方 `148.81` 首支撑相对 `161.38` 结构止损只提供约 `0.25–0.5R`；`01-10` 开盘重订又改变原 L2 合同。
- 结论：`expanding_triangle_boundary / continuation_or_climax / valid_no_trade`。扩张只说明双方波动加剧，不是自动空头反转。

### E. XOM 2024-07-18–08-02：扩张测试与跳空重订

- `07-25/30/31` 三次上探约 `109.82/110.34/111.43`，第三次抬高并扩大范围；它更像扩张/延续边界，不是收缩三角形衰竭。
- `08-01` 出现空头反应，`08-02` 开盘约 `107.90` 跳过原 sell stop；首支撑约 `105.20`，重订后粗略约 `0.7R`。
- 结论：`expanding_triangle_boundary / failed-or-unconfirmed-breakout / gap-reprice / valid_no_trade`。订单成交路径和几何必须与形态分开。

### F. KLAC 2025-10-14–24：浅旗/微型压缩的延续分支

- 强多头腿后 `10-22` 出现单日回调，`10-23` 强阳线突破并在 `10-24` 接受前高；视觉上可作为小型压缩或 flag-like 结构观察。
- 现有证据没有冻结两侧多次测试，因此不能称成熟三角形；它更接近趋势旗形的延续。
- 触发上方 `115.49–115.63` 左侧高点很近；严格日线分支 `valid_no_trade`，强趋势磁铁分支 `research_positive_conditional`。
- 结论：不是每个收窄结构都要升级成三角形，趋势背景和第一障碍优先。

## 8. 当前结论与缺口

1. 三角形首先是区间内压缩和双方试探，第一突破不能默认成功；
2. 扩张三角形说明波动扩张，不自动等于衰竭或反转；
3. Inside Bar/IOI 是微观压缩，普通旗形是趋势回调，成熟区间是父级状态；三者可以重叠但不应互相替代；
4. 突破接受要看收盘、跟随和回测守住；失败突破要看重新进入和第二次尝试；
5. 当前 ASML、RBLX、TSLA、COIN、XOM、KLAC 提供了区间、接受、失败、扩张和旗形对照，但没有严格、事件干净、首障碍宽裕的三角形正例；
6. 因此本框架保持 `partial / provisional`，只用于视觉筛选、订单重建和观望纪律，不进入 Codex Trading 或 Execution Agent。
