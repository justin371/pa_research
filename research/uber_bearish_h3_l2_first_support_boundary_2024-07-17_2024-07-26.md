# UBER 2024-07-17–2024-07-26：强空头 A、H3-like 计数歧义与 L2 首支撑边界

状态：`pattern_like / provisional-H3-like / L2-like / C-class-expansion-boundary / sector-aligned / earnings-filter-passed / low-cycle-no-trigger-gap / valid_no_trade`

这是一份视觉研究案例，不是交易建议，也不是量化规则。它的价值不在于证明 H3/L3，而在于审计一个很容易被完整图表“事后看起来很漂亮”污染的场景：三次上探确实存在，但后续出现了更高、更宽的扩张；反向下破没有跳空，却仍然因为首支撑太近和触发质量不足而不值得交易。

## 1. 数据与时间边界

- 标的：`US.UBER`
- 研究窗口：`2024-01-01`–`2024-07-30` Daily；`2024-07-17`–`2024-07-30` 60m/15m。
- 数据：Futu OpenD 历史 QFQ K 线，收盘后只读复核；没有实时行情，也没有下单。
- 板块参考：`US.XLY`。`2024-07-15`–`2024-07-25` 从约 `94.06` 走到 `88.81`，个股空头候选获得一定的板块方向许可；这不是单独的做空信号。
- 财报：Uber 官方投资者关系页面显示，2024 Q2 财报电话会在 `2024-08-06` 举行。因此 `2024-07-26` 距财报超过用户设定的前三个交易日，事件过滤暂时通过；这不等于已经排除了其他新闻风险。

## 2. 当时可见的视觉结构

### 2.1 强空头 A 腿

`2024-07-17` 从开盘约 `73.38` 下压到最低约 `68.56`、收于 `68.62`；`2024-07-18` 又从开盘约 `69.00` 下探到 `65.81`、收于 `66.26`。连续的方向性实体、低位收盘和较少的重叠，使 `07-17/18` 可以作为强空头 A 候选。

但它是上涨后的强反转型 A，不是运行很久的成熟空头趋势。研究时应同时保留“强 A”与“反转 A”两个标签，不能因为后面下跌就把它升级成无条件的趋势延续 A。

### 2.2 B 腿中的多次上探：像 H3，但计数不能硬定

从 `2024-07-18` 低点之后，60m/日线可以观察到：

- `2024-07-19` 高点约 `67.44`：第一次有意义的上探；
- `2024-07-22` 高点约 `68.78`：第二次上探；
- `2024-07-23` 高点约 `69.10`：可以提名为第三次上探，形成 H3-like 熊旗顶部观察；
- `2024-07-24` 出现向下反应，最低约 `65.78`；
- `2024-07-25` 早盘先下探到约 `64.40`，随后又冲到约 `69.37`，日内范围显著扩大。

关键裁决是：`07-23` 的三次上探可以作为一个 H3-like 观察点，但 `07-25` 又突破 `69.10` 并扩张，说明原来的“第三次测试后衰竭”假设已经被新价格行为削弱。若把 `07-25` 也算成第三推，则前面的 `07-23` 又被重复计数；若把它算成第四推，则必须承认计数已变复杂。这里最安全的标签是 **provisional-H3-like / count-ambiguous / C-class expansion boundary**，而不是确认的三推楔形。

这正是完整图表研究需要防止的错误：看见三个高点不等于第三推已经结束，更不能用后面跌下去证明 `07-23` 当时就是可靠 H3 反转点。

## 3. L1/L2 订单分支

### 3.1 `2024-07-24`：L1-like，但被第二天的上扩张否定

`07-24` 从约 `67.27` 下行到 `65.78`，可以作为 B 腿后的第一次空头尝试，研究上接近 L1-like。但 `07-25` 又从 `64.40` 一带反向冲到 `69.37`，把前面的空头恢复假设重新打回观察状态。

因此不能把 `07-24` 的下破和 `07-25` 的最终下跌连续拼成一条已经成立的空头 C 腿。`07-25` 的上扩张是一个必须保留的 Working/Warning 状态切换。

### 3.2 `2024-07-25/26`：L2-like 研究触发

如果把 `07-24` 视为第一次空头尝试，那么 `07-25` 的大幅反向冲高之后，`07-25` 低点约 `64.40` 下方可以提名为一次 L2-like sell stop：

- 计划订单：`64.40` 下方 `sell stop`；
- 结构止损：放在最终 B 顶部 `69.37` 上方并留出 buffer，研究范围约 `69.70–70.00`；
- 低周期：`2024-07-26` 的 15m 开盘约 `66.10`，到 `15:15` 最低约 `64.18`；虽然相对前收有小幅高开，但没有从开盘直接跳过 `64.40` 原触发价；
- 触发质量：触发附近的 15m K 线下探后收回，日线 `07-26` 也收在约 `64.40`，没有形成很干净的空头接受。它更像一个被触发但需要马上降级观察的分支，而不是高质量 L2。

这里的订单分支必须和 `07-24` 分开记录：不能因为最终价格继续下跌，就把 `07-24`、`07-25`、`07-26` 合成一个事后完美的空头入口。

## 4. 第一支撑、结构止损与粗略 R/R

在 `07-26` 触发时，左侧已经存在的主要低点簇包括：

- `2024-05-23` 低点约 `63.25`；
- `2024-05-28` 低点约 `63.10`；
- `2024-05-31` 低点约 `63.14`；
- `2024-06-03` 低点约 `62.94`。

因此，触发下方第一支撑应先看 `62.90–63.30` 区域，而不是使用 `07-29` 之后才出现的 `63.72` 或 `07-30` 的更低点。

用计划成交约 `64.35`、结构止损下沿变体约 `69.70` 粗略估算：

```text
风险 ≈ 69.70 - 64.35 = 5.35
到第一支撑上沿 ≈ 64.35 - 63.30 = 1.05 ≈ 0.20R
到第一支撑下沿 ≈ 64.35 - 62.90 = 1.45 ≈ 0.27R
```

即使方向后来继续下跌，入场当时也没有足够的第一障碍空间。`08-01/02` 的更低价格、后续 measured move 或财报前的结果都不能倒灌成 `07-26` 的目标依据。

所以这不是“没有空头机会”，而是：**形态像、方向有、板块许可有、无跳空低周期触发也有，但第一支撑太近，且触发 K 线接受度不足，完整风险合同不成立。**

## 5. 视觉结论

本案提供四个可复用边界：

1. 强 A 后的三个高点可以先标成 H3-like，但后面出现更高、更宽的第四次扩张时，必须回到 `count-ambiguous / C-class expansion`，不能保留事后确认的三推标签。
2. L1 失败后再找 L2 是合理的，但 L2 不是自动升级；要重新检查计数是否仍在同一回调、信号 K 是否接受、第一支撑是否已经贴近。
3. “没有跳空”只解决成交重订价问题，不解决触发质量和 R/R 问题。
4. 事件过滤通过、板块顺势和后续盈利都只是辅助证据；第一障碍仍然优先于 MM。

最终标签：`pattern_like / provisional-H3-like / L2-like / C-class-expansion-boundary / valid_no_trade`。它应作为 KLAC H3 正向研究候选的独立边界对照，不进入 Codex Trading 生产规则，也不交给 Execution Agent。
