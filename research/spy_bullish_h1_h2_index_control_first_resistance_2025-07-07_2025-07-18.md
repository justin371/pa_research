# SPY 2025-07-07–2025-07-18：多头 H1/H2-like 指数控制样本与首阻力边界

日期：2026-08-23
状态：`pattern_like / index-control / bullish-H1-H2-like / count-pending / low-cycle-trigger-confirmed / first-resistance-blocked / valid_no_trade / event-context-pending`

## 1. 研究目的

这是一个指数层的视觉控制样本，不是交易建议、胜率样本或量化规则。SPY 没有单一公司财报这个干扰，适合先训练“完整图表里是否像上涨 A → 回调 B → 多头恢复”的第一层判断；但指数仍然可能受宏观事件影响，事件状态不能默认通过。

本案的决策时点固定在 `2025-07-16` 收盘后，尽量不使用 `2025-07-17` 之后的走势反推入场前的质量。数据为 Futu OpenD 历史 QFQ，收盘后复核；不是实时行情，也没有下单。

## 2. 完整图表与 A/B 外形

### 背景

在局部窗口里，`2025-07-07`–`2025-07-10` 先出现连续抬高和方向性推进；但它不是极端连续的大阳线冲量，更准确地说是 `ordinary-directional-A`，而不是已经冻结的 `strong-looking-A`。更大级别仍需防止把局部上涨误当成脱离区间的开放趋势。

### A 腿候选：`2025-07-07`–`2025-07-10`

- `07-07` 低点约 `611.10`；
- `07-08` 低点约 `612.73`，低点没有立即破坏；
- `07-09` 收盘约 `617.22`；
- `07-10` 高点约 `620.00`，收盘约 `618.96`。

这段方向向上、重叠不算严重，可以作为局部 A 候选，但强度不足以跳过后面的 B、计数和首阻力审计。

### B 腿候选：`2025-07-11`–`2025-07-16`

- `07-11` 收盘回到约 `616.79`；
- `07-14` 最高约 `618.31`，但没有形成持续接受；
- `07-15` 低点约 `615.24`、收盘约 `615.32`；
- `07-16` 先探到约 `611.28`，随后收回并收于约 `617.38`，最高约 `617.88`。

视觉上这是一个**深、但后段出现稳定迹象的 B**：它没有有效跌破 `07-07` 的 A 起点附近，最后一天买方重新出现。不过 B 也在 `611–620` 的局部宽度内来回，不能把它机械升级为开放趋势中的标准 H2。第一阶段可保留为 `bullish-H1/H2-like`，计数暂记 `count-pending`：

- 若把 `07-11/14` 看作第一次恢复尝试未能接受，`07-17` 可以解释成第二次恢复，即 H2-like；
- 若认为此前没有一个独立、清楚的 H1 信号，`07-17` 也可以只是 B 后第一次恢复，即 H1-like。

在没有进一步证据前，两种描述并列保留，不为了得到 H2 标签而硬数。

## 3. 信号 K 与低周期触发

`2025-07-16` 的收回 K 具备“先探低位、再收回”的多头恢复外观，但它不是单凭一根 K 就能授权交易的优质信号。若研究 buy-stop 放在 `07-16` 高点约 `617.884` 上方：

- `2025-07-17` 开盘约 `617.557`，没有从开盘直接跳过原触发；
- 15m 在 `09:45` 左右的高点已经越过 `617.884`，因此原 stop 的价格顺序可以重建；
- 60m 结构从 `07-16` 午后低点约 `611.277` 恢复到收盘约 `617.379`，`07-17` 继续向上，低周期接受度比单看日线更清楚；
- QQQ 同期也从 `07-16` 低点约 `548.916` 收复，`07-17` 最高约 `559.585`，因此市场层面没有明显逆向信号。

这只证明“订单可以研究、低周期确实触发”，不证明这笔日线风险合同值得做。

## 4. 结构止损与第一阻力

### 结构风险

对于“`07-16` B 结束、`07-17` 多头恢复”的日线 thesis，结构失效应放在 `07-07` 起点和 `07-16` 深探低点形成的区域下方。研究上可用 `611.10–611.28` 下方的缓冲区做粗略风险观察；不能为了改善 R/R 偷换成更小的 15m 局部止损，因为那会变成另一份短线 thesis。

### 第一独立阻力

触发前已经能看到：

- `2025-07-03` 高点约 `619.42`；
- `2025-07-10` 高点约 `620.00`。

因此 `619.4–620.0` 是触发 `617.884` 上方后最先要面对的左侧高点/阻力簇。它不能被后来的 `07-17` 高点或 `07-18` 行情覆盖掉，也不能因为更远的 MM 可能指向更高而忽略。

以触发约 `617.88` 和结构风险约 `611` 下方做粗略比较，第一阻力只有约 `0.2R–0.35R` 的空间量级，明显不够支撑日线新仓。若用更紧的低周期止损重新计算，必须明确写成另一份盘中交易假设，不能把它拿来证明原日线 H1/H2 合同有空间。

## 5. 结论

| 层级 | 结论 |
| --- | --- |
| 视觉第一层 | `pattern_like`；局部可看作普通方向性 A、深但后段稳定 B、多头恢复；指数控制样本成立 |
| 计数 | `H1/H2-like`，但 `count-pending`；不强行冻结唯一 H2 |
| 低周期 | 15m/60m 可以重建原 buy-stop，且没有开盘跳过；`low-cycle-trigger-confirmed` |
| 交易层 | `first-resistance-blocked / valid_no_trade`；第一阻力在 `619.4–620.0` 太近 |
| 事件/市场 | QQQ 同步；公司财报不适用，但宏观事件状态仍 `pending` |

本案最重要的训练信息是：**“图形像”“订单真实触发”“触发后有空间”是三个不同问题。** SPY 前两个可以成立，第三个不成立，所以视觉助手应该输出“形态像但观望/不做”，而不是为了后面确实上涨就追认成优质入场。

## 6. 可迁移的视觉边界

1. 指数可以作为去除单一公司财报干扰的控制图，但不能自动去除宏观事件和区间背景问题。
2. 深 B 后段稳定可以进入 H1/H2-like 候选；如果此前第一次尝试不清楚，计数要保留 H1/H2 两种解释。
3. 低周期触发确认只解决“有没有按计划成交”，不解决“成交后第一阻力是否太近”。
4. 第一阻力先于 MM；在 `619.4–620.0` 没有被接受突破前，不能把后续更高目标写回到 `07-17` 的原始入场判断。
