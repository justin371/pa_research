# 支撑/阻力强度与八个 Pattern 的位置审计 V0.1

日期：2026-08-23  
状态：`visual-research / cross-pattern-filter / not-quantitative`

## 目的

支撑和阻力不是图表上的一条精确线，而是决定 pattern 是否发生在有意义位置、第一障碍是否拥挤、结构止损放在哪里的共同过滤层。本文件把已有的层级原则连接到当前八个主动 pattern，不建立评分器，也不把“碰到某个价位”变成自动信号。

共同上下文的基础排序见[`Support/resistance strength hierarchy`](../docs/common_context.md#supportresistance-strength-hierarchy-visual-working-version)；本文件补充的是跨 pattern 的使用顺序。

## 视觉强度排序

| 层级 | 典型结构 | 视觉上为什么更重要 | 常见误读 |
| --- | --- | --- | --- |
| `major` | 大周期主要摆动高/低点、成熟区间上沿/下沿、明确角色转换、多周期重合且离开力度大的区域 | 较多交易者在此改变立场；能作为主要位置、结构失效和首障碍 | 只看最近局部点，忽略很远但更重要的左侧区域 |
| `intermediate` | 清楚的次要摆动、失败突破区、缺口边缘/起涨起跌区、通道边界、反复验证的 EMA20/50 | 常常决定回调能否守住、触发后第一段空间和回测合同 | 把 EMA 或缺口单独算成强度，或与同一价簇重复计数 |
| `local` | 单个局部高低点、单根 K 极值、孤立 EMA 触碰、未经反应确认的趋势线/数学投影 | 适合低周期触发、细化进场和短线管理 | 用局部点压缩母级止损，或跳过更近的 intermediate/major 障碍 |

这不是“强度越高就越先到”的排序。交易审计仍然从实际入场方向寻找**最近的独立障碍**：远处的 major 不能跳过近处的 local/intermediate；近处的局部点也不能被随意当成母级结构。

## 五个位置判断问题

每个 pattern 在入场前都要回答：

1. 该位置属于 major、intermediate 还是 local？依据是什么？
2. 这个区域是否在入场前已经被左侧反复测试、强力离开或角色转换确认？
3. 它是入场方向的支撑/阻力，还是已经被有效接受、正在转成另一种角色？
4. 触发后最先遇到的独立区域在哪里？与其他结构是否其实属于同一价格簇？
5. 结构止损要放在这个区域外，还是放在更大的父级失效位外？如果止损覆盖正常测试后首障碍仍太近，应否 `valid_no_trade`？

## 八个 Pattern 的位置用法

| Pattern | 位置必须回答什么 | 结构止损和首障碍的优先级 | 典型降级 |
| --- | --- | --- | --- |
| H1/L1 | 第一次恢复是在开放趋势的 major/intermediate 支撑阻力，还是只碰到 local EMA？ | 止损覆盖 B/父级结构；触发方向上的最近高低点先算首障碍 | 只有局部 EMA 触碰、区间中部或首障碍拥挤 → `observation_only`/`valid_no_trade` |
| H2/L2 | 第二次尝试是否在同一关键区域得到更清楚的拒绝，还是已进入新趋势/区间？ | 首先保护第二次测试失效位；不能用低周期窄止损跳过前方 major/intermediate | B 已接受反向结构或计数跨越新区域 → 重置、区间或 H3/L3 |
| ABC 延续 | B 结束是否守住 A 起点、旧突破区、EMA 汇合或主要角色转换？ | 父级 A/B 结构外止损优先；C 方向上的左侧区域先于 MM/AB=CD | B 穿越并接受关键结构 → 旧 ABC 结束；区间中部 → 区间逻辑 |
| 区间边缘二次入场 | 是否真的靠近已反复验证的上沿/下沿，而非区间中部？ | 止损在边缘外并覆盖刺破；首目标先看中线，再看另一边缘/独立磁铁 | 边界未确认、第一目标太近或中部追单 → `observation_only` |
| 失败突破/高潮 | 越过的边界是否事前可见，收盘接受还是回到原侧？ | 止损在失败边界/高潮极端外；首障碍看反向最近磁铁 | 只有影线或一根反向 K → 仍是测试/反向尝试；原方向接受 → BOP |
| BOP | 旧 major/intermediate 边界是否被收盘和跟随接受，回踩是否守住角色转换？ | 止损在回踩角色转换区或新结构外；突破后最近主要障碍决定是否追价 | 只越过影线、没有跟随或重新回区间 → 失败突破/区间边缘 |
| MTR | 反向动作是否发生在成熟趋势的 major 位置，并真正破坏控制结构？ | 止损放在主要极端/失败边界外；首障碍是反向方向最近独立区域 | 只有 local 双顶、三推或减速 → `reversal_attempt`，不升级 MTR |
| 三推/H3-L3 | 第三次推进是否到达 major/intermediate 边界，且推进效率真的变化？ | 止损覆盖第三推极端；首障碍先看反向最近区域，不用远端 MM | 第三推扩张、区间重复测试或通道延续 → 不自动反向 |

## 角色转换与接受

同一价格区域在不同阶段可能扮演不同角色：

- 原阻力被强收盘越过、后续保持外侧并回踩守住，才可研究“阻力转支撑”的 BOP 合同；
- 影线越过后收回原侧，先记为测试或失败突破候选，不自动把它当成已转换；
- 原支撑被接受跌破、反弹回测失败后，才可研究“支撑转阻力”的空头合同；
- 角色转换成立后，旧的区间、MTR 或 H/L 合同不能继续使用原止损和原 R/R，必须按新合同重算；
- 主要区域附近的 EMA、缺口边缘、50% 回调和 MM 可以作为 META 汇合，但同一价簇只能计作一个主要障碍。

## 首障碍和 MM 的共同规则

1. 先冻结订单分支和结构止损；
2. 从入场方向找最近的**独立**支撑/阻力区域；
3. 若近端障碍不足以覆盖结构风险，输出 `valid_no_trade`，不使用远端 MM 挽救；
4. 只有价格接受或穿越近端障碍后，才把 MM、AB=CD 或区间高度作为后续目标；
5. 进入目标区域后，若出现实体变小、重叠增加、跟随失败或反向影线，可以分批管理，不必机械等精确数值；
6. 任何跳空、财报或实际成交改变，都要重新计算触发价、结构止损、首障碍和粗略 R/R。

## 验收标准

- 八个 pattern 都能指出位置所属层级和依据；
- 主要高低点、区间边缘和角色转换优先于孤立 EMA、整数位和 MM；
- 首障碍按独立区域计算，同一价格簇不重复计数；
- 结构止损覆盖该 pattern 的正常测试，不为了 R/R 任意压窄；
- 能把“形态成立”与“位置/空间允许交易”分开，并保留 `valid_no_trade`；
- 位置层只服务视觉研究，不创建量化评分或自动执行规则。
