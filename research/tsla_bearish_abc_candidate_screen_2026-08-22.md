# TSLA 空头 ABC 候选筛选：2026-08-22

## 研究目的

从 `2024-08-22`–`2026-08-21` 的 TSLA 日线中筛选空头 ABC 候选，优先寻找：

- A 腿有方向性，但不是单日财报冲击；
- B 腿是有意义的反弹，最好回到均线、前方阻力或前一段下破区域；
- C 腿重新向下，并且能在较低周期找到 L1/L2 研究触发；
- 没有明显跳空或卖出高潮把成交几何完全改变；
- measured move、主要支撑和 R/R 可以分开审计。

本文是候选筛选，不等于已经确认的交易规则。



### L1/L2 触发研究

#### L1 候选：`2026-03-12`

- 因此 L1 形态有研究价值，不直接等于可交易。

#### L2 候选：`2026-03-18`

### 第一障碍与低周期触发审计

这条候选的形态比前面带有跳空污染的样本更干净，但两个空头尝试都受到近端支撑限制：

- `2026-03-12` L1：若以 `394.65` 下方作为研究 sell-stop，结构止损参考 `416.38` 上方，粗略风险约 `21.73`。当时已经可见的支撑簇约为 `389.95`–`385.39`；到上沿只有约 `0.22R`，到下沿也只有约 `0.43R`，所以 Daily 新仓应跳过。
- `2026-03-18` L2：若以 `392.31` 下方作为研究 sell-stop，结构止损参考最近反弹高点 `403.73` 上方，粗略风险约 `11.42`。同一支撑簇的上沿只有约 `0.21R`，下沿约 `0.61R`；这仍然不是合格的 Daily 新仓几何。
- `15m` 细节显示，`2026-03-18` 的破位主要发生在收盘前的最后几根 K 线；`2026-03-19` 开盘约 `387.27` 是后续新状态，不能倒灌成 `2026-03-18` 已知的更好成交价或 R/R。
- 因此本例应标为“强视觉 ABC/L1-L2 候选 + 第一障碍过滤样本”，而不是因为后面继续下跌就把它升级成可交易规则。
