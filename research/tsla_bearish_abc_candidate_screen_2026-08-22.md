- EMA20、EMA50 处于下行或转弱状态，价格主要位于 EMA50 下方；
- 这是一条有方向性的空头候选，但重叠和 `2026-03-09` 的下探/收回使它低于最干净的强 A 等级。

#### B 腿：`2026-03-04`–`2026-03-11`

- 反弹最高：`2026-03-11`，约 `416.38`；
- 相对 A 腿的回撤约 `61%`；
- 若把 `2026-03-03` 当 A 终点，B 腿内部被 `2026-03-09` 的下破打断；若把 `2026-03-09` 当较晚 A 终点，B 更像 `2026-03-10`–`2026-03-11` 的快速反弹/重测；
- 反弹高点仍低于 A 腿起点 `436.35`，没有破坏较大的空头结构；
- `2026-03-11` 触及/靠近 EMA200 区域后收弱，给 C 腿提供了位置背景。

#### C 腿：`2026-03-12`–`2026-03-30`

- `2026-03-12` 从 B 高点后转弱，形成第一次空头尝试候选；

这条 C 腿内部仍然可以嵌套更低周期的 L1/L2，不应因为 Daily 只有一个 C 就假设所有周期计数相同。由于 A/B 锚点存在两种合理画法，本例最终只能标为 `pattern_like`，不能写成无争议的 ABC。

### Measured move

A 腿高度约为：

```text
436.35 - 385.39 = 50.96
```

从 B 腿高点 `416.38` 向下投影一倍：

```text
416.38 - 50.96 = 365.42
```

`2026-03-20` 的最低价约 `364.46`，与第一 measured-move 目标只相差约 `0.96`。随后价格反弹到 `2026-03-25` 约 `396.23`，再继续下跌到 `2026-03-30` 的 `352.14`，因此可以把 `365` 附近视为第一目标/停顿区，把 `352` 视为后续扩展，而不是把整条 C 腿当成一次直线运动。

如果以 `2026-03-09` 的 `381.40` 作为 A 腿终点，另一组投影约为 `416.38 - (436.35 - 381.40) = 361.43`。这组锚点也只能作为候选目标，不能因为后续价格更接近它，就事后否定前一个画法或反过来冻结它。

### L1/L2 触发研究

#### L1 候选：`2026-03-12`

- 前一天 `2026-03-11` 反弹到 `416.38` 后，`2026-03-12` 收弱并跌到约 `394.65`；
- 若以 `394.65` 下方作为 sell-stop 研究触发，结构止损需要参考 B 高点或最近的结构高点；
- `2026-03-13` 的 `389.95` 是触发后才形成的当天低点，不能用于事前 L1 目标；当时可见的主要低点是 `385.39` 和 `381.40`，空间取决于采用局部还是 B 结构止损；
- 因此 L1 形态有研究价值，不直接等于可交易。

#### L2 候选：`2026-03-18`

- `2026-03-16`–`2026-03-17` 先反弹到约 `403.73`/`400.12`；
- `2026-03-18` 再次向下，最低约 `392.31`，形成第二次尝试候选；
- 60m 上，`2026-03-18` 早盘先冲到约 `403.06`，随后全天逐步走弱，最后一小时收在约 `392.78`；
- 15m 上，跌破 `392.31` 后出现连续下行，`2026-03-19` 继续跟随。

但 R/R 需要按当时已知的第一支撑计算，不能把 `2026-03-19` 的低点倒灌进 `2026-03-18` 的计划。这个候选更适合研究“结构成立但第一障碍可能太近”的情况。

### 第一障碍与低周期触发审计

这条候选比带有明显跳空重订的样本更适合研究正常订单时序，但 A 锚点和两个空头尝试都需要边界标记：

- `2026-03-12/13` L1：以 `394.65` 下方研究 sell-stop；若用 `406.50` 局部止损，到已知 `385.39–381.40` 支撑簇约 `0.78R–1.12R`；若用 `416.38` B 结构止损，约 `0.43R–0.61R`。不能把 `389.95` 倒灌为触发前目标。
- `2026-03-18` L2：以 `392.31` 下方研究 sell-stop，结构止损参考 `403.73` 上方，风险约 `11.42`；已知 `389.95`、`385.39`、`381.40` 分层约给 `0.21R`、`0.61R`、`0.96R`，第一障碍仍拥挤。
- `15m` 细节显示，`2026-03-18` 的破位主要发生在收盘前的最后几根 K 线；`2026-03-19` 开盘约 `387.27` 是后续新状态，不能倒灌成 `2026-03-18` 已知的更好成交价或 R/R。
- 因此本例应标为“视觉 ABC/L1-L2 候选 + A 锚点歧义 + 第一障碍过滤样本”，而不是因为后面继续下跌就把它升级成可交易规则。
