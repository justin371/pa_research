# TSLA 空头 ABC 与 L1/L2/L3 复核：2025-02-19 至 2025-03-10

## 状态与范围

- 标的：TSLA
- 研究窗口：`2025-02-19` 至 `2025-03-10`
- 周期：Daily、60m、15m；4H 只用 60m 研究块观察
- 数据源：Futu OpenD，`US.TSLA`，QFQ 历史数据
- 研究目的：补充与三个多头案例相对称的空头 ABC、L1/L2/L3 样本
- 研究状态：历史复盘；没有下单，不构成实盘授权
- 事件边界：本文不把后来的大幅下跌结果倒灌为入场依据；正式统计前仍需按交易日重新核对财报和其他事件日

## 一句话结论

这是一段清楚的空头背景：`2025-02-19` 高点之后形成强 A 下跌腿，`2025-02-28` 至 `2025-03-03` 只出现有限的 B 反弹。`2025-03-03` 的高点 `303.94` 触及并略过 EMA200（约 `303.23`）后反转，形态上可以记录为第一次空头尝试 L1。这里不能把“跳空后不追”简化成“没有交易”：若使用 `277.30` 下方的 sell stop，`2025-03-04` 跳空到 `270.93` 会改变实际成交；若使用已经发生反弹后的 sell limit/retest 分支，则可以在 `284.0–284.3` 附近重新评估。`2025-03-05/06` 又出现第二次空头尝试 L2，但第一道支撑太近，Daily R/R 仍不足。`2025-03-07` 至 `2025-03-10` 的第三次下探更像 L3/第三推候选，其中 `2025-03-10` 带有明显卖出高潮特征，不能因为编号为 3 就自动做空或预测反转。

## 1. 大周期背景

在本窗口之前，TSLA 已经从高位回落，价格位于下降的 EMA20/EMA50 下方。`2025-02-19` 的高点 `367.34` 不是一个全新牛市高点，而是下跌背景中的反弹高点。之后价格连续走低，直到 `2025-02-27/28` 附近跌至 `273.60–280.88`。

这决定了本案例的方向许可：

- 空头方向与 Daily、60m 背景一致；
- 做空不需要逆势猜顶，主要问题变成回调位置、L1/L2 计数和下方空间；
- 但越接近前低和可能的卖出高潮，越不能用“趋势很强”代替支撑与 R/R 审计。

`2025-03-06` 当日 SPY、QQQ 和 XLY 均收弱，市场与可选消费背景没有给 TSLA 多头提供明显许可；这支持空头方向，但不替代个股触发。

## 2. ABC 分解

### A 腿：`2025-02-19` 至 `2025-02-27/28`

核心下跌推进可以从 `2025-02-19` 高点 `367.34` 观察到 `2025-02-27` 低点 `280.88`，随后 `2025-02-28` 盘中又下探到 `273.60`。

- `2025-02-19` 收盘约 `360.56`，已经低于 EMA20 `372.23` 和 EMA50 `375.73`；
- `2025-02-20`、`2025-02-21`、`2025-02-24`、`2025-02-25`、`2025-02-26` 连续降低高点和收盘；
- `2025-02-25` 至 `2025-02-27` 继续向下扩张，收盘分别约 `302.80`、`290.80`、`281.95`；
- 低点和收盘持续下移，重叠不多，卖方控制明显。

**A 腿判断：** `A-`。这是强方向性下跌腿，但后段波动已经扩大，接近 `280` 附近时要开始观察卖出高潮和支撑，而不能无限追空。

### B 腿：`2025-02-28` 至 `2025-03-03`

以 `2025-02-28` 低点 `273.60` 到 `2025-03-03` 高点 `303.94` 作为局部 B 反弹：

- 反弹幅度约 `30.34`，相对于前一大段下跌仍然有限；
- `2025-02-28` 收盘 `292.98`，但 `2025-03-03` 冲高到 `303.94` 后收回 `284.65`；
- `2025-03-03` 的上方拒绝很明显，B 腿没有发展成新的多头趋势；
- B 腿更像下跌趋势中的 bear flag/反弹测试，而不是趋势反转。

**B 腿判断：** 对空头而言位置较有利，但 B 腿后段的 `2025-03-03` 已经出现较大波动和上方拒绝，L1 的理论触发必须防止跳空和过度扩张。

### C 腿：`2025-03-04` 以后

`2025-03-04` 开盘约 `270.93`，低于 `2025-03-03` 的低点 `277.30`，随后最低到 `261.84`；`2025-03-05` 出现反弹，`2025-03-06` 再次下探到 `260.02`，之后 `2025-03-07` 和 `2025-03-10` 又继续下移。

这条 C 腿在方向上成立，但包含多个冲击/扩张 K。它适合研究“空头延续中的 L1/L2/L3 计数”，不适合直接把每一次低点突破都当成低风险订单。

## 3. L1/L2/L3 计数

### L1 候选：`2025-03-03/04`

`2025-03-03` 的 Daily O/H/L/C 约为：

```text
300.34 / 303.94 / 277.30 / 284.65
```

它可以作为 B 反弹后的第一次有意义空头尝试，而且 EMA200 是这里的重要汇合因素：

- 高点触及 `303.94` 后明显回落；
- 当日 EMA200 约为 `303.23`，最高价只略过 EMA200 约 `0.71`，随后收回到 `284.65`；
- 收盘低于开盘，且接近日内低位区域；
- 位置仍在下降背景和反弹阻力附近；
- `2025-03-04` 继续向下，方向上给出跟随。

这里要把形态判断与订单类型分开。三种订单含义不同：

1. **Sell stop：等价格向下跌破。** 如果在 `2025-03-03` 低点 `277.30` 下方设置 sell stop，意图是价格跌破低点时做空。但 `2025-03-04` 直接以 `270.93` 开盘，跳过了 `277.30`，stop-market 的实际成交不会保证在 `277`，而可能接近下一可成交价格 `270.93`，所以原来的 `277` 入场价和 2R 计算不能事后沿用。
2. **Sell limit：等价格向上反弹到指定价位卖出。** 在市场仍位于 `284.65` 附近时，挂 `284.50` 或 `277.00` 的 sell limit 并不是“等它下跌到这个价位”：如果订单在盘中提交，这两个价格都低于当时市场，属于可立即成交的 marketable limit，通常会立即在当前可得价格附近成交；如果是在收盘后提交，次日跳空到 `270.93`，它又不会在低于限价时成交，而会等待价格重新反弹到限价位。
3. **Sell limit/retest 分支：等跳空后的反弹回测。** `2025-03-04` 先下探到 `261.84`，后来反弹到 `284.35`。因此，若在跳空后重新观察并预先设定约 `284.0–284.3` 的 sell limit，确实存在一个可成交的反弹回测分支；`284.50` 则因为当日最高只有 `284.35`，不会成交。这个分支不是对原来 `277` sell stop 的补救，而是一笔新的、条件不同的 L1 交易。

因此：

- 形态上：L1 候选成立；
- 因果上：有后续跟随；
- 执行上：必须明确是向下突破的 sell stop，还是向上回测的 sell limit；不能把二者混为一谈；
- 研究上：`277` sell stop 是跳空滑点分支，`284.0–284.3` sell limit 是跳空后的新回测分支，二者必须分别统计。

### L2 候选：`2025-03-05/06`

`2025-03-04` 下跌到 `261.84` 后，`2025-03-05` 反弹到 `279.55`，重新靠近 `2025-03-03` 低点 `277.30` 和 `2025-03-04` 高点 `284.35` 的角色转换阻力。随后 `2025-03-06` 再次向下：

```text
2025-03-05：272.92 / 279.55 / 267.71 / 279.10
2025-03-06：272.06 / 272.65 / 260.02 / 263.45
```

这更像一次有位置依据的 L2：

- L1 之后出现了有意义的反弹，而不是一根 K 线内的微小噪音；
- 反弹回到先前下破区域附近，构成阻力测试；
- L2 信号方向与大周期一致；
- `2025-03-06` 的空头 K 实体清楚，收盘位置偏低，卖方再次控制。

但 L2 仍不能自动授权做空。若以 `2025-03-05` 低点 `267.71` 下方作为较早确认，结构止损放在 `279.55` 上方，风险约 `11.84`。当时最先可见的前低支撑约在 `261.84`，空间只有约 `5.87`，约为 `0.50R`。

所以这个案例的正确标签是：**L2 形态和位置成立，但 Daily 交易跳过，因为第一道支撑太近。**

### L3/第三推候选：`2025-03-07/10`

`2025-03-07` 继续下探到 `250.73`，但收盘回到 `262.67`；`2025-03-10` 又出现开盘后快速下跌，最低到 `220.00`，收盘约 `222.15`。

这段可以作为 L3/第三推研究候选，但不能冻结成标准 L3：

- 第三次下探的压力确实继续出现；
- 但 `2025-03-10` 是异常扩张和卖出高潮性质的 K，成交量约 `1.89` 亿，远高于前几天；
- 第三推没有表现出稳定的动能衰竭，反而出现了加速；
- 它不能因为“第三次下跌”就自动被解释为反转做多，也不能因为 L3 就追空。

这正好验证了当前项目的边界：`L3` 是第三次尝试的计数标签；三推楔形还需要逐推减弱、位置和反向确认。这里更像“空头延续中的第三推/卖出高潮候选”，不是已确认的三推楔形反转。

## 4. 60m 与 15m 触发审计

### L1 的三种订单分支

`2025-03-03` 60m 后半段从约 `300` 区域快速跌到 `277.30`，但第二天直接以 `270.93` 开盘。方向判断可能正确，但订单类型决定了“计划是否被跳过”：

#### 分支 A：`277.30` 下方 sell stop

- 这是追随向下突破的订单；
- 跳空开在 `270.93`，会产生跳过触发价和滑点；
- 不能按 `277.30` 入场、`303.94` 止损、约 `220–222` 目标去回填一个“已成交”的 2R 案例；
- 如果实际成交在 `270.93` 附近，风险距离变大，且下方空间已经被压缩，必须重新计算，不能追认原 R/R。

#### 分支 B：收盘附近的 sell limit

- 如果在 `2025-03-03` 仍处于盘中、市场在 `284.65` 附近时提交 `284.50` 或 `277.00` 的 sell limit，订单会因为价格已经高于限价而倾向于立即成交；它不是等待下跌；
- 如果在收盘后提交，次日 `270.93` 的开盘低于限价，订单不会成交，只有重新反弹到限价位才会成交；
- 因此，必须记录订单提交时点，而不能只记录一个价格。

#### 分支 C：跳空后的反弹回测 sell limit

- `2025-03-04` 先出现低点 `261.84`，随后最高反弹到 `284.35`；
- 重新观察后，在 `284.0–284.3` 附近设置 sell limit，属于等待反弹回测阻力的计划；
- 当日 `284.50` 没有被触及，因此 `284.50` 不会成交；
- 若成交在约 `284.0`，结构止损可研究性地放在 `303.94`/EMA200 阻力上方，约为 `304` 上方；第一已知支撑约 `261.84`，到第一支撑约 `1.1R`，到 `220–222` 的扩展目标约 `3R` 以上；
- 这是一笔新的回测交易，不是把原来 `277` 的 sell stop 改名为 limit order。

这与多头案例 `2025-09-05` 的跳空问题对称：跳空后的结果不能替代原来的可成交触发，但也不能因此否定跳空后重新形成的回测机会。

### L2：有低周期下行，但空间仍近

`2025-03-06` 15m 开盘后第一根研究 K 从 `272.06` 下探到 `264.40`，随后价格继续在 `260–270` 之间向下推进。它证明空头方向有跟随，但也说明：

- 若使用 `2025-03-05` 低点 `267.71` 作为 sell stop，触发过程发生得很快；
- 最近的 `2025-03-04` 低点 `261.84` 仍然很近；
- 低周期没有把第一道支撑从交易几何中消除，只是让执行更细。

因此，不能仅因为 15m 出现了漂亮的连续空头 K，就把 L2 从 `0.50R` 变成合格交易。

## 6. R/R 审计

### L1 理论方案：分别审计突破与回测

若在 `2025-03-03` 低点 `277.30` 下方设置 sell stop：

- 止损需要放在 `303.94` 或更完整结构高点上方；
- 当时最近的支撑和前低已经很近；
- `2025-03-04` 跳空到 `270.93`，理论入场被跳过。

正确动作是重新计算实际成交和第一支撑，而不是把 `277.30` 的旧 R/R 继续沿用。用户提出的“风险约 `27–28`、目标约 `54`、约 `2R`”只有在确实以约 `277` 成交时才成立；它不能由 sell limit 在 `277` 自动实现。

若等跳空后的反弹回测，在约 `284.0` 研究性成交：

```text
研究入场：约 284.0
结构止损：约 304.0 上方
风险：约 20.0
第一支撑：约 261.84
第一支撑空间：约 22.16，约 1.1R
扩展目标：约 220–222，约 3.1R–3.2R
```

这个回测分支的第一障碍已经超过约 `1R`，所以比 `277` 下方突破后的实际跳空成交更有可研究性；但它仍需要在当时确认信号、滑点、成交量和事件风险，不能直接变成实盘规则。

### L2 理论方案：形态成立，第一障碍不足

若以 `267.71` 下方作为确认，止损放在 `279.55` 上方：

```text
理论入场：约 267.70
结构止损：约 279.55 上方
风险：约 11.84
第一支撑：约 261.84
第一障碍空间：约 5.87
第一障碍 R/R：约 0.50R
```

即使后面价格继续下跌，L2 在当时也不满足我们的 Daily 新仓标准。要么等待更清楚的低周期二次结构并承认它是另一笔短线交易，要么跳过。

## 7. 与三个多头案例的对称比较

这个空头样本强化了三案例矩阵中的几条共同规律：

1. **强 A 不等于可以在任何位置追。** 空头 A 很强，但靠近 `261–267` 支撑后，继续追空的空间同样会被第一障碍限制。
2. **L1/L2 与 H1/H2 对称。** L1 主要用来观察第一次尝试是否失败；L2 需要第一次失败、反弹测试、位置和确认共同成立。
3. **跳空会改变执行状态，但不等于所有交易分支都失效。** `2025-03-04` 的 `277.30` sell stop 受到跳空滑点影响；然而，跳空后的 `284.0–284.3` 反弹回测可以作为一笔新的 sell-limit 分支单独评估。
4. **L3 不等于三推反转。** `2025-03-07/10` 继续加速下跌，说明第三次尝试可以是趋势延续或卖出高潮，而不是自动反转。
5. **第一障碍对多空同样有效。** 多头看前方阻力，空头看前方支撑；任何一方的第一障碍不到约 `1R`，都应降低等级或跳过。
