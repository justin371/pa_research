## 状态与范围

- 标的：TSLA
- 结构背景窗口：`2025-01-31` 至 `2025-03-10`
- 原始后段复核窗口：`2025-02-19` 至 `2025-03-10`
- 周期：Daily、60m、15m；4H 只用 60m 研究块观察

## 一句话结论

这段研究的关键修正是：不能等到 `2025-02-19` 才回头寻找 A 腿。对实时交易而言，较大的 A 下跌腿已经在 `2025-01-31` 至 `2025-02-11` 形成；`2025-02-12` 至 `2025-02-19` 是 B 反弹/回测，`2025-02-20` 已经应该评估较早的 L2/第二次空头尝试。原来的 `2025-02-19` 至 `2025-03-10` 只是后段子窗口，适合研究后续 L1/L2/L3 和跳空执行，不能被当作第一次寻找 A 腿的时间点。

## 0. 事后结构标签与实时决策时间线

之前把 `2025-02-19` 写成 A 腿起点，是研究流程上的错误：我把“事后把整段行情分成 A/B/C”误当成了“实盘什么时候开始寻找 A 腿”。A 腿是结构标签，不是等到完整走势走完之后才开始观察的信号。

正确的实时顺序是：

1. `2025-01-31` 的高点 `419.99` 到 `2025-02-11` 的低点 `325.10`，已经可以标记为 A 腿候选；更大的空头背景可以追溯得更早，但本例的局部 A/B 研究从这里开始最清楚。
2. A 腿形成后，立即寻找 B 腿结束的位置，不等 C 腿完成。`2025-02-12` 至 `2025-02-19` 是反弹和回测：`2025-02-12/13` 是主要反弹，`2025-02-14/18` 出现停顿，`2025-02-19` 又上探到 `367.34`，更像 B 腿的最后一次测试。
3. `2025-02-20` 跌破 `2025-02-19` 低点 `353.67`，应至少列为较早的 L2/第二次空头尝试候选。它的日线收盘不够干脆，所以要区分“盘中触发的条件性短线机会”和“日线收盘确认”。
4. `2025-02-21` 的下跌跟随更清楚，但这属于确认更晚、价格可能更差的分支；不能用它倒推说 `2025-02-20` 没有研究价值。

因此，后文的 `2025-03-03/04` L1、`2025-03-05/06` L2 和 `2025-03-07/10` L3，是同一空头背景中更后面的延续子样本，不是这段行情第一次出现空头入场机会的时刻。今后每个案例同时记录“最早可识别的 A 日期”和“实际决策/触发日期”。

## 1. 大周期背景

在本案例的更大窗口内，TSLA 已经从高位回落，价格位于下降的 EMA20/EMA50 下方。`2025-01-31` 的高点 `419.99` 之后，`2025-02-03` 至 `2025-02-11` 出现多根扩张阴线，形成了可供实时交易使用的强空头 A 腿。`2025-02-19` 的高点 `367.34` 不是一个全新牛市高点，而是 A 腿之后 B 反弹的最后一次上探。之后价格连续走低，直到 `2025-02-27/28` 附近跌至 `273.60–280.88`。

这决定了本案例的方向许可：

`2025-03-06` 当日 SPY、QQQ 和 XLY 均收弱，市场与可选消费背景没有给 TSLA 多头提供明显许可；这支持空头方向，但不替代个股触发。

## 3. L1/L2/L3 计数

### 较早的 L2/第二次空头尝试候选：`2025-02-20`

按这段行情的实时读法，用户指出的重点是正确的：`2025-02-20` 不应被跳过。它至少应该被列为 B 腿结束后的 L2/第二次空头尝试候选。

```text
2025-02-19：354.00 / 367.34 / 353.67 / 360.56
2025-02-20：361.51 / 362.30 / 348.00 / 354.40
2025-02-21：353.44 / 354.98 / 334.42 / 337.80
```

- `2025-02-20` 盘中跌破 `2025-02-19` 低点 `353.67`，这提供了向下触发点；
- 但当天收盘 `354.40` 又收回到前一日低点上方，日线信号 K 的收盘质量不如 `2025-02-21`；
- 因此，`2025-02-20` 可以是低周期确认后的条件性短线空头，也可以是日线系统中的 L2 setup/attempt，不能简单写成“没有交易”；
- 若要求日线收盘确认，`2025-02-21` 更清楚，但它是更晚的确认，不是最早的机会；
- 以 `353.67` 附近触发、结构止损放在 `367.34` 上方时，必须先面对已经可见的 `350.02–347.50` 支撑簇；`329.12–325.10` 是后面的更深支撑，不能跳过第一障碍直接拿来证明 R/R。这个 L2 的研究价值主要在于“更早识别”，不等于 Daily 全风险交易已经合格。

计数上不必把争论变成僵硬标签：如果把 `2025-02-14/18` 的早期卖方尝试算作失败的 L1，`2025-02-20` 就是 L2；如果认为那两天没有形成合格的信号 K，`2025-02-20` 也可以写成第一次清晰的空头触发候选。两种写法都不改变核心结论：**实时工作应在 `2025-02-11` 之后寻找 B 结束和空头入场，而不是等到 `2025-02-19` 之后才开始寻找 A。**

### `2025-02-20` 的低周期和订单分支审计

这次补充只审计入场当时可见的 Daily、60m 和 15m 数据，不把 `2025-02-21` 之后的结果拿回去证明 `2025-02-20`。

#### 触发前能看到什么

截至 `2025-02-19` 收盘，已知信息是：

- A 腿已经在 `2025-02-11` 前形成；
- B 反弹在 `2025-02-19` 上探 `367.34` 后再次受压；
- `2025-02-19` 低点 `353.67` 是下一个可定义的空头触发位；

- `2025-02-11/12` 的 `325.10–329.12` 是更深一层、但不是第一道障碍的支撑区。

因此，不能只看到强 A 和 B 失败就预设“下跌空间很大”；触发后首先要面对 `350.02–347.50`。

#### 15m 的实际顺序

```text
2025-02-20 09:45：O361.51 / H362.30 / L355.06 / C356.11
2025-02-20 10:00：O356.14 / H356.52 / L350.45 / C350.71
2025-02-20 10:15：O350.75 / H351.84 / L348.00 / C351.04

```

`10:00` 已经跌破 `353.67`，并且收盘靠近日内低位，形式上可以作为低周期空头触发候选；但它几乎立即进入 `350.02–347.50` 支撑簇。`10:15` 下探到 `348.00` 后收回到 `351.04`，随后价格重新回到 `354` 附近，这说明卖方没有在第一障碍前形成干净跟随。

这带来两个结论：

1. `2025-02-20` 的低周期触发不是不存在，而是“触发及时、位置不划算、跟随不足”；
2. 如果把 `10:15` 的低点 `348.00` 下方再作为卖出触发，订单已经靠近或穿过第一支撑，不能把它包装成更高质量的 L2。

### L1 候选：`2025-03-03/04`

`2025-03-03` 的 Daily O/H/L/C 约为：

```text
300.34 / 303.94 / 277.30 / 284.65
```

它可以作为 B 反弹后的第一次有意义空头尝试，而且 EMA200 是这里的重要汇合因素：

- 高点触及 `303.94` 后明显回落；
- 当日 EMA200 约为 `303.23`，最高价只略过 EMA200 约 `0.71`，随后收回到 `284.65`；
- 收盘低于开盘，且接近日内低位区域；
- 位置仍在下降背景和反弹阻力附近；
- `2025-03-04` 继续向下，方向上给出跟随。

这里要把形态判断与订单类型分开。三种订单含义不同：

1. **Sell stop：等价格向下跌破。** 如果在 `2025-03-03` 低点 `277.30` 下方设置 sell stop，意图是价格跌破低点时做空。但 `2025-03-04` 直接以 `270.93` 开盘，跳过了 `277.30`，stop-market 的实际成交不会保证在 `277`，而可能接近下一可成交价格 `270.93`，所以原来的 `277` 入场价和 2R 计算不能事后沿用。
2. **Sell limit：等价格向上反弹到指定价位卖出。** 在市场仍位于 `284.65` 附近时，挂 `284.50` 或 `277.00` 的 sell limit 并不是“等它下跌到这个价位”：如果订单在盘中提交，这两个价格都低于当时市场，属于可立即成交的 marketable limit，通常会立即在当前可得价格附近成交；如果是在收盘后提交，次日跳空到 `270.93`，它又不会在低于限价时成交，而会等待价格重新反弹到限价位。
3. **Sell limit/retest 分支：等跳空后的反弹回测。** `2025-03-04` 先下探到 `261.84`，后来反弹到 `284.35`。因此，若在跳空后重新观察并预先设定约 `284.0–284.3` 的 sell limit，确实存在一个可成交的反弹回测分支；`284.50` 则因为当日最高只有 `284.35`，不会成交。这个分支不是对原来 `277` sell stop 的补救，而是一笔新的、条件不同的 L1 交易。

因此：

- 形态上：L1 候选成立；
- 因果上：有后续跟随；
- 执行上：必须明确是向下突破的 sell stop，还是向上回测的 sell limit；不能把二者混为一谈；
- 研究上：`277` sell stop 是跳空滑点分支，`284.0–284.3` sell limit 是跳空后的新回测分支，二者必须分别统计。

### L2 候选：`2025-03-05/06`

`2025-03-04` 下跌到 `261.84` 后，`2025-03-05` 反弹到 `279.55`，重新靠近 `2025-03-03` 低点 `277.30` 和 `2025-03-04` 高点 `284.35` 的角色转换阻力。随后 `2025-03-06` 再次向下：

```text
2025-03-05：272.92 / 279.55 / 267.71 / 279.10
2025-03-06：272.06 / 272.65 / 260.02 / 263.45
```

这更像一次有位置依据的 L2：

- L1 之后出现了有意义的反弹，而不是一根 K 线内的微小噪音；
- 反弹回到先前下破区域附近，构成阻力测试；
- L2 信号方向与大周期一致；
- `2025-03-06` 的空头 K 实体清楚，收盘位置偏低，卖方再次控制。

但 L2 仍不能自动授权做空。若以 `2025-03-05` 低点 `267.71` 下方作为较早确认，结构止损放在 `279.55` 上方，风险约 `11.84`。当时最先可见的前低支撑约在 `261.84`，空间只有约 `5.87`，约为 `0.50R`。

所以这个案例的正确标签是：**L2 形态和位置成立，但 Daily 交易跳过，因为第一道支撑太近。**

### L3/第三推候选：`2025-03-07/10`

`2025-03-07` 继续下探到 `250.73`，但收盘回到 `262.67`；`2025-03-10` 又出现开盘后快速下跌，最低到 `220.00`，收盘约 `222.15`。

这段可以作为 L3/第三推研究候选，但不能冻结成标准 L3：

- 第三次下探的压力确实继续出现；
- 但 `2025-03-10` 是异常扩张和卖出高潮性质的 K，成交量约 `1.89` 亿，远高于前几天；
- 第三推没有表现出稳定的动能衰竭，反而出现了加速；
- 它不能因为“第三次下跌”就自动被解释为反转做多，也不能因为 L3 就追空。

这正好验证了当前项目的边界：`L3` 是第三次尝试的计数标签；三推楔形还需要逐推减弱、位置和反向确认。这里更像“空头延续中的第三推/卖出高潮候选”，不是已确认的三推楔形反转。

## 4. 60m 与 15m 触发审计

### L1 的三种订单分支

`2025-03-03` 60m 后半段从约 `300` 区域快速跌到 `277.30`，但第二天直接以 `270.93` 开盘。方向判断可能正确，但订单类型决定了“计划是否被跳过”：

#### 分支 A：`277.30` 下方 sell stop

- 这是追随向下突破的订单；
- 跳空开在 `270.93`，会产生跳过触发价和滑点；
- 不能按 `277.30` 入场、`303.94` 止损、约 `220–222` 目标去回填一个“已成交”的 2R 案例；
- 如果实际成交在 `270.93` 附近，风险距离变大，且下方空间已经被压缩，必须重新计算，不能追认原 R/R。

#### 分支 B：收盘附近的 sell limit

- 如果在 `2025-03-03` 仍处于盘中、市场在 `284.65` 附近时提交 `284.50` 或 `277.00` 的 sell limit，订单会因为价格已经高于限价而倾向于立即成交；它不是等待下跌；
- 如果在收盘后提交，次日 `270.93` 的开盘低于限价，订单不会成交，只有重新反弹到限价位才会成交；
- 因此，必须记录订单提交时点，而不能只记录一个价格。

#### 分支 C：跳空后的反弹回测 sell limit

- `2025-03-04` 先出现低点 `261.84`，随后最高反弹到 `284.35`；

## 8. 与三个多头案例的对称比较

这个空头样本强化了三案例矩阵中的几条共同规律：

1. **强 A 不等于可以在任何位置追。** 空头 A 很强，但靠近 `261–267` 支撑后，继续追空的空间同样会被第一障碍限制。
2. **L1/L2 与 H1/H2 对称。** L1 主要用来观察第一次尝试是否失败；L2 需要第一次失败、反弹测试、位置和确认共同成立。
3. **跳空会改变执行状态，但不等于所有交易分支都失效。** `2025-03-04` 的 `277.30` sell stop 受到跳空滑点影响；然而，跳空后的 `284.0–284.3` 反弹回测可以作为一笔新的 sell-limit 分支单独评估。
4. **L3 不等于三推反转。** `2025-03-07/10` 继续加速下跌，说明第三次尝试可以是趋势延续或卖出高潮，而不是自动反转。
5. **第一障碍对多空同样有效。** 多头看前方阻力，空头看前方支撑；任何一方的第一障碍不到约 `1R`，都应降低等级或跳过。
