# H3/L3 独立候选筛选日志：2025-08 至 2025-11

状态：`visual-screen / boundary-log / not-quantitative`

## 证据头

- 数据：Futu OpenD 历史 QFQ Daily 图表，收盘后读取；本轮只做第一阶段视觉筛选，没有假装获得实时行情。
- 目的：在 KLAC H3 正向候选之外，寻找第二个同样具有清楚第三次尝试、反向触发和第一障碍空间的独立样本。
- 结果：本轮暂未找到足以升级为 H3/L3 正向候选的图。以下样本保留为边界，原因是它们对“不要把趋势延续/宽区间误读为 H3”有学习价值。

## 1. AVGO：强趋势中的重复回调，不冻结为 H3/L3

`2025-05`–`2025-08` 的整体背景是明显上涨，局部确实有多次回踩 EMA20、支撑或前一停顿区的机会。但这些回踩之间没有稳定、独立的三次同级别失败尝试；很多位置只是强趋势中的浅回调和继续推进。

- 视觉上可以提名若干 H1/H2-like 延续，但不能把连续上涨后的每一次小回调都数成 H3；
- `2025-06` 和 `2025-07` 的候选上方往往紧接前高，第一阻力先于 MM，空间不宽；
- 低周期没有继续补审，因为第一阶段尚未形成一个明确、可复核的 H3 lineage。

当前标签：`strong-trend-continuation / H1-H2-like / not-confirmed-H3 / first-obstacle-crowded`。

## 2. MSFT：方向很强，但没有清楚的第三次独立尝试

`2025-05`–`2025-07` 的高低点大体上移，趋势控制较强。局部回调多为一两天的浅整理，随后重新向上；这对 H1/H2 研究有价值，但不构成清楚的三次反复失败。

- 若把每次 EMA20 附近的小回踩都计数，会把强趋势的普通延续夸大成 H3；
- 某些触发附近接近前一高点或主要高点簇，第一阻力不够宽；
- 当前没有独立的 H3 反向触发和结构止损合同。

当前标签：`strong-trend / shallow-pullback / not-h3-l3 / observation-only`。

## 3. PANW：形态有候选，但 B 与首障碍仍不够干净

`2025-09`–`2025-10` 可以看到一条上涨背景、回调和再次恢复的外形。`2025-09-23`–`09-25` 的回调较深，后续重新向上；另一段 `2025-10` 的回调也能画出 H1/H2-like 结构。

- 这些恢复更像一到两次趋势延续，不足以确认第三次同级别尝试；
- B 末端和前高区之间的空间偏紧，首障碍在低周期触发前后容易先到；
- 事件/高波动背景尚未单独完成过滤，因此不把它升级成 H3/L3 正向样本。

当前标签：`pattern_like / H1-H2-like / H3-count-unclear / first-obstacle-boundary / event-context-pending`。

## 4. MRVL：恢复强，但事件/缺口和宽波动改变了结构解释

`2025-08-29` 之后的恢复很强，`2025-09`–`10` 也有多次回调和重新上行。但大范围跳空、长实体和宽幅反向 K 线使母腿与局部腿难以稳定分层。

- 不能把事件/缺口驱动的恢复直接当作普通趋势 H3/L3；
- `2025-10` 的局部回调虽然有多次测试，但重叠与波动范围较大，接近复杂 B 或过渡，而不是清楚的衰竭三推；
- 首障碍、结构止损和订单分支尚未冻结，因此保持观察。

当前标签：`event-gap-recovery / wide-volatility / count-unclear / boundary`。

## 5. DELL：下跌中的反弹多次出现，但 B 更像宽区间/过渡

`2025-08`–`2025-11` 先出现下跌，随后多次反弹和回落。局部可以看到三次上探的外形，但反弹之间重叠大，且父级状态在趋势和区间过渡之间切换。

- 三次上探不能自动称为熊旗 H3；
- B 过宽、来回穿越均线，优先使用区间/过渡逻辑；
- 没有满足开放趋势 H3 的计数和首障碍前置条件。

当前标签：`range-transition / provisional-H3-like / not-open-trend-ABC / observation-only`。

## 当前筛选结论

本轮没有新增 H3/L3 正向案例，但补强了三个保护判断：

1. 强趋势中的重复浅回调，不等于 H3/L3；
2. 事件/缺口造成的强恢复，必须先与普通趋势结构分开；
3. 三次上探若伴随宽 B、重叠和区间化，优先降级为过渡/区间边界。

KLAC 仍是当前 H3 研究基准；本日志中的样本不进入低周期订单审计，直到出现明确的同一 lineage、第三次尝试、反向触发和首障碍空间。
