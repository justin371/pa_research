# VCP / Minervini 定义与视觉证据缺口审计

日期：2026-08-24  
状态：`independent-system / visual-workable / provisional / no-new-positive`

## 0. 结论先行

VCP 已经可以建立一套供视觉助手使用的工作版定义：**强势股票的上涨背景中，整理母体内连续出现越来越窄的回撤/波动收缩，供应和成交量趋于减弱，最后收缩上方形成 pivot，价格在需求/成交量支持下突破并接受。**

这套语言足以开始筛选候选，但还不能宣称“VCP 已完成验证”，也不能把任何漂亮的窄区间当成 VCP。当前最重要的边界是：

1. VCP 是 Minervini / SEPA 的独立多头 setup，不属于 Al Brooks 核心八个 PA pattern；
2. `2–4`、`2–6`、每次约半幅、最终收缩低于某个固定百分比等，来自二手教学的常见描述，不在本仓库冻结为硬阈值；
3. 原始书籍和旧官方文章目前没有在本项目中完整提供，旧官方文章 URL 也已返回 404，所以本文件把“已交叉支持”“二手总结”“待回到原书核对”明确分开；
4. 当前还没有完成事件干净、无后见之明、pivot/首阻力/实际路径 R/R 都能复核的 PA Research VCP 正向案例，状态保持 `no-new-positive`。

### C. 不采用为硬规则的说法

以下内容在网络二手资料中反复出现或被某些文章写得很精确，但本轮没有足够的原始证据把它们冻结：

- 每次收缩必须严格是前一次的 50%；
- 必须恰好 3 或 4 次收缩；
- 必须出现 20%→10%→5% 或某个固定百分比序列；
- 最终量能必须低于 50 日均量的某个固定比例；
- 突破必须达到某个固定放量倍数；
- pivot 后固定 5% 以内才允许买；
- 所有 VCP 都使用 4–5% 或固定百分比止损；
- 任意网络文章声称的成功率、失败率或“80% 正例”。

这些数字若以后需要，只能作为待核对的实验字段，而不是现行交易规则。

## 2. PA Research 采用的视觉工作定义

### 必须先有的前置条件

- 左侧有清楚的上行领导/相对强势证据；
- 整理发生在有意义的位置，通常是强势上涨后的母体，而不是长期下跌后的反弹；
- 市场和板块环境没有明显与多头 setup 冲突的证据；
- 财报前三个交易日不新开仓，这是 PA Research 的用户覆盖规则，不声称是 Minervini 原始定义。

### 母体内要观察的东西

对 T1、T2、T3…逐次记录：

| 字段 | 视觉问题 | 当前强度 |
| --- | --- | --- |
| 价格幅度 | 后一次高低摆动是否明显比前一次窄 | 核心 |
| 低点结构 | 是否守住前一收缩的关键低点，或出现快速 shakeout 后恢复 | 核心辅助 |
| 持续时间 | 后一次是否更快收敛 | 加分项，非必要 |
| 重叠与收盘 | 是否由宽幅、混乱变成窄幅、收盘稳定 | 核心辅助 |
| 成交量 | 回撤/下跌是否总体减量，末端是否安静 | 重要参考，非必要 |
| 供应反应 | 下跌是否越来越难推动价格，反弹是否更容易恢复 | 核心解释层 |
| pivot | 最后收缩上沿和独立阻力是否可在当时定义 | 核心 |

“每一推都更弱”不是 VCP 的表达。VCP 关注的是**收缩序列和供应减少**，不是 Brooks 三推的反转压力计数；如果后一次下跌反而扩张，应优先考虑分配、失败或新父级状态。

## 3. 交易合同（研究版）

### 标准 breakout 合同

1. 在最后收缩形成后，事先画出 pivot；
2. 价格以 stop-entry / buy-stop 方式越过 pivot；
3. 检查突破 K 的收盘、需求、成交量和后续接受；
4. 止损放在最后收缩低点或其下方的结构位置；
5. 入场前先检查第一独立阻力和粗略 R/R；
6. 如果跳空过远、临近财报、板块/市场冲突或首阻力太近，使用 `no-trade`、`gap-reprice` 或 `wait-for-new-base`。

### 非标准、必须分开记录的合同

- 母体内提前 limit / cheat：这是假设性提前入场，不能和 pivot 确认混合；
- pivot 突破后回踩：可以与 Brooks BOP/H1/H2 结合，但它是新交易合同；
- 财报跳空：先标记事件，不把跳空结果写成 VCP 本身的证明；
- 低周期触发：只能确认高周期合同或形成独立低周期合同，不能替代日线/周线母体证据。

## 4. 失败与否决

### 直接否决或降级

- 后一次收缩比前一次明显更深/更宽；
- 放量下跌破坏最后收缩低点或母体关键支撑；
- 价格尚未形成清楚 pivot，只是在区间中部来回；
- 突破没有需求、收盘回到 pivot 下方，或很快重返母体；
- 突破后第一独立阻力贴得太近，实际 R/R 不成立；
- 事件、板块或大盘环境使多头假设失去背景支持。

### 不能用后见之明补救

后续暴涨不能证明当时的收缩已完成；后续暴跌也不能把当时所有窄区间 retroactively 叫作“失败 VCP”。每个端点、pivot、止损和首障碍都必须只用当时可见的 K 线记录。

## 5. 与当前 PA pattern 的接口

| VCP 阶段 | 可借用的 PA 观察 | 不可混淆之处 |
| --- | --- | --- |
| 母体形成 | 背景、支撑/阻力、EMA、缺口、META | 这些不是 VCP 的收缩定义 |
| pivot 突破 | BOP 的接受、强信号 K、突破回踩 | VCP 是 setup lineage，BOP 是状态/交易合同 |
| 突破后回撤 | H1/H2、支撑测试、缺口回补 | 不能把一次 H2 反向命名为 VCP |
| 失败 | 失败突破、高潮、MTR 观察 | 失败分类仍按 PA 状态，不回写 VCP 原定义 |

## 6. 当前证据状态与下一步

当前没有把 KLAC、TSLA、NFLX、TSM 或已有 ABC/H-L 案例强行升级为 VCP。它们可以在后续筛选中作为候选，但必须重新按 VCP 的母体、T1/T2/T3、pivot 和成交量证据审计。

下一轮只增加能填补以下缺口的图表：

- 事件干净、强势背景清楚、至少两次收缩且最后 pivot 可定义的多头候选；
- 后一次收缩扩张/放量破坏的失败对照；
- 突破高开、回踩、首阻力或财报前三日否决的订单分支；
- 同一 VCP setup 在日线与 4H/1H/15m 上的高周期合同与低周期确认对照。

在这些案例完成前，结论只能是 `visual-workable / provisional / no-new-positive`，不能移交 Codex Trading 做程序化实现。
