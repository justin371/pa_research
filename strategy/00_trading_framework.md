# Trading Framework

## Core Methods

- Al Brooks Price Action
- Wyckoff volume and price analysis
- META: Multiple Edge Trading Area

## Analysis Order

1. Market context
2. Higher-timeframe structure
3. Trading location
4. Pattern
5. Trigger
6. Invalidation
7. Target
8. Trade management

## Principle

A pattern alone is not enough. Prefer setups where multiple independent edges converge.
