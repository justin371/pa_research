# PA Research Knowledge

这里集中放置 PA Research 的学习资料摘要、方法论和验证记录。内容是基于来源整理的原创笔记，不复制书籍全文。

## 目录

- [Al Brooks Price Action 学习笔记](./al_brooks_pa_notes.md)：趋势、交易区间、突破、反转、三推/楔形、入场与失效条件。状态：研究草稿。
- [Kaufman 系统开发与回测参考](./kaufman_systems_backtest_notes.md)：规则形式化、回测设计、成本、稳健性、风险与样本外验证。状态：参考草稿。

## 使用边界

1. PA 笔记负责描述行情结构和候选交易逻辑。
2. 系统与回测笔记负责把可重复的规则转成可验证流程；主观标签不能直接当作已验证策略。
3. META 是多重优势汇聚的背景框架，不是自动买卖触发器。VCP 将单独建档。
4. 所有规则在进入实盘或生产回测前，都要补充明确条件、数据范围、成本假设和验证结果。
