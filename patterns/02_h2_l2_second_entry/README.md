# H2 / L2：第二次入场

状态：`visual-research / provisional / primary`

## 研究目的

实现趋势回调中的第二次方向尝试：多头看 H2，空头看 L2。当前这是最优先的趋势延续主线，但 H2/L2 仍必须服从背景、位置和空间。

## 视觉定义

- 父级方向明确，A 腿有足够方向性；
- 第一次方向尝试失败或没有走出，回调再走一腿；
- 第二次尝试在 EMA20/50、前高前低、角色转换或其他结构区出现；
- 信号 K 先下探后收回、实体完整或有清楚的拒绝尾巴；
- 触发后到第一独立障碍有实际空间，结构止损位置自然。

## 重点比较

1. 强 A 与普通 A；
2. 浅 B 与深但后段受控 B；
3. 趋势中的 H2/L2 与区间边缘的 H2/L2；
4. 同一高周期合同的低周期确认与独立低周期交易；
5. 首障碍先到、结构止损先失效和真正达到 MM 的区别。

## 主要失效

区间中部强行计数、B 已接受反向趋势、第二次尝试仍无跟随、跳空越过旧触发、财报窗口、首障碍不足约 1R。以上都是视觉审计结论，不是固定数值规则。
