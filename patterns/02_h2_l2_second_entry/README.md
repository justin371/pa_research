# H2 / L2：第二次入场

状态：`visual-research / provisional / primary`

## 研究目的

实现趋势回调中的第二次方向尝试：多头看 H2，空头看 L2。当前这是最优先的趋势延续主线，但 H2/L2 仍必须服从背景、位置和空间。

## 视觉定义

- 父级方向明确，A 腿有足够方向性；
- 第一次方向尝试失败或没有走出，回调再走一腿；
- 第二次尝试在 EMA20/50、前高前低、角色转换或其他结构区出现；
- 信号 K 先下探后收回、实体完整或有清楚的拒绝尾巴；
- 触发后到第一独立障碍有实际空间，结构止损位置自然。

H2/L2 的“第二次”是同一回调中的第二次有意义的方向尝试，不是第二根阳线/阴线，也不是任意局部高点/低点突破。出现新趋势极值、回调演变成交易区间或关键结构被接受后，旧计数必须重新评估。

## 最小审计模板

| 字段 | 多头 H2 | 空头 L2 |
| --- | --- | --- |
| `parent_state` | 开放上涨趋势、支撑反应或被接受的多头延续 | 开放下跌趋势、阻力反应或被接受的空头延续 |
| `A_leg` | 买压方向性、跟随和重叠 | 卖压方向性、跟随和重叠 |
| `B_state` | 受控，或深但后段稳定 | 受控，或深但后段稳定 |
| `first_attempt` | H1 失败/不充分/无跟随 | L1 失败/不充分/无跟随 |
| `second_attempt` | 关键支撑处 H2 反应 | 关键阻力处 L2 反应 |
| `signal_quality` | 强收阳线、先探后收、下影拒绝等 | 强收阴线、先冲高后收、上影拒绝等 |
| `trigger` | 信号 K 高点外 buy-stop，或明确低周期确认 | 信号 K 低点外 sell-stop，或明确低周期确认 |
| `failure` | 接受跌破支撑/回到触发前区域/无跟随 | 接受突破阻力/回到触发前区域/无跟随 |

## 优先级与降级

1. **强 A + 受控 B**：可以优先比较 H1；若第一次失败，再看 H2/L2。
2. **强 A + 深但后段受控 B**：H1 降级，H2/L2 仍可研究，但结构止损和首障碍要更严格。
3. **普通 A、宽通道或区间中部**：不要用 H2 编号挽救形态；先切换区间/过渡逻辑或观望。
4. **第三次及以后尝试**：转入三推/H3-L3 或 MTR 目录，不在 H2/L2 中无限计数。

## 订单分支

- `same_contract_stop`：高周期信号 K 后用 stop 确认；高周期结构止损保持不变。
- `low_cycle_confirmation`：1H/15m 只改善时序；必须说明它确认的是同一 H2/L2 合同，还是新的短线合同。
- `limit_retest`：回测支撑/阻力的限价分支单独记录，不能和原 stop 分支混算。
- `observation_only`：第一障碍太近、跳空越过触发、事件窗口、结构止损过宽或 B 已失控时，保留形态但不交易。

低周期窄止损不能用来美化日线 R/R。若交易假设改变了止损、持仓周期或目标，就必须新建合同。

## 重点比较

1. 强 A 与普通 A；
2. 浅 B 与深但后段受控 B；
3. 趋势中的 H2/L2 与区间边缘的 H2/L2；
4. 同一高周期合同的低周期确认与独立低周期交易；
5. 首障碍先到、结构止损先失效和真正达到 MM 的区别。

## 主要失效

区间中部强行计数、B 已接受反向趋势、第二次尝试仍无跟随、跳空越过旧触发、财报窗口、首障碍不足约 1R。以上都是视觉审计结论，不是固定数值规则。

## 当前目标验收

本目录进入下一阶段前，至少需要继续保留：

- 多空对称的 H2/L2 视觉定义；
- 一个形态清楚但首障碍否决的边界样本；
- 一个低周期确认与高周期合同分离的样本；
- 明确的结构止损、第一障碍、粗略 R/R 和 no-trade 分支。

本轮专项审计的结论是：多头 H2 已有条件性覆盖，但仍缺事件干净、开放趋势、首障碍宽裕的普通基准；空头 L2 已有计数和失败边界，但仍缺同等条件的对称正例。低周期窄止损与高周期结构止损必须按不同合同记录，静态 R/R 不能替代路径审计。

在这些条件满足前，H2/L2 仍是研究候选，不是生产规则或自动下单规则。
