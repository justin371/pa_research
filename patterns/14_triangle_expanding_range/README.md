# Triangle / 三角形、扩张三角形与区间内区间

文档状态：`document_status=research_only / document_maturity=provisional / handoff_status=not_ready / not-quantitative`

完整案例先套用[`PA Research 统一输出合同 v0.1`](../../docs/pa_research_output_schema_v0_1_CN.md)；本目录只补两侧边界、压缩/扩张和突破接受或失败。三角形中部没有有效方向时必须写 `no_valid_direction`。

三角形研究的是双向市场中的压缩、边界测试和状态切换。它不是两点连线、普通趋势旗形或区间中部的一次摆动。扩张三角形也不是自动的反转形态；方向必须由位置、突破接受/失败、跟随和风险合同决定。

## 最小定义

### 收缩三角形

至少需要：

- 同一父级背景内有双向摆动；
- 上方高点逐步降低、下方低点逐步抬高，或两侧边界明确收窄；
- 两侧都有多次可见测试/反应，不是只有两个点；
- 摆动幅度收缩，但双方仍在试探；
- 位置、突破前磁铁和失效边界在当时可见。

只有一个高点和一个低点时，记为 `trendline-candidate`，不升级成三角形。

### 扩张三角形

高点更高、低点更低、波动边界向外扩张。它说明双方都能把价格推得更远，方向优势可能下降；但若后续范围、收盘和跟随继续增强，仍要防范延续或高潮扩张，不能因为“扩张”就做反向。

### 区间内区间

成熟大区间内部出现更小的收缩区间时，优先记为 `range-inside-range`。内部突破可以失败；只有区间外强收盘、跟随和回测守住，才逐步重建新趋势或 BOP 合同。重新回到小区间/父级中部时，原突破合同失效。

## 状态分流

| 状态 | 当时可见证据 | 默认处理 |
| --- | --- | --- |
| `triangle-candidate` | 两侧边界收窄、测试足够、父级仍未完全决定 | 观察边界与位置；不提前押方向 |
| `range-inside-range` | 大区间内出现小型双向压缩 | 小区间只作为子结构；区间边缘优先 |
| `expanding-triangle-boundary` | 高低点同时外扩、范围放大、第三次测试更强 | 防扩张/高潮/延续；不自动反转 |
| `breakout-acceptance-candidate` | 强收盘在边界外、跟随、回测守住 | 转 BOP/新趋势合同 |
| `failed-breakout-candidate` | 越界后重新回到原结构内，并有反向压力 | 等第二次确认或区间边缘合同 |
| `triangle-middle-no-trade` | 中线附近、首磁铁贴近、边界不清 | 观察，不交易 |
| `not-triangle-frozen` | 只有趋势线或旗形外观，测试不足 | 保留候选，不事后命名 |

## 先看什么

1. 父级是开放趋势、成熟区间、通道还是过渡；
2. 上沿、下沿和中线/磁铁是否由多次反应支持；
3. 当前在上沿、下沿还是中部；
4. 第一下突破是接受、失败还是尚未确认；
5. 是否存在 H1/H2、L1/L2，但不把三角形内部局部计数直接继承为开放趋势计数；
6. 订单、结构止损、第一独立支撑/阻力和 rough R/R 是否在决策时成立。

## 突破与订单

- **突破接受**：强收盘越过边界、外侧停留、后续跟随或回测守住；多头上沿外用 buy stop，空头下沿外用 sell stop。
- **失败突破**：第一次刺破只代表尚未接受；重新进入后，等待第二次边界失败、反向信号 K 或回测拒绝。
- **Limit-retest**：只在边界/突破区/角色转换区已经明确后使用；未回测前不假设成交，穿过边界后必须重建合同。
- **Market-close**：只给强突破收盘和空间仍充足的晚确认分支；大突破 K 接近首阻力时应降低仓位或观望。
- **Observation-only**：测试不足、中部、第一障碍拥挤、事件跳空改变成交，或只靠窄止损制造 R/R。

结构止损：收缩三角形突破至少覆盖边界和最近有效摆动；扩张三角形反向要放在最后一次测试极端外；区间内区间要明确是小区间失效还是父级边缘失效，不能混写。目标先看最近独立支撑/阻力、另一侧边界或父级中线，再看三角形高度/MM；第一障碍不足约 1R 记为 `valid_no_trade`，约 2R 只是波段参考。

## 与相邻 pattern 的边界

- **Inside Bar / IOI**：微观母子 K 范围压缩；三角形需要更大级别的双向摆动和多次边界测试。
- **普通旗形**：趋势中的反向小回调，原方向惯性占优；没有双向测试和收窄边界时不叫三角形。
- **交易区间**：成熟区间的上下沿和中部逻辑优先；小三角形不能改变父级状态。
- **BOP**：只有突破接受后才切换成 BOP；突破前不能把三角形当成已完成突破。
- **失败突破/高潮**：刺破后重新进入才开启失败分支；扩张本身不等于高潮或 MTR。
- **Final Flag/MTR**：末端背景或结构破坏需要单独确认，三角形外观不是反转授权。
