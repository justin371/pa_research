# H1 / L1：第一次入场

文档状态：`document_status=adopted / research_state=provisional / handoff_status=not_ready / not-quantitative`

完整案例先套用[`PA Research 统一输出合同 v0.1`](../../docs/pa_research_output_schema_v0_1_CN.md)；本目录只补 H1/L1 的第一次有意义尝试。方向、事件闸门、订单合同、结构止损、首障碍和分轴状态不能省略。

## 研究目的

实现强方向 A 腿后的第一次恢复：多头看 H1，空头看 L1。H1/L1 不是“碰到 EMA 后的第一根 K”，而是回调结束、方向尝试重新出现并位于有意义结构位置的候选。

## 图表范围前置

进入 H1/L1 判断前，先按[`PA 图表视觉复核卡`](../../docs/visual_pa_review_card_CN.md)查看同一标的至少两年的 Daily 左侧背景（若窗口支持），并记录主要高点、主要低点、支撑阻力和 EMA20/50/200。局部 4H/1H/15m 只能补充回调细节；缺少这些左侧证据时保留 `pending`，不把局部第一根顺向 K 机械命名为 H1/L1。

## 视觉定义

- 背景是开放趋势、方向许可清楚，而不是交易区间中部；
- 多头 H1 的 Daily EMA20、EMA50 均向上；空头 L1 的 Daily EMA20、EMA50 均向下；任一走平或反向时降级为 `pattern_like / observation_only`；
- A 腿方向性明显：收盘有压力、重叠较少、有跟随；
- B 回调较浅，或主要以时间整理完成；
- 第一次方向恢复在支撑/阻力、前高/前低、突破区，或与方向一致的 EMA20/EMA50 附近出现；
- 信号 K 质量和后续确认足够，且第一障碍不贴着触发价。

多头 H1 的回调结束位置优先靠近向上运行的 EMA20/EMA50、前期低点/支撑或前高突破后的角色转换区；空头 L1 对称地优先靠近向下运行的 EMA20/EMA50、前期高点/阻力或前低跌破后的角色转换区。EMA 触碰本身不是 H1/L1 信号。

H1/L1 的“第一次”是回调中第一次**有意义**的方向恢复，不是第一根顺方向 K，也不是 EMA 触碰后的机械突破。它的优势是更早、更接近强趋势启动；它的代价是第一次尝试失败的概率通常高于 H2/L2，因此必须保留等待第二次入场的分支。

## 多空对称的最小审计模板

| 字段 | 多头 H1 | 空头 L1 |
| --- | --- | --- |
| `parent_state` | 开放上涨趋势，且 Daily EMA20/50 均向上 | 开放下跌趋势，且 Daily EMA20/50 均向下 |
| `A_leg` | 方向性买压、收盘质量和跟随 | 方向性卖压、收盘质量和跟随 |
| `B_state` | 浅、时间整理，或后段明显收缩 | 浅、时间整理，或后段明显收缩 |
| `location` | 向上 EMA20/50、前期低点/支撑、前高回测或突破区 | 向下 EMA20/50、前期高点/阻力、前低回测或突破区 |
| `ema_slope_gate` | `long_pass`：EMA20、EMA50 均向上 | `short_pass`：EMA20、EMA50 均向下 |
| `signal_bar` | 强阳线、先探后收、下影拒绝 | 强阴线、先冲高后收、上影拒绝 |
| `trigger` | 信号 K 高点外 buy-stop | 信号 K 低点外 sell-stop |
| `fallback` | 第一次无跟随则等待 H2 | 第一次无跟随则等待 L2 |

## H1/L1 何时值得优先

1. Daily EMA20、EMA50 与方向一致：H1 两者向上，L1 两者向下；
2. A 腿明显强于普通波动：方向性收盘、少重叠、连续推进或清楚跟随；
3. B 回调浅，或主要通过时间整理完成；
4. 第一次恢复出现在预先存在的支撑/阻力，而不是区间中部；
5. 信号 K 质量好，但没有大到把结构止损推得过远；
6. 触发前已有足够空间到第一独立障碍；
7. 市场、板块和事件背景没有明显冲突。

如果方向一致的 EMA、前高/前低、支撑/阻力或角色转换在同一回调区域重合，记录为 META 共振并在图上标出区域；它是质量加分项，不是独立触发器，也不能补救 EMA 斜率不合格或首障碍不足。

这是一组优先筛选条件，不是固定阈值，也不代表 H1/L1 的胜率高于 H2/L2。

## 什么时候必须降级到 H2/L2

- A 腿普通、宽通道、重叠多或父级处于过渡；
- Daily EMA20/50 走平、反向或无法确认方向；
- B 前段反向压力很强，尚未在后段稳定；
- H1/L1 信号位在区间中部或没有左侧结构支持；
- 信号 K 只有形状，没有确认和跟随；
- 第一阻力/支撑贴近触发，或结构止损过宽；
- 开盘跳过旧触发，必须重建订单而不是假设原价成交。

降级不是“形态错误”：可以保留 `H1/L1-like`，但等待同一回调中的 H2/L2、新结构或观望。

## 订单与风险分支

- 默认研究 `stop-confirmation`，信号 K 只是 setup/count bar；
- 低周期 1H/15m 可以确认 H1/L1，但不能用窄止损覆盖高周期结构风险；
- limit/retest 是独立合同，不能和原 stop 分支合并；
- 首障碍不足约 1R、事件过滤失败或父级结构不明时，记录 `valid_no_trade`；
- 如果第一次尝试失败，不能把后续 H2/L2 的结果倒灌成 H1/L1 当时已知的证据。

## 研究分支

- `candidate`：强 A + 受控 B + 位置清楚 + 有空间；
- `boundary`：形态像，但 A 普通、位置模糊、首障碍拥挤或触发被跳空；
- `no_trade`：区间中部、第一尝试太晚、结构止损过宽或事件过滤失败。

## 当前目标验收

- 多空方向使用同一套“强 A → 受控 B → 第一次恢复 → stop-confirmation”语言；
- 至少一个案例展示 H1/L1 值得研究、另一个展示应等待 H2/L2；
- 形态标签、订单成交、结构止损、第一障碍和 R/R 分栏记录；
- 不把事件驱动 A、普通 A、区间中部和趋势末端追价混成一组。

## 入场审计

默认先研究 signal K 高/低点外的 stop-confirmation。若使用低周期确认，必须说明它是在确认同一高周期合同，还是另立短线合同。止损放在父级结构失效处，不因为想提高 R/R 而压进正常波动。

## 暂不冻结

不设固定实体百分比、成交量阈值、EMA 距离或斜率数值阈值；但方向性斜率闸门已经采纳：H1 多头两条均线向上，L1 空头两条均线向下。其余仍用强 A、B 后段压力变化、位置和首障碍做视觉判断。
