# H1 / L1：第一次入场

状态：`visual-research / provisional / priority-required`

## 研究目的

实现强方向 A 腿后的第一次恢复：多头看 H1，空头看 L1。H1/L1 不是“碰到 EMA 后的第一根 K”，而是回调结束、方向尝试重新出现并位于有意义结构位置的候选。

## 视觉定义

- 背景是开放趋势、方向许可清楚，而不是交易区间中部；
- A 腿方向性明显：收盘有压力、重叠较少、有跟随；
- B 回调较浅，或主要以时间整理完成；
- 第一次方向恢复在支撑/阻力、前高/前低、突破区或 EMA 汇合处出现；
- 信号 K 质量和后续确认足够，且第一障碍不贴着触发价。

H1/L1 的“第一次”是回调中第一次**有意义**的方向恢复，不是第一根顺方向 K，也不是 EMA 触碰后的机械突破。它的优势是更早、更接近强趋势启动；它的代价是第一次尝试失败的概率通常高于 H2/L2，因此必须保留等待第二次入场的分支。

## 多空对称的最小审计模板

| 字段 | 多头 H1 | 空头 L1 |
| --- | --- | --- |
| `parent_state` | 开放上涨趋势或关键支撑处的多头恢复 | 开放下跌趋势或关键阻力处的空头恢复 |
| `A_leg` | 方向性买压、收盘质量和跟随 | 方向性卖压、收盘质量和跟随 |
| `B_state` | 浅、时间整理，或后段明显收缩 | 浅、时间整理，或后段明显收缩 |
| `location` | 支撑、前高回测、突破区或 EMA 汇合 | 阻力、前低回测、突破区或 EMA 汇合 |
| `signal_bar` | 强阳线、先探后收、下影拒绝 | 强阴线、先冲高后收、上影拒绝 |
| `trigger` | 信号 K 高点外 buy-stop | 信号 K 低点外 sell-stop |
| `fallback` | 第一次无跟随则等待 H2 | 第一次无跟随则等待 L2 |

## H1/L1 何时值得优先

1. A 腿明显强于普通波动：方向性收盘、少重叠、连续推进或清楚跟随；
2. B 回调浅，或主要通过时间整理完成；
3. 第一次恢复出现在预先存在的支撑/阻力，而不是区间中部；
4. 信号 K 质量好，但没有大到把结构止损推得过远；
5. 触发前已有足够空间到第一独立障碍；
6. 市场、板块和事件背景没有明显冲突。

这是一组优先筛选条件，不是固定阈值，也不代表 H1/L1 的胜率高于 H2/L2。

## 什么时候必须降级到 H2/L2

- A 腿普通、宽通道、重叠多或父级处于过渡；
- B 前段反向压力很强，尚未在后段稳定；
- H1/L1 信号位在区间中部或没有左侧结构支持；
- 信号 K 只有形状，没有确认和跟随；
- 第一阻力/支撑贴近触发，或结构止损过宽；
- 开盘跳过旧触发，必须重建订单而不是假设原价成交。

降级不是“形态错误”：可以保留 `H1/L1-like`，但等待同一回调中的 H2/L2、新结构或观望。

## 订单与风险分支

- 默认研究 `stop-confirmation`，信号 K 只是 setup/count bar；
- 低周期 1H/15m 可以确认 H1/L1，但不能用窄止损覆盖高周期结构风险；
- limit/retest 是独立合同，不能和原 stop 分支合并；
- 首障碍不足约 1R、事件过滤失败或父级结构不明时，记录 `valid_no_trade`；
- 如果第一次尝试失败，不能把后续 H2/L2 的结果倒灌成 H1/L1 当时已知的证据。

## 研究分支

- `candidate`：强 A + 受控 B + 位置清楚 + 有空间；
- `boundary`：形态像，但 A 普通、位置模糊、首障碍拥挤或触发被跳空；
- `no_trade`：区间中部、第一尝试太晚、结构止损过宽或事件过滤失败。

## 当前目标验收

- 多空方向使用同一套“强 A → 受控 B → 第一次恢复 → stop-confirmation”语言；
- 至少一个案例展示 H1/L1 值得研究、另一个展示应等待 H2/L2；
- 形态标签、订单成交、结构止损、第一障碍和 R/R 分栏记录；
- 不把事件驱动 A、普通 A、区间中部和趋势末端追价混成一组。

## 入场审计

默认先研究 signal K 高/低点外的 stop-confirmation。若使用低周期确认，必须说明它是在确认同一高周期合同，还是另立短线合同。止损放在父级结构失效处，不因为想提高 R/R 而压进正常波动。

## 暂不冻结
