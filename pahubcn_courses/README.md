## 研究使用约定

- 先判断市场处于趋势、通道还是交易区间，再判断形态；不要脱离背景孤立读单根 K 线。
- 形态是概率结构，不是确定预测。入场、初始止损、目标、管理方式和失效条件必须分开记录。
- 将“课程中的一般性框架”“本人的交易规则”“经过样本验证的规则”分开，避免把事后解释当成已验证优势。
- 本目录目前是学习整理稿。任何规则进入回测或实盘前，都要补充可重复条件、样本范围、交易成本、滑点和失效统计。
