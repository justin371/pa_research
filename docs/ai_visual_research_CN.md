# AI 视觉研究：当前默认入口

目标是让 Astra 直接读图，结合 Al Brooks 的背景与案例推理，提出值得检验的入场假设。模型选择沿用当前任务配置；这里没有新增 API 或自动交易服务。此入口取代日常发现阶段的固定表格流程，旧合同仅用于指定历史实验与兼容导出。

## 日常怎么做

先看实际图像，再写简短研究备忘。AI 自主选择足够的全局背景和局部放大；需要时结合 Daily、4H 或更低周期。说明看到了什么、市场当前可能在做什么、哪里值得等待、什么变化会推翻判断。价格行为的连续性、压力、重叠、突破质量和位置比标签先行。

有价值的竞争解释要留下；不要求每张图凑足固定数量的假设、标签或候选。H1/H2、ABC、BOP、楔形等是描述语言，数不清某一腿不等于没有研究价值。均线和成交量提供背景，不自动否决反转或转换状态。上下文不足时注明局限并决定补图或观察；不用“缺两年图”代替看图判断。

按当前疑问检索 [Brooks 图例索引](../knowledge/brooks_visual_examples.json)，打开原页或本地授权图像，再比较相似点和关键差异。优先找容易误认的反例及相同结构不同结果的对照，不只找外观最像的成功图。文字摘要不能冒充读过图；课程示例不能成为该候选的胜率样本。

```powershell
python scripts/pa_visual_examples.py --query "breakout"
```

轻量记录可以是几段文字：图表路径/来源与可见截止时点；背景和关键视觉证据；首选解释与有意义的反证；等待的变化及失效条件；参考例与差异；下一步。模糊价格写区域，只有读取对应 OHLC 后才写精确入场、止损和首障碍。模板不要求填写与本次问题无关的轴或分数。

## 哪些工作交给 AI，哪些交给代码

| 工作 | 当前处理方式 |
| --- | --- |
| 背景、压力、趋势/区间转换、多周期关系 | AI 直接读图并解释证据；不用固定六步分类器 |
| 腿段、形态、候选发现和排序 | AI 比较多个合理解释；取消发现阶段的形态白名单和配额 |
| EMA、覆盖窗口、信号质量 | AI 按问题判断相关性；保留实际可见范围与冲突说明 |
| Brooks 类比与反例选择 | 简单索引检索辅助 AI；实际打开图例并解释差异 |
| 价格、费用、R、时间与来源绑定 | 程序计算或验证，不能靠像素猜测和语言自信 |
| 未来信息隔离、冻结记录、样本重复和结果统计 | 程序守护；不把事后教学例混入前向测试 |
| “高概率”判断 | 可说明定性优势；数值胜率需独立结果样本，当前仍未知 |

## 从想法到可检验结果

AI 可独立完成研究备忘，不需要每次等专家批准。准备回放时，才把选定假设转成精确的方向、触发、结构止损、首障碍、退出规则和费用假设，并在看后续结果前冻结图像、截止时点、来源和记录。冻结历史判断不等于真实事前预测；已看过结果或相关标签时必须注明污染。

现有回放器仍要求 `human_chart_review` 和旧枚举；本次没有放宽该引擎，也不能把 AI 伪装成人工。AI 备忘不直接输入旧引擎。需要旧合同回放时遵守其真实来源要求；新的 AI 直接回放接口属于后续明确实现范围，不能宣称已经支持。原来的人工/专家要求仅继续用于这些旧合同或专家标注准确率基准。

后续验证分两件事：识图解释与独立专家的一致性，以及冻结决策后的交易结果。比较旧流程和 AI 流程时使用相同的未看结果样本、费用与退出规则，同时统计漏选、误选、弃权、成本后收益和回撤。熟悉的仓库图只作工作流演示，不能证明 Astra 优于旧流程。扩大图例库优先覆盖失败与边界结构，实际数量和验证状态以索引为准。
