# Measured Move、AB=CD 与磁铁目标管理

状态：`visual-research / provisional / cross-pattern / not-quantitative`

这是 PA Research 的第二个基础视觉层。它不把 MM 当成新的 K 线形态，也不把 AB=CD、缺口、EMA 或 50% 回调相加成机械评分。它的作用是：在已经有背景、结构和订单合同之后，帮助视觉助手判断空间、第一道障碍、目标层级和持仓管理。

## 1. 两种语言必须分开

### 结构语言

`A 腿 → B 回调 → C 恢复` 描述市场状态与控制权。它回答：方向腿是否强、回调是否受控、下一次尝试是否成立、区间是否已经重置。

### 测量语言

`AB=CD`、`Leg 1 = Leg 2`、区间高度或缺口测量描述距离投影。它回答：如果第二段复制第一段，可能走到哪里。

因此：

```text
结构：确认 A、B、C 和当前父级状态
测量：冻结锚点，从 C 投影 D
交易：先审计订单、结构止损、第一独立障碍和路径 R/R
```

价格符合一个漂亮的 1:1，并不能自动把它叫作 C 腿、H2、MTR 或入场信号。

## 2. 常用测量类型

### 2.1 AB=CD / Leg 1 = Leg 2

多头测量可写成：

```text
D = C + (B - A)
```

空头测量可写成：

```text
D = C - (A - B)
```

这里的 A、B、C 是测量锚点，不一定等于 pattern 标签中的 A、B、C。锚点必须在当时图表可见时冻结，允许记录“接近等距”“不足”或“扩展”，不允许事后移动锚点去制造精确命中。

### 2.2 区间高度与已接受突破高度

只有在区间边界真实、反复被验证，并且突破被接受之后，区间高度或突破高度才有目标意义。一次影线刺破、收回或没有跟随，不能先使用 breakout height，再把后续走势解释成已经接受的突破。

### 2.3 Measuring gap

缺口可以成为未充分交易区域、磁铁或角色转换区。普通缺口较容易被测试；突破型缺口可能只回测一部分；衰竭型缺口更需要防止深度回补和反转。缺口回补是路径信息，不是“必须回补”的入场条件。

### 2.4 结构磁铁

主要高点、主要低点、区间边缘、角色转换区、缺口边缘、通道边界和明确的前高/前低，都是可能改变路径的磁铁。磁铁的强度和距离是两个维度：最强的区域不一定是第一遇到的区域，但第一遇到的独立区域也不能被远端 MM 跳过。

同一价格簇中的前高、缺口边缘、EMA、50% 和 MM 只记为一个主要障碍，同时注明各自来源；不能把同一位置重复计算成多个 META 优势。

## 3. 目标层级

所有候选在入场前按下面的顺序审计：

```text
入场合同
  ↓
结构止损
  ↓
第一独立障碍 / 磁铁
  ↓ 只有在强收盘、跟随和回测接受后
第二道结构障碍或角色转换区
  ↓ 路径仍开放时
AB=CD / Leg 1 = Leg 2 / 区间高度 / 缺口测量
  ↓
更大父级腿的延伸
```

### 第一独立障碍

第一障碍是从入场方向看最先遇到、真正可能改变价格路径的区域。优先检查：

1. 近端反复反应的主要摆动高低点或角色转换区；
2. 成熟区间的上沿/下沿；
3. 突破区、缺口边缘、通道边界和反复验证的次要结构；
4. 低周期局部位，但只有在低周期合同独立成立时才可使用。

如果第一障碍距离不足约 1R，候选默认降级为 `valid_no_trade` 或缩小暴露；完整波段想法通常需要更宽的空间，但不能用远端 MM 救回近端坏 R/R。

### 障碍接受后的升级

只有同时出现以下证据，才把状态从“阻力前管理”切换为“突破后目标管理”：

- K 线实体和收盘明确越过区域；
- 有跟随，而不是单根孤立大 K；
- 回测中原阻力转为支撑，或原支撑转为阻力；
- 价格没有立即收回旧区间。

记录状态 `obstacle-accepted`，再把下一个 MM 作为主要目标。原来等待阻力反应的合同与新的 BOP/回踩合同必须分开，不把两者结果合并。

## 4. 局部腿与父级腿

时间窗口不能切得过短。一条局部上涨可能是更大上涨腿中的嵌套腿，局部目标与父级目标可以并存：

```text
local_measure: 锚点、目标区、首障碍、当前状态
parent_measure: 锚点、目标区、首障碍、当前状态
```

局部腿可以帮助短线管理，父级腿可以帮助理解背景；父级远端目标不能倒过来授权局部入场。若两种投影落在同一价格簇，合并为一个目标区；若局部测量穿过已知主要障碍，先暂停该投影。

## 5. 订单、止损与持仓管理

入场前必须冻结：

- 订单类型、触发价和实际成交假设；
- 结构失效点与合理缓冲；
- 第一障碍的来源和价格区；
- 到首障碍的粗略 R/R；
- 事件、财报、跳空、板块和多周期过滤结果。

结构止损不能只放在方便计算的信号 K 极值内；也不能用一个过窄的低周期止损去掩盖高周期结构已经失效。财报前三个交易日不建立新仓；跳空穿过触发价时必须重算实际成交、风险和第一障碍空间。

到目标区后，MM 是区域而不是精确点。实体变小、重叠增加、跟随失败、反复长影线、成熟通道或磁铁出现反应时，可以先减仓一部分，剩余仓位再看精确 MM 或更大延伸。不要为了最后几个价格单位把全部利润暴露给首障碍反应。

若结构止损先被破坏，记录 `path-invalidated-before-target`，即使后来价格到达 MM，也不能把原计划改写为成功。若价格先接受第一障碍，记录 `obstacle-accepted` 并创建新的管理合同。

## 6. 跨案例入口

详细证据审计见 [`Measured Move / AB=CD / 磁铁视觉证据审计`](../../research/measured_move_visual_evidence_gap_audit_2026-08-24_CN.md)。当前基础案例包括：

- KLAC `2025-05-07`–`2025-06-03`：H2 后先遇 `79.03–79.79` 近端阻力，远端 MM 约 `87`；先审计首阻力，目标区减仓，不让 MM 跳过阻力。
- TSLA `2025-08-06`–`2025-08-22`：H2 后先遇 `340.25–340.55`，再遇 `348.68–357.54`；日线与低周期合同必须分开。
- TSLA `2024-03-04`–`2024-03-14`：MM `153.93` 与左侧支撑 `152.37–153.75` 重叠，只算一个目标簇；结构路径先失效的案例。
- TSLA `2025-03-11`–`2025-05-13`：卖出高潮 MM `220–224` 到位后进入宽区间；目标完成不等于自动反转。
- NFLX `2024-08-05`–`2024-09-26`：首支撑 `66.54–65.98` 太近，远端测量不能修复 R/R，标记 no-trade。
- TSLA `2025-09-08`–`2025-09-12`：强收盘越过阻力并有跟随，旧阻力接受后才升级到后续目标。

## 7. 当前边界

本层仍为 `provisional`。它服务于视觉筛选和交易计划复核，不进入 Codex Trading，不生成量化扫描器，不连接 Execution Agent。后续新增案例只有在锚点、首障碍、结构止损、订单合同和实际路径能够重建时，才值得继续深审。
