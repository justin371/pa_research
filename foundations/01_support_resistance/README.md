# Support / Resistance / 支撑阻力视觉基础层

文档状态：`document_status=adopted / research_state=provisional / handoff_status=not_ready / not-quantitative`

统一字段、方向和状态分轴见[`PA Research 统一输出合同`](../../docs/pa_research_output_schema_v0_1_CN.md)。

支撑阻力是所有 PA pattern 的位置、止损和首障碍过滤器，不是一个单独的买卖形态。它按区域而不是一条精确线记录；“强度”与“距离”必须分开判断。

## 强度层级

| 层级 | 典型来源 | 主要用途 |
| --- | --- | --- |
| `major` | 大周期主要摆动高/低点、成熟交易区间上/下沿、明确角色转换、多周期重合且强力离开区域 | 父级位置、结构失效、主要目标或强首障碍 |
| `intermediate` | 清楚的次要摆动、失败突破区、缺口边缘/起涨起跌区、通道边界、反复验证的 EMA20/EMA50 | 回调能否守住、第一段空间、回测合同、META 汇合 |
| `local` | 单个局部高低点、单根 K 极值、孤立 EMA 触碰、未经反应确认的趋势线/数学投影 | 低周期触发、短线管理和细化，不应压过母级结构 |

这不是“major 永远先到”的排序。交易审计从实际入场方向寻找**最近的独立障碍**：近处的 local/intermediate 不能被远处的 major 或 MM 跳过；局部点也不能随意升级成母级结构。

## 区域而不是精确线

- 先画价格簇：多个相近高低点、实体区域、影线测试、缺口边缘和角色转换可以合并为一个区域；
- 同一价格簇中的前高、EMA、50% 回调、缺口和 MM 只算一个主要障碍，再记录各自来源；
- 单根影线刺破后收回，先记为测试；强收盘、跟随和回测守住才支持结构被接受；
- 越高周期、越多次反应、离开越有力度、越多周期重合，越可能升级层级；但不把视觉印象写成固定分数。

## 位置判断顺序

1. 左侧在当时已经发生了什么：主要高点/低点、区间边缘、缺口、起涨/起跌区；
2. 当前价格靠近 major、intermediate、local 还是中部；
3. 该区域对当前方向是支撑、阻力、磁铁还是已经完成角色转换；
4. 触发后最先到达的独立区域在哪里；
5. 结构止损需要放在哪个层级外，第一障碍是否给足空间；
6. 如果形态成立但位置/空间不成立，输出 `valid_no_trade`，不要用远端 MM 挽救。

## 主要高低点与次要高低点

- **主要高点/低点**：在更高周期形成明显摆动，造成强反向反应、突破、区间边缘或长期记忆；通常可以作为结构失效或 major 障碍。
- **次要高点/低点**：当前腿内清楚但影响范围较小的反应点，用来定义回调、信号 K、局部颈线和低周期触发。
- **未确认点**：只有一根 K 的极值、没有后续反应或只由数学投影得到，先保持 local/候选。

主要/次要不是固定的价格属性，而是相对于周期、父级和当前研究合同的层级。一个次要点在更高周期或多次回测后可能升级；一个原本主要的区域在被强收盘接受后，也可能从障碍变成支撑/阻力转换区。

## 角色转换

### 阻力转支撑

```text
原阻力
→ 强收盘越过
→ 外侧停留/跟随
→ 回测原区域
→ 回测守住
→ 新支撑角色成立
```

### 支撑转阻力

空头对称：支撑被接受跌破，反弹回测失败，再由空头跟随确认。只有影线越过、没有跟随或重新回到原区间时，仍是测试/失败突破候选。

角色转换成立后，旧的区间、MTR、H/L 或 BOP 合同不能沿用原止损和原 R/R；必须按新角色建立新合同。

## 与 pattern 的连接

- H1/H2、L1/L2：优先看是否在与方向一致的 EMA20/EMA50、主要支撑/阻力、前低/前高、突破回测或区间边缘，不在中部机械计数；日线多头要求 EMA20/50 均向上，空头要求均向下；
- ABC：B 能否守住 A 起点、旧突破区、EMA 或角色转换区，决定是否仍可看 C；
- 区间边缘：上下沿是主要位置，中线是首磁铁和常见 no-trade 区；
- 三推/H3-L3 与双顶/双底：次数不是交易授权，第三次测试必须结合所在区域和扩张/衰竭；
- MTR/头肩/Final Flag：形态只有落在成熟趋势极端和主要位置，才有反向研究价值；
- BOP：原 major/intermediate 边界被收盘、跟随、回测接受后，才改写为突破合同；
- MM：先看最近独立支撑/阻力，只有接受或穿越后再看 MM/AB=CD。

## 订单、止损与首障碍

- `stop_confirmation`：在结构区域反应后的信号 K 外等待；触发价必须和实际成交分开记录；
- `limit_retest`：只有区域角色转换或边缘回测已冻结才使用；未回测不能假设成交；
- `market_close`：强收盘后的晚确认分支，仍需检查首障碍与滑点；
- `observation_only`：中部、区域未确认、影线未被接受、事件/跳空改变几何或首障碍拥挤。

结构止损放在能覆盖正常测试的区域外：支撑/阻力簇外、父级极端外或真正失效点外。不能为了得到好看的 R/R 把止损塞进区域内部。目标顺序是第一独立障碍 → 第二道结构区域/角色转换 → MM/AB=CD/区间高度。首障碍不足约 1R 记为 `valid_no_trade`，完整波段约 2R 是参考而非固定胜率门槛。
